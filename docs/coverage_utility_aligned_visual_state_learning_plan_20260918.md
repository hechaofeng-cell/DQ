# 覆盖－效用对齐的视觉状态学习完整方案

> 文档状态：实验设计稿，2026-09-18  
> 工作名称：Coverage-Utility Aligned Visual-State Learning（CUA-VSL）  
> 基础版本：Visual-State Coverage-Aware Learning（VSCAL）  
> 当前案例：Open Images V7 五分类目标区域分类，dog 为状态覆盖增强类别

## 1. 方案定位

本研究不再只回答“补图后覆盖率是否提高”，而是进一步回答：

> 可解释视觉状态覆盖的改善，怎样通过数据选择和训练机制转化为模型在稀有、困难视觉状态上的识别收益？

当前实验已经证明：在相同新增 300 张 dog 图片的预算下，`gap300` 的 dog_v3.1 覆盖指数为 91.73%，高于 `random300` 的 87.89%，差值为 3.85 个百分点。但四个标准分类骨干没有获得一致的性能提升。这说明：

1. 缺口驱动选样能够提高定义内覆盖；
2. 普通交叉熵训练不一定主动利用新增的稀缺状态；
3. 覆盖率提高不是模型性能提高的充分条件；
4. 下一步需要把覆盖信息显式接入训练目标，并优先处理“既缺少、又导致模型出错”的状态。

因此，新方案将原来的“测量－补图－重新训练”流程升级为：

```text
视觉状态定义
    ↓
覆盖缺口测量
    ↓
验证集状态错误估计
    ↓
覆盖－效用联合优先级
    ↓
等预算候选选择
    ↓
覆盖感知采样与状态辅助学习
    ↓
固定测试集上的总体与状态分层评价
```

本方案的创新目标是构建一个统一闭环，而不是宣称提出新的 ResNet、ConvNeXt、MaxViT 或 EfficientNet 骨干网络。

## 2. 与以前方案的主要区别

### 2.1 总体对比

| 维度 | 以前的方案 | 新方案 |
|---|---|---|
| 研究重点 | 视觉状态覆盖评价与缺口补图 | 覆盖测量、选样、训练和评价的一体化方法 |
| 状态信号用途 | 主要用于候选图片选择 | 同时用于候选选择、训练采样、辅助损失和分层评价 |
| 选样依据 | 状态是否缺失或低频 | 状态覆盖缺口与验证错误的联合优先级 |
| 模型训练 | 标准骨干加普通交叉熵 | 标准骨干加覆盖感知采样和 23 组状态辅助头 |
| 状态与任务关系 | 默认稀缺状态可能有价值 | 用验证集错误判断该状态是否影响当前分类任务 |
| 主要模型指标 | Accuracy、Macro-F1、dog F1、dog Recall | 原指标加 Rare-State Macro Recall、Worst-State Recall 等状态指标 |
| 随机对照 | 一组固定 `random300` | 至少五组独立随机 300，对随机选择方差建模 |
| 随机种子 | 每个条件三个训练种子 | 正式实验建议至少五个训练种子 |
| 消融实验 | base、random300、gap300 | 分离选样、加权采样、状态辅助头及效用反馈的贡献 |
| 论文主张 | 缺口选样提高覆盖，性能收益部分成立 | 检验覆盖－效用对齐是否能稳定转化为稀有状态收益 |
| 推理阶段 | 标准分类器 | 仍为标准分类器，状态辅助头可删除 |

### 2.2 相对于基础 VSCAL 的增强

基础 VSCAL 使用覆盖缺口指导采样和状态辅助学习。增强后的 CUA-VSL 还加入模型效用信号：

```text
VSCAL：状态越缺少，优先级越高

CUA-VSL：状态越缺少，并且模型在该状态上越容易出错，优先级越高
```

这个变化针对当前实验中最关键的现象：某些状态虽然稀有，但未必影响五分类决策；如果只追求覆盖，可能把预算用于与任务性能弱相关的状态。

### 2.3 现有结果与新实验的关系

现有四模型、三条件、三种子共 36 次训练是新方案的重要先导证据，但不是 CUA-VSL 的结果，因为这些训练尚未包含：

- 状态辅助头；
- 覆盖感知采样；
- 覆盖－效用联合优先级；
- 多组独立随机补图对照；
- 足量的状态校准集与状态分层测试集。

如果新实验改变数据划分或增加状态校准集，所有 E0-E8 条件都必须在同一新协议下重新训练。不能把旧的 `gap300` 结果与新训练的 CUA-VSL 结果直接拼接成公平比较。

## 3. 研究问题与假设

### RQ1：覆盖测量是否能发现并补足可解释的类内视觉状态缺口？

- H1：在相同补图预算下，缺口驱动选择的覆盖指数高于随机选择。
- 当前证据：已支持一次固定 `gap300` 对 `random300` 的比较。
- 尚缺证据：多组随机补图的分布、人工状态标签审计和跨类别复验。

### RQ2：覆盖感知训练能否让分类模型更充分地利用稀有状态样本？

- H2：在相同训练数据上，覆盖感知采样与状态辅助学习能够提高稀有状态平均 Recall。
- 主要比较：E5 对 E3，以及 E5 对 E4。

### RQ3：加入任务错误信号是否优于只依据覆盖缺口？

- H3：覆盖－效用联合选样和训练优于纯覆盖驱动方法。
- 主要比较：E8 对 E5；E6 和 E7 分别隔离效用信号在训练与选样环节的贡献。

### RQ4：方法收益是否具有跨模型一致性？

- H4：该方法在多个不同结构的预训练骨干上保持方向一致，而不是只对某一个模型有效。
- 骨干：ResNet-18、ConvNeXt-Tiny、MaxViT-T、EfficientNetV2-S。

## 4. 问题定义与数据协议

### 4.1 分类任务

第一阶段继续使用已知目标框裁剪图进行五分类：

```text
dog / cat / horse / sheep / person
```

这样能够减少背景和多目标干扰，并与现有实验保持一致。当前结论只适用于目标区域分类，不能外推为端到端目标检测结果。

### 4.2 数据集合

建议在新实验开始前冻结以下清单：

```text
D_train_base   原始训练集
D_cal          可选的独立状态校准集；采用交叉拟合时可以不单独划分
D_val          模型选择与早停验证集
D_test         固定主测试集
D_state_test   人工复核的状态分层测试集
U_dog          未进入训练、校准、验证和测试的 dog 候选池
```

要求：

1. `D_test` 和 `D_state_test` 在选样与调参之前冻结；
2. 测试集不参与状态缺口计算、选样、超参数选择或停止判断；
3. 推荐使用 `D_train_base` 内的分层交叉拟合产生训练外预测来估计状态错误；如果改用 `D_cal`，其中必须有足够的 dog 状态样本，现有每类 30 张的验证集不足以稳定估计大量状态错误率；
4. 所有条件使用完全相同的非 dog 数据、验证集、测试集和训练预算；
5. 检查 image ID、图像哈希和感知哈希，排除训练与测试的重复和近重复；
6. 每个图片固定一个目标框，保存图片 ID、目标框、类别和数据版本。

### 4.3 dog_v3.1 状态标签

每个 dog 目标使用固定三视图输入本地 VLM：

```text
原图 + 目标框标记图 + 目标框裁剪放大图
```

输出 23 组有限枚举视觉状态。标签处理规则：

- `unknown`、不可见或不适用状态使用掩码，不进入相应辅助损失；
- 非 dog 图片不计算 dog 状态辅助损失；
- 保存 VLM 原始响应、解析结果、协议版本和校验错误；
- 正式论文至少人工复核 `gap300`、随机对照和 `D_state_test`；如果采用独立 `D_cal` 路线，也应复核 `D_cal`；
- 对低一致性状态可以删除、合并，或降低训练权重，但必须在测试结果揭晓前确定。

## 5. 方法设计

### 5.1 符号

设视觉状态全集为 `S`，状态 `s` 在基础 dog 训练集中的频数为 `n_s`，目标覆盖阈值为 `tau`。当前覆盖实验采用每状态 30 次封顶，因此新实验可将 `tau=30` 作为预注册起点，但应通过训练集与校准集确定，不能依据测试结果调整。

图片 `x_i` 是否具有状态 `s` 表示为：

```text
I(i,s) = 1  图片 i 具有状态 s
I(i,s) = 0  图片 i 不具有状态 s 或该状态被掩码
```

### 5.2 覆盖缺口

单个状态的标准化缺口定义为：

```text
d_s = max(0, tau - n_s) / tau
```

其范围为 `[0,1]`：

- `d_s = 0`：状态已经达到目标频数；
- `d_s = 1`：状态在基础训练集中完全缺失；
- 中间值：状态存在但仍未达到目标频数。

覆盖指数仍作为数据属性独立报告，不与分类准确率混写。

### 5.3 状态任务错误

推荐使用训练集内的分层 K 折交叉拟合估计状态条件错误率：每一张基础训练图片都只由未见过该图片的折外模型预测，再把 dog 折外预测与 dog_v3.1 状态标签连接。这样既不使用测试集，也不需要从候选池拿走最稀有图片。可以预注册 ResNet-18 与 ConvNeXt-Tiny 为两个效用参考模型，并对二者的折外状态错误率取平均，使后续 `CUA300` 对四个评估骨干保持固定。

如果计算预算受限，也可以使用独立的 `D_cal`，但 `D_cal` 必须从所有候选选择和最终训练中排除。对于包含状态 `s` 的 dog 样本：

```text
e_s = (FN_s + beta * e_global) / (N_s + beta)
```

其中：

- `FN_s`：具有状态 `s` 但没有被正确预测为 dog 的数量；
- `N_s`：折外预测集合或 `D_cal` 中具有状态 `s` 的 dog 数量；
- `e_global`：参考模型在全部 dog 折外样本上的错误率；
- `beta`：收缩强度，建议预注册从 `beta=10` 开始。样本少的状态向全局 dog 错误率收缩，样本多的状态主要由自身错误决定。

当 `N_s` 太小时，不直接使用原始错误率。应采用以下一种预注册处理：

1. 使用上述向全局 dog 错误率收缩的估计；
2. 把状态合并到同一特征组；
3. 仅依据覆盖缺口，不引入该状态的错误项；
4. 扩充人工复核的状态校准样本。

### 5.4 覆盖－效用联合优先级

定义状态优先级：

```text
p_s = d_s^eta * e_s^kappa
```

其中 `eta` 和 `kappa` 控制覆盖缺口与任务错误的重要程度。推荐把以下设置作为有限消融，而不是进行大规模测试集调参：

```text
纯覆盖：eta=1, kappa=0
等权联合：eta=1, kappa=1
弱效用校准：eta=1, kappa=0.5
```

`p_s` 只根据训练集折外预测或独立 `D_cal` 计算，并在候选选择前冻结。

### 5.5 候选图片选择

对候选图片 `x`，基础价值为：

```text
q(x) = sum_s p_s * I(x,s)
```

正式选择使用动态边际增益。每选择一张图片后更新相应状态的剩余缺口，再选择下一张：

```text
Delta(x | A) = sum_s e_s^kappa * [d_s(A) - d_s(A union {x})]
```

其中 `A` 是已经选择的候选集合。这样可以避免连续选择大量具有相同状态的冗余图片。

在相同 300 张预算下形成：

```text
S_random：随机选择
S_gap：只根据覆盖缺口选择
S_cua：根据覆盖缺口与状态错误联合选择
```

三组都必须经过相同的真实 dog 检查、质量控制和去重流程。

### 5.6 覆盖感知训练采样

训练样本权重根据冻结的基础状态优先级计算：

```text
r_i = mean({p_s | I(i,s)=1})
w_i = clip(1 + alpha * normalize(r_i), 1, w_max)
```

建议：

- 保持五个类别的顶层类别平衡；
- 只在 dog 类内部进行状态感知采样；
- 对 `w_i` 设置上限，防止少数样本被过度重复；
- 每个 epoch 的总抽样数保持一致，避免把更多训练步数误当成方法收益；
- 首次实验可设 `w_max=3`，并只在训练集与验证集上选择 `alpha`。

### 5.7 状态辅助学习

模型结构为：

```text
目标框裁剪图
      ↓
共享骨干 f_theta
      ↓
共享特征 z
      ├── 五分类头 g_cls
      └── 23 组状态头 g_state_1 ... g_state_23
```

23 组状态中，21 组 `enum` 字段使用独立的 softmax 分类头和交叉熵；`occlusion_parts` 与 `truncation_parts` 两组 `set` 字段使用 multi-hot 目标、sigmoid 输出和二元交叉熵。不能把多选部位字段强制压缩成单一类别。联合损失定义为：

```text
L_total = L_cls + lambda * L_state
```

其中：

```text
L_cls = mean_i [w_i * CE(g_cls(z_i), y_i)]

L_state = L_enum + L_set

L_enum = masked weighted CE over 21 enum heads
L_set  = masked weighted BCEWithLogits over 2 set heads
```

- `m_ij=1` 表示 dog 样本 `i` 的第 `j` 组状态标签有效；
- `m_ij=0` 表示非 dog、`unknown`、不可见或不适用；
- `omega_ij` 由该图片状态对应的 `p_s` 生成并设置上限；
- `lambda` 只通过 `D_val` 选择，不查看测试集；
- 推理时只保留五分类头，因此可以不增加部署阶段的推理开销。

### 5.8 防止负迁移

场景、毛色等状态不一定都帮助类别识别，全部强制学习可能产生负迁移。因此必须做状态组消融：

```text
A：外观状态（颜色、图案、毛发）
B：结构与姿态（头部、身体、腿、尾巴、动作）
C：可见性（遮挡、截断、可识别性）
D：场景状态
```

先比较 `A+B+C` 与 `A+B+C+D`。如果场景辅助任务提高训练指标但降低固定测试集泛化，应将其保留为覆盖评价维度，而不进入模型辅助损失。这个决策必须基于验证集，而不是测试集。

## 6. 实验矩阵

### 6.1 核心消融

| 编号 | 新增数据 | 训练方法 | 回答的问题 |
|---|---|---|---|
| E0 | `random300` | 普通交叉熵 | 随机补图基线 |
| E1 | `gap300` | 普通交叉熵 | 纯缺口选样是否优于随机，已有先导实验 |
| E2 | `random300` | 状态辅助学习 | 辅助监督本身是否有效 |
| E3 | `gap300` | 状态辅助学习 | 缺口选样与辅助监督的组合效果 |
| E4 | `gap300` | 仅覆盖感知采样 | 覆盖采样单独贡献 |
| E5 | `gap300` | 覆盖采样 + 状态辅助学习 | 基础 VSCAL 完整方法 |
| E6 | `gap300` | 效用校准采样 + 状态辅助学习 | 只改变训练优先级，隔离效用训练贡献 |
| E7 | `CUA300` | 纯覆盖采样 + 状态辅助学习 | 只改变选样集合，隔离效用选样贡献 |
| E8 | `CUA300` | 效用校准采样 + 状态辅助学习 | CUA-VSL 完整方法 |

关键判断：

```text
E1 > E0：纯覆盖选样优于随机补图
E3 > E2：在相同辅助训练下，缺口选样仍有额外价值
E5 > E3：覆盖感知采样具有增益
E5 > E4：状态辅助头具有增益
E6 > E5：在相同 gap300 上，效用校准训练优于纯覆盖训练
E7 > E5：在相同训练机制下，效用校准选样优于纯覆盖选样
E8 > E6：在效用训练固定时，CUA300 优于 gap300
E8 > E7：在 CUA300 固定时，效用训练优于纯覆盖训练
E8 > E5：完整 CUA-VSL 优于基础 VSCAL
```

### 6.2 必要的通用基线

为了证明收益不是普通长尾处理即可获得，至少加入：

- 类内逆频率采样；
- Class-Balanced Loss 或等价的有效样本数加权；
- Focal Loss；
- 不使用状态结构、只使用模型置信度或损失进行 hard-example sampling；
- 等预算随机选择的多次重复。

这些基线使用相同数据访问权限、预训练权重、训练步数和调参预算。

### 6.3 骨干模型

继续使用四个已冻结的模型族：

| 模型 | 在实验中的作用 |
|---|---|
| ResNet-18 | 低容量、成熟卷积基线 |
| ConvNeXt-Tiny | 现代卷积网络 |
| MaxViT-T | 卷积与注意力混合结构 |
| EfficientNetV2-S | 高效缩放卷积结构 |

不能只保留结果提高的模型。负结果用于判断方法是否具有架构依赖性。

### 6.4 随机性设计

正式实验建议：

```text
随机补图子集：至少 5 组独立 random300
训练随机种子：每个主要条件至少 5 个
配对原则：相同骨干和相同数据条件使用相同训练种子
```

如果完整 `9 条件 × 4 模型 × 5 种子` 成本过高，可按两阶段执行：

1. ResNet-18 与 ConvNeXt-Tiny 完成 E0-E8 和超参数消融；
2. 冻结方法后，在 MaxViT-T 与 EfficientNetV2-S 上只运行 E0、E1、E5、E8。

第二阶段不能重新根据测试结果调整方法。

## 7. 评价指标

### 7.1 数据覆盖线

```text
C_base
C_random
C_gap
C_cua
Delta C_gap-random
Delta C_cua-gap
```

同时报告：

- 完全缺失状态数；
- 低频状态数；
- 达到 `tau` 的状态数；
- 每组特征的覆盖率；
- 被选择图片对各状态的边际贡献。

### 7.2 总体分类线

- Accuracy；
- Macro-Precision；
- Macro-Recall；
- Macro-F1；
- dog Precision、Recall 和 F1；
- 非 dog 平均 Recall；
- 混淆矩阵。

### 7.3 状态分层线

在人工复核的 `D_state_test` 上计算：

- Rare-State Macro Recall：对预注册低频状态分别计算 dog Recall 后取宏平均；
- Worst-State Recall：状态 Recall 的最低值或最低若干状态均值；
- 小目标、极小目标 Recall；
- 遮挡 Recall；
- 截断 Recall；
- 非典型姿态 Recall；
- 低频毛色与图案 Recall；
- 复杂场景 Recall。

状态分组允许重叠，但必须报告每组样本数和置信区间。样本过少时只作探索性分析。

### 7.4 统计报告

- 报告各训练种子的均值、标准差和全部单次结果；
- 对相同测试图片的模型预测使用配对 bootstrap；
- 对相同种子条件报告配对差值；
- 多组随机 300 用于估计随机选样方差；
- 不以单个最优种子作为主结果；
- 不因为某个骨干下降而删除该骨干。

## 8. 公平性与泄漏控制

所有核心比较必须固定：

- 数据预处理与目标框裁剪；
- ImageNet 预训练权重版本；
- 输入尺寸与数据增强；
- 优化器、学习率计划、batch size；
- epoch 数或每个 epoch 的抽样总数；
- early stopping 规则；
- 验证集、测试集和随机种子；
- 状态协议和 VLM 提示词；
- 模型选择与超参数预算。

禁止：

- 使用 `D_test` 计算 `e_s`；
- 根据测试结果修改 `tau`、`lambda`、`alpha` 或状态分组；
- 对 `gap300` 做更严格清洗、但不对 `random300` 做同等清洗；
- 给 CUA-VSL 更多训练步数；
- 只展示提高的模型或种子；
- 把覆盖指数当作分类准确率。

## 10. 建议的成功条件

正式运行前应冻结成功条件。建议采用以下分层判定：

### 覆盖贡献成立

```text
C_gap > random300 多次抽样覆盖率的均值
```

并报告 gap 结果处于随机覆盖分布的什么位置。

### 基础 VSCAL 得到支持

```text
E5 相对 E3 提高 Rare-State Macro Recall
且 E5 相对 E4 显示状态辅助头的额外收益
```

同时总体 Macro-F1 不应出现预注册为不可接受的下降。具体容忍值必须在查看正式测试结果前确定。

### CUA-VSL 得到支持

```text
E8 相对 E5 在主要状态指标上提高
并在至少 3/4 骨干上方向一致
```

E6、E7 用于解释提升来自效用校准训练、效用校准选样，还是两者的共同作用。如果 E8 提高而 E6、E7 均没有单独提高，应将结果解释为组合效应，而不能把收益单独归因于其中一个模块。

如果只在一个骨干上提高，应写成架构特定结果；如果稀有状态提高但总体指标不变，应写成局部状态收益；如果总体与状态指标都没有改善，应否定或修改当前机制，而不是继续筛选有利模型。

## 11. 创新点及其边界

### 11.1 可以争取的贡献

1. **对象内部视觉状态覆盖表示。** 使用有限枚举、可审计的状态体系描述同一类别内部的外观、姿态、可见性和场景差异。
2. **覆盖－效用联合优先级。** 不仅寻找稀缺状态，还判断这些状态是否对应模型错误，把“少见”与“有任务价值”分开。
3. **同一信号贯通数据与模型。** 使用统一的状态优先级指导候选选择、类内采样和辅助损失。
4. **无额外推理开销的模型插件。** 状态头只在训练阶段使用，可接入多个标准骨干。
5. **覆盖线与性能线分离评价。** 同时报告数据覆盖、总体分类性能和状态分层性能，避免用覆盖指标代替任务指标。

### 11.2 不能直接宣称的内容

- 不能仅因为组件组合完成，就宣称世界首创；
- 不能把普通重采样或属性辅助头本身称为新算法；
- 不能在 E6-E8 尚未运行前声称覆盖－效用对齐有效；
- 不能由 dog 单类别案例推断对所有对象类别有效；
- 不能由目标框分类推断端到端检测性能；
- 不能由当前 91.73% 覆盖率推断模型必然优于随机补图；
- 不能只选择结果提高的模型来证明普遍有效。

### 11.3 与相关研究的边界

| 相关方向 | 已有工作能力 | 本方案需要形成的区别 |
|---|---|---|
| 多属性数据覆盖 | 在多个离散属性上识别欠覆盖区域并计算补数据需求 | 面向对象区域的 VLM 状态、状态可靠性和分类闭环 |
| 稀有切片主动学习 | 根据稀有类别或切片选择待标注样本 | 使用显式状态缺口与验证错误联合定义选择目标 |
| 属性辅助学习 | 联合学习对象类别与视觉属性 | 属性权重来自覆盖缺口与任务错误，而不是统一辅助监督 |
| 长尾重采样与重加权 | 按类别或样本频率调整训练贡献 | 处理类别内部的状态长尾，并与数据获取使用同一优先级 |
| 稀有场景测试集 | 在常见与非典型环境中评价分类器 | 从诊断进一步连接到定向补图和覆盖感知训练 |
| 数据策展基准 | 在固定预算下比较不同策展策略 | 提供可解释状态级选择原因与状态分层收益分析 |

## 12. 结果对应的论文表述

### 情况 A：覆盖和性能均稳定提高

可以写：

> 在固定预算、数据访问和训练配置下，覆盖－效用对齐方法提高了 dog 类内视觉状态覆盖，并在多个骨干上改善了稀有状态识别性能。

仍需限定数据集、任务和模型范围。

### 情况 B：稀有状态提高，总体 Macro-F1 基本不变

可以写：

> 方法的收益主要体现在预注册的稀有视觉状态，而不是整体平均性能，说明总体指标可能掩盖类内困难切片的变化。

### 情况 C：覆盖提高，但模型性能仍不提高

可以写：

> 可解释状态覆盖是独立的数据属性，但其改善没有在当前任务和训练机制下稳定转化为分类收益。

这种结果仍可支持覆盖诊断价值，但不支持模型改进主张。

### 情况 D：只有单个模型提高

可以写：

> 方法收益具有架构依赖性；当前证据不足以支持跨模型普遍有效。

不得删除负结果模型后重新表述为普遍提升。

## 13. 风险与控制

| 风险 | 影响 | 控制方法 |
|---|---|---|
| VLM 状态标签错误 | 错误缺口、错误辅助监督 | 结构化校验、人工复核、掩码和可靠性分析 |
| 折外或 `D_cal` 状态样本过少 | `e_s` 方差过大 | 向全局错误率收缩、合并状态，必要时扩大独立校准集 |
| 场景辅助导致捷径学习 | 总体或跨域性能下降 | 状态组消融，只用验证集决定是否保留 |
| 重复采样过强 | 对少数图片过拟合 | 权重上限、增强、记录有效样本暴露次数 |
| 多组随机对照成本高 | 训练量增加 | 先在两个骨干筛选，再冻结方法跨骨干验证 |
| 方法只对 dog 有效 | 通用性不足 | 第二阶段增加至少一个新类别及其独立状态协议 |
| 候选池没有关键状态 | 覆盖上限受限 | 报告候选池可达上限，不把不可达缺口归因于算法 |

## 14. 推荐的最小可执行版本

若先控制成本，建议按以下顺序实施：

1. 冻结交叉拟合折分；如果选择独立校准路线，则划出并冻结足量 `D_cal`；同时冻结所有 E0-E8 数据清单；
2. 人工复核 `D_state_test`、`gap300` 和一组 `random300`；如果使用独立 `D_cal`，同时复核该集合；
3. 先实现 ResNet-18 的掩码状态辅助头；
4. 运行 E0、E1、E3、E4、E5，判断基础 VSCAL 是否有信号；
5. 若 E5 相对 E3/E4 有正向结果，再实现 `p_s=d_s*e_s` 并运行 E6-E8；
6. 在 ConvNeXt-Tiny 上复验；
7. 冻结方法后扩展到 MaxViT-T 和 EfficientNetV2-S；
8. 最后增加多组随机 300 和更多训练种子，形成正式统计结果。

这里的停止条件很重要：如果 E5 在 ResNet-18 与 ConvNeXt-Tiny 上均没有改善稀有状态指标，应先检查标签、采样暴露次数和负迁移，不直接扩大到全部模型。

## 16. 最终推荐的论文主线

建议将论文主线确定为：

> 类别数量不能完整描述训练数据的充分性。本文使用可解释的对象内部视觉状态表示数据覆盖，识别状态缺口，并提出覆盖－效用对齐机制，将训练集缺口与验证集状态错误联合用于目标化数据选择、类内采样和辅助学习。本文分别评价覆盖改善、整体分类性能和稀有状态性能，从而检验视觉状态覆盖何时能够、何时不能转化为模型收益。

对应的贡献表述应保持为“提出并验证一种方法”，而不是“已经证明覆盖率越高模型越好”。只有完成 E0-E8 并获得相应证据后，才能把待验证假设升级为论文结论。
