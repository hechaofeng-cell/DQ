# 标签分歧敏感性：缓存分析方案

本轮仅复用B（COCO，2400）、C（VOC2007，600）及D（Objects365，2400）的双VLM标签和24份冻结预测；不新增标注、训练或人工复核。该分析在既有结果可见后制定，是事后敏感性，不升级为新的预注册确认。

问题：风险层性能落差、模型排序及原A薄弱状态方向对标签分歧有多敏感？先冻结下列规则，再计算新子集结果，不按保留率或差值调整门槛。

三组均输出：全体；risk_agree（身体可见性、遮挡、截断、朝向四个VLM风险字段均非unknown且值一致，程序尺度来自同一个框）；shared_agree（14个共享字段全部非unknown且值一致，多值字段按集合比较）。逐字段unknown/一致/分歧率保留，不只报告最有利来源。

风险层沿用各来源全池原中点五分位层，筛选后不重新划层。各组按类别、原风险层报告保留数量、面积比、H均值、未知率；不能将筛选组更好的总体性能解释为标注准确。主描述为原Q5减Q1 Macro-F1；若两层中任一类别少于5图，标记不可评价，不补样或改层。

每模型每种子保存风险差；汇总先平均种子再等权架构（本任务各架构均3种子，等价于24运行平均）。2000次类别/原层内源图重采样，保持每图跨24运行的相关性，区间条件于固定模型面板。对子集与全体差值用同一全池重采样再筛选，保留两者相关性；偶然缺某类别的重采样不计算，报告有效次数。模型排序只在所有类别支持充分时，以各架构三个种子的原Q5平均F1计算Kendall相关；描述性，不给新的优势检验。

薄弱状态仍沿用A冻结175条状态—模型组合：逐字段筛选双方非unknown且值一致的目标，而非要求14字段同时一致。在该字段一致子集内重新计算状态Recall和类别参考Recall；状态≥20且非该状态参考≥20才评价。同时在同一有足够支持的组合集合上重算全体结果，区分样本筛选与组合集合变动。记录原组合不可评价、方向改变及模型/状态支持量，不声称每条独立显著。此处不是错误因果验证。

全字段一致组过小时作为选择偏差/证据缺失结果保留。双VLM一致不等于真值，分歧组难度不同不能归因于标签错误。原主检验、主次家族、原状态支持门槛及全部不支持结果保持不变。

产物：样本级分组、逐字段对齐、类别/风险分布、逐运行指标、源图区间、排序变化、字段一致状态确认、两面板可编辑SVG与完整结果报告。复算脚本scripts/analyze_label_disagreement_sensitivity.py。输出artifacts/label_disagreement_sensitivity_20261005。
