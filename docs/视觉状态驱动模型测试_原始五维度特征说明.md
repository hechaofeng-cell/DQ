# 视觉状态驱动模型测试：原始五维度特征说明

围绕原始附件所定义的目标尺度、身体可见性、遮挡程度、截断程度和身体朝向五个维度，分别说明整体字段、相关局部细项及其状态取值。每个维度按“描述对象—字段—枚举状态”展开。五个整体字段用于第3.4节的风险评分，局部细项用于解释相应标注协议如何描述目标；是否参与当前分析由实际采用的共享字段集合决定。

| 维度 | 整体字段与含义 | 整体状态 | 相关细项与使用范围 |
|---|---|---|---|
| 目标尺度 | target_scale；官方目标框面积占原图面积的比例 | tiny、small、medium、large | 当前尺度字段由程序计算；独立头部协议另有head_scale，目标区域和分档不同。 |
| 身体可见性 | body_visibility；目标整体可见的完整程度 | full、most、partial、minimal、unknown | 相关协议另描述头部、腿部、尾部、面部及头发等局部的可见性；这些局部字段不直接加入当前风险评分。 |
| 遮挡程度 | occlusion_level；目标被其他可见物体挡住的程度 | none、light、moderate、heavy、unknown | 遮挡来源、遮挡部位；头发挡住面部属于特定头部协议中的遮挡来源。 |
| 截断程度 | truncation_level；目标因越过图像或裁剪边界而缺失的程度 | none、light、moderate、heavy、unknown | 截断身体部位；独立头部协议还区分上、下、左、右边界。 |
| 身体朝向 | body_orientation；目标整体相对于观察视角的方向 | front、back、left_side、right_side、three_quarter、overhead_or_unusual、unknown | 头部朝向；独立头部协议另区分水平转向、俯仰与倾斜。 |

## 目标尺度

目标尺度描述目标在原始场景中占据的相对面积。令aᵢ为官方目标框面积与原始图像面积之比，计算式为aᵢ=(目标框宽×目标框高)/(原图宽×原图高)。该量依据官方目标框和原图尺寸由程序计算，不依赖VLM对尺度的主观判断。

尺度分为四档：tiny表示aᵢ<0.01，small表示0.01≤aᵢ<0.03，medium表示0.03≤aᵢ<0.10，large表示aᵢ≥0.10；对应风险分值依次为3、2、1、0。这里的阈值描述原图中的面积占比，裁剪图被缩放为固定输入尺寸后，仍沿用原图尺度。

局部目标需要单独定义尺度区域。例如，独立head_face_v1.0协议定义head_scale，用于描述头部区域的尺度，取small、medium、large或unknown。它与当前完整目标的target_scale采用不同对象及分档，不能把完整目标的四档阈值直接套用于头部字段。相对面积也不直接等同于目标绝对像素数或图像清晰度。


## 身体可见性

身体可见性描述目标整体在图像中的可见完整程度。body_visibility取full（完整可见）、most（大部分可见）、partial（部分可见）、minimal（仅少量可见）或unknown（无法可靠判断）。犬、猫、马、羊和人的字段描述目标身体整体；车辆对应整辆车。风险映射为full／most取0，partial取2，minimal取3。

头部和肢体应在局部字段中分别描述。通用对象协议的head_visibility取clear、partial、not_visible、unknown，分别表示头部清楚可见、部分可见、不可见和无法判断；leg_visibility取all_expected、some、one、none、unknown，分别表示该类别通常应有的腿部均可见、部分腿部可见、仅一条可见、均不可见和无法判断。犬猫专用协议另有tail_visibility，记录尾巴清晰可见、部分可见或不可观察，并以独立字段记录尾巴姿态。

面部和头发也可以在相应专用协议中进一步细分。head_face_v1.0分别记录face_visibility、eye_visibility、nose_visibility和mouth_visibility；其中眼睛可见性区分双眼可见、仅左眼、仅右眼、均不可见和无法判断。hair_visibility取clear、partial、not_visible、unknown，记录头发清楚可见、部分可见、不可见和无法判断；hair_presence另区分有头发、光头或剃发、被覆盖和无法判断。

上述局部字段来自各自协议，不能由body_visibility自动推得，也不直接累加为当前身体可见性的风险分值。当前六分类共享分析保留body_visibility，未将这些头部、肢体、面部或头发局部字段纳入其15项状态矩阵。身体可见性描述可见结果，导致缺失的具体情况由遮挡与截断维度分别说明。


## 遮挡程度

遮挡程度描述目标被其他可见物体挡住的情况。occlusion_level取none、light、moderate、heavy或unknown，分别表示无、轻度、中度、重度遮挡或无法判断；已知等级对应0、1、2、3分。比如，栏杆挡住目标腿部或其他目标挡住其身体，属于遮挡。

遮挡来源由occluder_type进一步描述。当前共享协议的已知值包括none、person、same_class_object、other_object、vegetation、frame_or_structure、image_boundary和multiple，分别记录无、人、同类目标、其他物体、植被、框架或结构、图像边界及多种来源；该字段允许记录多个类型，none和unknown不能与其他值共存。image_boundary是现有词表保留值，边界造成的目标缺失仍由截断字段描述，不据此直接增加遮挡分值。

遮挡部位在犬猫专用协议中由occlusion_parts记录，包含head、torso、legs、tail、none和unknown，分别对应头部、躯干、腿部、尾巴、无和无法判断。独立头部协议的occluder_types还能记录口罩、眼镜、头发、手、物体和其他人物等来源。因此，“头发挡住面部”可作为遮挡来源，但“头发颜色”不属于遮挡程度。

当前风险评分只读取occlusion_level，不读取遮挡物类型或遮挡部位来追加分值。occluder_type仍是当前共享覆盖与条件评价字段；occlusion_parts及头部协议中的专用来源没有进入当前共享分析。不同协议的等级词表存在差异，犬猫专用协议的none／partial／heavy及独立头部协议的severe不能未经说明就替代当前评分词表。


## 截断程度

截断程度描述目标超出图像边界或裁剪边界，导致一部分未被完整呈现的情况。truncation_level取none、light、moderate、heavy或unknown，分别表示无、轻度、中度、重度截断或无法判断；对应风险分值为0、0.5、1、2。判断时结合原图与裁剪图，核对缺失是否来自边界。

通用对象协议的truncation_parts进一步记录none、head、torso、legs、tail_or_rear、multiple和unknown，分别对应无、头部、躯干、腿部、尾部或后部、多个部位和无法判断。犬猫专用协议采用tail表示尾部，其部位词表应按相应版本记录。独立头部协议的head_truncation_parts则区分top、left、right、bottom、multiple、none、unknown，描述头部在哪个边界方向缺失；head_completeness另记录完整、轻度截断、严重截断或无法判断。

例如，目标头部超出画面上边缘属于头部截断，头部被其他人物挡住属于头部遮挡。截断部位和边界方向提供更细的描述，但当前风险评分只读取truncation_level，当前共享状态矩阵也未保留truncation_parts。遮挡与截断可以同时发生，分别标注。


## 身体朝向

身体朝向描述目标整体相对于观察视角的方向。body_orientation取front、back、left_side、right_side、three_quarter、overhead_or_unusual或unknown，分别表示正向、背向、目标自身左侧、目标自身右侧、斜向、俯视或非常规视角及无法判断。front／left_side／right_side／three_quarter取0分，back取1分，overhead_or_unusual取2分。车辆的front和back分别指车头与车尾朝向镜头。

头部朝向可与身体朝向不同，需要在相应协议中独立记录。通用对象协议的head_orientation取front、back、left、right、up、down、unknown。独立头部协议进一步将观察方向拆分为yaw、pitch和roll：yaw记录正面、左／右斜向、左／右侧面及后向或面部缺失；pitch记录向上、水平或向下；roll记录直立、轻微倾斜或明显倾斜。各字段均保留unknown。

身体动作与朝向也分别定义。站立、坐姿、躺卧、行走和奔跑属于姿态或动作状态，不能直接转换成身体朝向分值。当前风险评分及共享状态矩阵使用body_orientation；头部朝向、头部三轴姿态及姿态动作字段未进入当前共享子集。左侧和右侧采用目标自身方位，不能仅根据目标位于画面左边或右边判断。

五维度之外的外观与场景字段仍按其原协议保留。人物头发颜色、长度、质地以及犬猫被毛颜色、图案、质地描述外观，不能强行归为尺度、可见性、遮挡、截断或朝向。头发可见性属于可见情况，头发挡住面部属于遮挡来源，头发颜色则是另一类属性。背景、模糊、照明等当前共享字段仍用于覆盖和条件评价，未加入五维风险分数。
上述五维度是当前风险组织的预定义子集，不表示已穷尽所有视觉特征。现有协议对身体可见性、遮挡程度和截断程度采用定性等级，未统一规定可见、遮挡或截断面积的比例阈值；中文释义不补造新的数值边界。unknown表示无法可靠判断，不能当作无遮挡、无截断或不可见。相关状态的覆盖处理与风险替代规则分别按第3.3和第3.4节执行。

## 五维评分汇总

| 维度 | 状态或区间 | 分值 |
|---|---|---|
| 尺度 | large / medium / small / tiny | 0 / 1 / 2 / 3 |
| 可见性 | full、most / partial / minimal | 0 / 2 / 3 |
| 遮挡 | none / light / moderate / heavy | 0 / 1 / 2 / 3 |
| 截断 | none / light / moderate / heavy | 0 / 0.5 / 1 / 2 |
| 朝向 | front、left_side、right_side、three_quarter / back / overhead_or_unusual | 0 / 1 / 2 |

五项直接求和，取值范围为0—13；unknown按该维度可能分值范围的中点处理，并记录未知维数。各维度最大值不同，直接求和具有隐含权重，不代表各维影响相同。
