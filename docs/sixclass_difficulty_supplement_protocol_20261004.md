# 六类难度分层补充分析

本分析由用户要求分层出结论后追加，属于已知主实验结果后的补充分析，不称为独立盲测或事前主实验。原六类双VLM四项主检验和全部负结果保持原样。

固定修订池2400目标、六类各400，24个冻结分类运行和两来源严格标签；不训练或再次调用VLM。使用六类共享字段构造五维视觉风险，延续原尺寸/可见性/遮挡/截断/朝向规则，但适配共有枚举。不给类别专属头部字段加分，不以分类错误、置信度或VLM可识别性定义风险。

| 维度 | 风险映射 |
|---|---|
| 原图框面积 | >=.10:0；[.03,.10):1；[.01,.03):2；<.01:3 |
| 身体可见性 | full/most:0；partial:2；minimal:3 |
| 遮挡 | none:0；light:1；moderate:2；heavy:3 |
| 截断 | none:0；light:0.5；moderate:1；heavy:2 |
| 朝向 | 常规前/侧/三分之四:0；back:1；overhead_or_unusual:2 |

H为五维之和，范围0–13。unknown不视为确定低风险：保存H下/上界，主分析未知维度采用区间中点，下/上界划层用于敏感性分析。未知率和同分边界另报。共有原图尺度不等于裁剪图绝对像素质量，H只称视觉风险代理。

每种来源独立在每类按H和sample_id升序分为Q1–Q5，每层80，六类同层共480。低/高仅指类别内相对风险，同分可能跨相邻层，不声称统一绝对难度门槛。每层贪心选20，边际凹状态收益延续此前各层的计数，最终每类100、总600。unknown不计覆盖，分母沿用完整双来源可行状态并集。状态字段和H输入同一VLM会有依赖，独立错误指标和跨源评价用于降低循环解释。

主要随机对照1000次：在同来源、同类别、同层内，严格匹配Coverage所选样本的(H,未知维数)频数，无放回抽取相同数量；控制比仅同层匹配更严格。新对照仅评价分层Coverage，不能替代原全池未分层强基线比较。原DeepGini、DSA、k-center结果在新论文中完整保留。

输出全层480目标分类曲线、每层120选样批次、累计120–600目标曲线、24运行和两来源模型排名、风险状态错误台账。六种来源×未知处理的Q5−Q1 Macro-F1比较为补充检验族，4项来源×等错误数指标的难度匹配随机比较为另一补充检验族，分别Holm校正。5000层级bootstrap和8架构为单位符号置换沿用原实现；CI不包含完整候选池重采样不确定性，不推断因果。

标签/计数/预测缺失、类别不均、累计覆盖下降、随机组风险频数不匹配或源哈希变化时停止。所有模型、来源、层和未知处理均报告，不按结果改分数/阈值，不要求F1单调下降。补充分析输入、代码和顺序在计算本轮模型指标前保存哈希。
