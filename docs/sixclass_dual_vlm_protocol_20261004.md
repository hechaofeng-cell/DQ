# 六类别线上／本地VLM对齐实验方案

本轮只研究状态标注来源对覆盖驱动测试的影响。六类为dog、cat、horse、sheep、person、car；每类400候选，训练每类300。分类模型沿用已完成的8个架构、3个种子，共24份冻结权重与2400目标预测，不再训练或调参。

## 1. 对齐与复用

每个目标固定原图、A框标记图、裁剪放大图、目标框、ID和真实类别。线上SenseNova 6.8 Flash Lite与本地Qwen3-VL 30B分别标注同一目标。原五类沿用object_state_v1.0的19字段，car沿用car_shared_state_v1.0的18字段；同一个类别在线上、本地使用相同schema与语义提示。主比较投影到14共享字段，加程序计算的目标尺度。全部原生字段保留。

已通过严格校验的本地五类2000张、线上五类200张与线上car400张复用，新增线上1800张、本地car400张。复用标签逐张核对三视图、ID与协议，保存源文件路径及哈希。已有标签来自不同日期，远端模型别名的历史版本不可完全控制；格式约束提示、重试及JSON传输机制与语义协议分别记录。

两个VLM均为自动标注来源，不作为人工真值。不进行人工复核或人为统一冲突标签。结构化成功率不代表语义正确率，一致率也不代表准确率。

## 2. 固定状态分母

各类别使用线上、本地在同一400目标上可行状态的并集，两个标注源的矩阵对齐到相同列。unknown不作为正向覆盖证据，单独报告。由此避免某个标注器漏掉状态后，覆盖分母缩小导致覆盖率虚高。跨类别报告宏平均，不将不同原生字段数直接混合。

## 3. 标注与选样差异

- 全14共享字段与原生字段：逐类别枚举一致率、Cohen kappa、集合字段精确一致率/Jaccard、unknown比例；退化kappa留空并说明。
- 各状态频数与差值，原生标签保留并按类别诊断。
- 按每类20、40、60、80、100张预算比较两种Coverage的集合重合率、Jaccard以及完整400样本排序相关。

## 4. 两选样来源×两评价来源

本地标签选样、线上标签选样分别在本地标签和线上标签下评价，形成2×2交叉表。同预算Random1000次、DeepGini、DSA、独立ViT k-center全部保留；这些基线的图片顺序和预测固定，只改变Coverage顺序和状态评价来源。

所有选择只使用状态或该基线预定分数，不使用分类错误真值筛选图片。分类错误只用于事后诊断。报告Accuracy、Macro-Precision、Macro-Recall、Macro-F1、逐类别指标、状态覆盖、失败状态广度和状态召回。

## 5. 独立诊断与统计检验

主要指标是各真实类别内分别匹配错误数量后的错误混淆类型广度、冻结分类表征错误簇广度。它们不使用VLM状态字段计算。错误簇由全池错误表征固定构造，0/1错误类别有明确定义，并保留在宏平均中。

主检验族包含本地Coverage相对Random两指标、线上Coverage相对Random两指标，共4项，统一Holm校正。统计单位为8个架构，3种子嵌套；架构级精确符号翻转检验和5000次层级bootstrap，不能把24次运行当作24个独立架构。预算AUC沿用原定义含预算0的零收益起点，报告归一化差值而非误称准确率百分比提升。

预定判定：两套标注的两项主要指标均为正且4项Holm p<0.05，才能说相对随机的独立诊断收益在本设置下跨标注源复现。其他情形报告部分支持、不稳定或不支持；不把未显著差异解释为等价。比较两来源收益差值，额外两项检验单独Holm校正。强基线比较全部报告，并提供全比较校正敏感性；car单类4项随机对比属于次要检验族，其余类别探索性报告。

## 6. 状态留出避免循环评价

预定5个不重叠组：尺度/可见性、朝向、遮挡/截断、场景/交互、图像质量/呈现。每次选样前移除一个组，只用剩余状态计算Coverage顺序，再使用另一VLM对留出组的标签评价。随机、DeepGini、DSA、k-center保持同预算。留出组失败广度与覆盖作为辅助结果，不替代不依赖状态标签的主要指标。

## 7. 模型排序与输出

在两来源Coverage测试集上分别按三种子平均Macro-F1排序，报告各预算Kendall相关及排名变动。排名仅限本测试选样和固定训练配置，不声称模型普遍优劣。

输出标注差异表、选样重合表、完整2×2指标、独立等错误数对照、跨来源留出指标、模型排名及可编辑SVG/PNG图。真实预算点保留，曲线插值只帮助阅读，不计作新增测量。
