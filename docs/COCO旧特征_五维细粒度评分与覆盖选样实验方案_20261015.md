# COCO旧特征上的五维细粒度评分与覆盖选样实验方案

日期：2026-10-15。

本方案按最新要求调整：先使用一个旧数据集，保留已有特征识别结果，将五维局部细粒度评分明确加入风险分层与覆盖选样；完成探索实验后，再在另外两个旧来源上复核。以下保留实验设计，末尾补充实际执行状态，不将旧合并池结果写成本轮新结果。

## 一、本轮要回答的问题

主问题：在旧COCO目标与旧VLM标注上，使用局部细粒度五维评分组织风险配额后，覆盖优先选样能否提高视觉状态支持，并揭示不同分类模型的条件差异？

分成两个可分别检验的问题：

1. 与整体五维评分相比，加入头部、腿部和头部朝向后的局部评分，是否更能区分模型错误与薄弱条件？
2. 在同一评分规则、相同风险配额内，覆盖优先选样是否比随机选样提供更多状态支持和等错误数混淆信息？

第一个问题检验评分方式，第二个问题检验选样方式。不能只比较两个同时改变评分与选样的集合，就把全部差异归因于细粒度评分。

## 二、数据范围与现有条件

### 2.1 先用COCO单源

本轮候选池使用已有COCO2017确认池：2400个固定目标，dog、cat、horse、sheep、person、car各400个。

目录：`/home/hcf/project/QE/artifacts/sixclass_independent_confirmation_20261004`。

后续保留VOC2007的600目标与Objects365的2400目标，分别运行，不与COCO合并后再声称是独立来源结果。OpenImages发现池不纳入本轮候选池。

分类输入仍为已有目标框裁剪图；类别真值来自官方目标标签。沿用本地VLM已保存的原生状态，不需要重新调用VLM，也不需要新增人工逐图核验。

## 三、完整流程

COCO已有目标与旧标注 → 逐字段映射风险值 → 类别适用的维内局部汇总 → 五维总分与未知区间 → 类别内Q1—Q5分层 → 共同风险格配额 → 三策略选样 → 复用分类预测 → 覆盖、评分区分度和模型条件报告。

视觉状态还直接用于覆盖统计。风险分与覆盖增益分别计算，二者不能互相换算；分类模型只在后续评价阶段提供预测。

## 四、五维细粒度评分：本轮的明确规则

### 4.1 五个维度与维内构成

各维度先归一化到0—1，再各贡献最多20分，总分为0—100分。

| 维度 | 非车：dog/cat/horse/sheep/person | car | 本轮细化程度 |
| --- | --- | --- | --- |
| 尺度 | 原图目标框面积占比 | 同左 | 使用原图几何尺度分级 |
| 可见性 | 头部可见性50%＋腿部可见性50% | 沿用整体身体可见性 | 非车从整体描述细化到两个局部字段 |
| 遮挡 | 已有整体遮挡等级 | 同左 | 使用旧标注的分级，不假装有逐部位遮挡程度 |
| 截断 | 已有整体截断等级 | 同左 | 使用旧标注的分级；截断部位保留用于条件分析 |
| 朝向 | 身体朝向50%＋头部朝向50% | 沿用车身朝向 | 非车从单一朝向细化到身体与头部 |

因此，本方案准确名称是“旧特征支持的五维局部细粒度评分”。五个维度均输出分值，但不是五个维度都拥有逐解剖部位的标注。

对车辆，不将可见车轮少直接解释为风险高：正常侧面视角也可能只见两个车轮。车辆颜色、可见部件等仍保留用于覆盖或条件报告，不为凑齐局部评分而临时赋风险。

### 4.2 逐字段映射

以下沿用现有`equal_parts`配置，不根据本轮模型结果调整分值。

| 字段 | 状态 → 归一化风险值 |
| --- | --- |
| 尺度，面积比a | a＜0.01→1；0.01≤a＜0.03→2/3；0.03≤a＜0.10→1/3；a≥0.10→0 |
| 头部可见性 | clear→0；partial→0.5；not_visible→1 |
| 腿部可见性 | all_expected→0；some→0.5；one→0.75；none→1 |
| 整体身体可见性，车辆及整体基线 | full/most→0；partial→2/3；minimal→1 |
| 遮挡程度 | none→0；light→1/3；moderate→2/3；heavy→1 |
| 截断程度 | none→0；light→0.25；moderate→0.5；heavy→1 |
| 身体朝向 | front/left_side/right_side/three_quarter→0；back→0.5；overhead_or_unusual→1 |
| 头部朝向 | front/left/right→0；back→0.5；up/down→1 |

这些是待实证检验的风险代理值，不是分类失败概率。可见性、遮挡、截断可能相关，因此相加不代表维度彼此独立。

### 4.3 五维合成公式

记f为上表的状态映射，非车目标的可见性与朝向为：

$$d_{\mathrm{vis}}(i)=\tfrac12 f(\mathrm{head\_visibility}_i)+\tfrac12 f(\mathrm{leg\_visibility}_i),$$

$$d_{\mathrm{ori}}(i)=\tfrac12 f(\mathrm{body\_orientation}_i)+\tfrac12 f(\mathrm{head\_orientation}_i).$$

其余维度分别由尺度、遮挡、截断对应映射得到。五维总分为：

$$H(i)=20\left[d_{\mathrm{scale}}(i)+d_{\mathrm{vis}}(i)+d_{\mathrm{occ}}(i)+d_{\mathrm{trunc}}(i)+d_{\mathrm{ori}}(i)\right].$$

不把整体可见性再加到“头部＋腿部”上，也不把整体朝向与同一身体朝向重复相加。整体方案和局部方案是替代评分，不是把两套分数叠加。

### 4.4 一个具体例子

假设某犬目标面积占比0.02，头部partial、腿部one、遮挡moderate、截断light、身体back、头部front，且以上值均已知：

| 维度 | 归一化值 | 对总分的贡献 |
| --- | ---: | ---: |
| 尺度 | 2/3 | 13.33 |
| 可见性 | (0.5＋0.75)/2＝0.625 | 12.50 |
| 遮挡 | 2/3 | 13.33 |
| 截断 | 0.25 | 5.00 |
| 朝向 | (0.5＋0)/2＝0.25 | 5.00 |
| 总分 | — | **49.17** |

这是规则演示，不是对真实样本或模型结果的报告。

### 4.5 unknown怎样处理

unknown/not_observable不直接赋确定的最高风险。对某维内权重为w的未知部件，其贡献保留为[0,w]，已知部件照常计算；维度及总分均输出下界、中点、上界。

例如，头部clear、腿部unknown，则可见性下界0、上界0.5、中点0.25，对总分的贡献为0—10分，中点5分。中点只用于排序，不表示真实风险的期望值。

主选样按中点排序，报告未知区间宽度与未知比例；评分效果另在整体/局部所需字段都已知的共同目标上比较，以检查差异是否主要来自未知处理。共同完整子集只用于补充评价，不替代主选样的2400目标候选池。

## 五、覆盖如何与细粒度评分结合

### 5.1 主覆盖口径保持不变

为了区分“风险评分变化”和“覆盖字典变化”，主覆盖仍使用旧共享15字段口径、每类71状态、六类426个类别—状态单位，τ＝20，先类内平均再六类宏平均。

同时补充“局部评分字段状态支持表”，检查入选目标中头部可见性、腿部可见性和头部朝向的分布。该表单独报告，不把新加字段悄悄塞进原71状态分母。

如需汇总局部字段覆盖，按各类别适用的预设枚举单独定义分母，并对整体/局部评分方案使用同一字典；不能只在局部方案中使用更丰富词表。

### 5.2 在COCO内部重新分层

对整体评分与局部评分分别处理。每个类别有400个目标，各自按该评分的风险中点与sample_id排序，得到五层，每层80个。

不能复用7800合并池的层号，也不能在局部方案中沿用整体方案的层号。只有重新分层，才能评价局部评分如何改变测试组织。

### 5.3 主预算与三策略

主展示每类选200个，共1200个。风险约束组每类Q1—Q5各40个。

| 策略 | 选样规则 |
| --- | --- |
| Coverage | 每类400中选200，不限制风险层；按旧词表的稀缺状态增益选择 |
| RiskRandom | 使用相应评分的风险层与风险格配额，无放回随机抽样，重复1000次 |
| RiskCoverage | 使用与RiskRandom完全相同的配额，在可行候选中选择覆盖增益最大者 |

共同风险格定义为“类别内风险层＋风险中点分数＋未知区间宽度”。每层40个名额按格内候选数比例用最大余数法分配。匹配中点与宽度也就匹配了总分上下界，但不保证各维度组合完全一致。

联合选样时，从所有仍有名额的风险格中选择当前增益最大者，同分按sample_id；更新该类别全部已选样本的状态支持，直到选满。状态支持不按层清零，零增益阶段也按相同预算结束。

覆盖增益沿用对未饱和状态的对数边际增益之和：log(n＋2)−log(n＋1)，n＜20时计入，n≥20时不再贡献。

### 5.4 为检验细粒度评分，共需要五种独立结果

| 编号 | 评分 | 选样 | 用途 |
| --- | --- | --- | --- |
| E0 | 不依赖风险评分 | Coverage | 共享的无风险约束覆盖参考 |
| E1 | 五维等权整体equal_global | RiskRandom | 整体评分随机参考 |
| E2 | 五维等权整体equal_global | RiskCoverage | 整体评分＋覆盖 |
| E3 | 五维等权局部equal_parts | RiskRandom | 局部评分随机参考 |
| E4 | 五维等权局部equal_parts | RiskCoverage | 本轮完整方案 |

比较E4−E3验证局部评分配额下的覆盖选样；E2−E1提供整体评分下的对应比较。结合完整候选池上的评分区分度及两对增量，分析局部评分是否带来额外价值。

不能仅凭E4的错误数高于E2就断言局部评分更好，两者可能选中了不同难度与未知构成。E0在两套评分下是同一集合，不重复算成两个独立实验。

## 六、模型与评价

### 6.1 沿用现有模型预测

使用已有ResNet-18、ResNet-50、MobileNetV3-Small、MobileNetV3-Large、DenseNet-121、EfficientNet-B0、ConvNeXt-Tiny、Swin-T，每架构三个种子。

本轮不训练新模型。先按状态与风险规则选样，再按目标ID核对并读取已有预测。24组模型预测与1000次随机选样是两类不同的重复，分别汇总。

### 6.2 三类结果分开报告

| 结果线 | 主要指标 | 说明 |
| --- | --- | --- |
| 评分有效性 | 完整COCO池的类别宏平均错误AUROC；Q5−Q1错误率差；同模型同类别整体/局部配对差 | 风险评分是否真的对应模型失误差异，不能只看分值本身 |
| 覆盖充分性 | 出现覆盖、支持覆盖、局部评分字段支持量、实际风险与未知分布 | 选样是否带来更多状态证据 |
| 模型诊断价值 | 逐模型Macro-F1、类别Recall、风险层Recall、状态条件Recall、等错误数混淆广度差 | 是否揭示模型之间的差异及更多类别混淆 |

错误AUROC中错误为正类，风险越高应越倾向错误；只存在正确或只存在错误时不可评价。Q5−Q1错误率差为正只说明端点区分，不要求中间层单调。

等错误数混淆广度在同模型、种子、真实类别下配对控制错误数量后计算；它反映错误预测类别的种类，不代表独立错误根因数量。错误数为0的类别单列可评价情况。

不把分层后F1下降说成模型训练效果变化。八个模型与所有种子都保留，不只选正向模型。

## 七、实施步骤与需要改的代码

### 阶段A：旧标注重评分

读取COCO2400条原生标注，复用已有score_sample，分别计算equal_global与equal_parts，导出逐字段风险值、维内权重、五维上下界与总分。先核对若干规则算例，再处理全量，不调用VLM。

这一核心评分函数与映射已经存在，但旧先导报告使用的池不等于本轮COCO候选池，不能直接搬用其分数汇总作为新结果。

### 阶段B：新增COCO单源选样入口

沿用已实现的贪心与最大余数法，适配本轮COCO400目标/类、两种评分和五种结果。输出新目录，不覆盖旧选样。

**必须修改旧实现的一个假设：**旧三策略脚本通过“分数区间宽度÷20，再取整”推导未知维数，并断言区间宽度为20的整数倍。局部评分的半权重未知部件可产生10分宽度，不能这样推导。本轮直接保存未知部件/权重信息，并以实际区间宽度构建风险格，不使用该取整规则。

旧脚本还写死每类1300个候选及合并池路径，不能直接原样运行到COCO池。需要单源适配，不是简单替换一个评分名称即可完成。

### 阶段C：复用预测并生成报告

检查COCO目标ID、真值、目标框裁剪与已有预测一一对应，计算评分区分度、五集合模型指标与等错误数混淆差，补齐风险层和局部条件支持报告。

随机选择先对1000次汇总，模型内再汇总三个种子；跨模型主要展示八个架构的配对方向和效应大小。若做架构级检验，应事先列出主比较与校正家族，不能在查看结果后删比较或缩小家族。

### 阶段D：决定是否扩展来源

先检查候选数、评分映射、配额、未知区间及预测绑定是否正确，再判断评分和选样是否有实证收益。若只有部分模型或类别改善，按条件报告；若没有改善，先区分实现问题与方法未获支持，不反复调权重直到出现好结果。

后续沿用同一规则分别进入VOC2007、Objects365，不合并来源再冒充独立实验。VOC每类只有100个，不能沿用每类200的主预算；跨三源比较可预设共同每类40、80的补充预算，分别在各源内部重新分层与分配风险格名额。

现有池已经做过多次研究分析，本轮定位为新评分—选样组合的探索与跨源复核，不称从未接触数据的全新盲测。

## 八、什么结果可以形成结论

| 观察 | 允许的解释 |
| --- | --- |
| 局部评分区分度高于整体，但覆盖选样增量不明显 | 支持评分在该设置的作用，未支持额外选样收益 |
| E4支持覆盖提高，等错误数广度未提高 | 覆盖改善成立，额外混淆诊断价值尚未得到支持 |
| E4−E3稳定正向，但整体/局部评分区分度持平 | 覆盖选样有收益，不能归功于局部评分更强 |
| 局部评分与覆盖选样两项均改善，且跨模型/来源保持方向 | 支持完整方法在这些条件下的测试组织价值，仍需报告不确定性 |
| 部分维度、模型、类别下降 | 保留下降与边界，不宣称普遍优越 |

本方案不预设局部评分一定更好。已有缓存先导显示局部方案的收益并不一致，因此本轮保留等权整体对照，不能把“更细”当成“更有效”的证据。
