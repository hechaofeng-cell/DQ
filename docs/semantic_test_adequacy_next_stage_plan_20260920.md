# 类别内部视觉状态测试充分性：下一阶段详细实验方案

日期：2026-09-20

## 1. 研究目标

本阶段不重新训练分类器，也不把压力测试集上的低 F1 解释为模型性能下降。研究对象保持为已经冻结的 D300 五分类模型：

- 8 种架构；
- 每种架构 3 个训练种子；
- 共 24 个冻结模型；
- dog、cat、horse、sheep、person 五分类；
- 测试输入为固定目标框裁剪图。

需要回答的核心问题是：

> 在相同测试预算下，基于类别内部、可解释视觉状态的选样方法，是否比随机、不确定性、模型行为距离和通用图像嵌入多样性方法发现更广泛的模型失败状态？

这里的“更好”主要指诊断充分性，不指测试集上的 F1 更高。

## 2. 研究问题与预注册假设

### RQ1：覆盖效率

在预算 `b ∈ {20, 40, 60, 80, 100}` 下，视觉状态覆盖方法是否覆盖更多预定义状态？

- H1：Coverage 的频次覆盖率和存在覆盖率高于 Random、DeepGini、DSA 和 k-center。
- 该问题检验方法是否完成了其直接目标，但不能单独证明测试有效。

### RQ2：失败状态发现

视觉状态覆盖方法是否能发现更多种类的状态相关失败？

- H2：Coverage 的失败状态广度曲线 AUC 高于各基线。
- 这是本阶段的主要假设和主要终点。

### RQ3：错误发现

视觉状态覆盖是否带来更高的错误样本发现率？

- H3：Coverage 可能在中高预算下提高目标类别错误发现率，但不要求其随覆盖单调上升。
- 错误率、错误数和 F1 均作为辅助终点，不作为方法成立的必要条件。

### RQ4：标签可靠性

VLM 生成的 cat 状态标签是否足以支持覆盖分析？

- H4：人工标注者之间具有较高一致性，且 VLM 与最终裁决标签之间具有可量化的一致性。
- 若关键特征一致性不足，则先修订 `cat_v1.0`，再重跑所有 cat 选样结果。

### RQ5：跨类别复现

覆盖效率和失败状态发现结果能否在第三个类别复现？

- 候选第三类为 person。
- 依据现有 24 个模型在原始 100 张候选上的只读统计，person 平均错误率为 19.33%，高于 sheep 6.88%、horse 5.79% 和 cat 3.13%。
- 该统计只能用于选择研究类别，不能用于挑选具体 person 样本。

## 3. 固定实验对象

### 3.1 不变项

以下内容在整个实验中冻结：

- D300 训练集及验证集；
- 24 个模型权重；
- 图像裁剪、缩放和归一化；
- 五分类标签空间；
- dog 和 cat 各自的 200 张候选池；
- 每类测试预算 `20/40/60/80/100`；
- 每个实验中四个非目标类别的样本及排列；
- `dog_v3.1` 和经人工复核后的 `cat_v1.0` 状态定义；
- 覆盖上限 `cap=30`；
- 所有方法均输出嵌套排序，前 20 张必须是前 40 张的子集，以此类推。

### 3.2 唯一变化项

同一目标类别实验中，只改变目标类别 200 张候选的排序方法。任何方法都不能改变非目标类样本、模型权重或推理配置。

## 4. 五种同预算选择方法

### 4.1 Coverage：本文方法

使用当前贪心边际覆盖排序。设样本 `x` 的状态向量为 `z(x)`，当前每个状态累计次数为 `n_s`，每一步选择能够为尚未达到 `cap` 的状态带来最大新增贡献的样本：

```text
score_cov(x) = Σ_s 1[z_s(x)=1] · 1[n_s < cap]
```

并列时使用固定 `sample_id` 排序，保证完全可复现。该方法不读取任何被测模型的预测、概率或错误标签。

### 4.2 Random：简单控制组

- 保留当前 1000 条固定随机种子的嵌套排列；
- 每个预算从同一排列截取前 `b` 张；
- 随机组用于构造经验零分布和抽样区间；
- 1000 个随机排列不是 1000 个独立模型实验，统计时不得扩张样本量。

### 4.3 DeepGini：模型不确定性基线

对每一个冻结模型分别计算：

```text
score_DG(x) = 1 - Σ_c p(c|x)^2
```

按分数从高到低形成嵌套排序。DeepGini 使用模型输出但不使用真实正确/错误结果。由于不同模型的概率不同，因此每个模型拥有自己的 DeepGini 排序。

附加敏感性分析可加入：

- 最低最大软概率：`1 - max_c p(c|x)`；
- 预测熵：`-Σ_c p(c|x) log p(c|x)`。

论文主表只保留 DeepGini，另外两项放入附录，避免重复基线过多。

### 4.4 DSA：Surprise Adequacy 基线

对每个冻结模型提取分类头之前的最后一层特征。以 D300 训练样本为参考集，对候选样本 `x`：

1. 使用模型预测类别 `c`；
2. 找到参考集中类别 `c` 的最近特征 `x_a`；
3. 找到与 `x_a` 类别不同的最近特征 `x_b`；
4. 计算：

```text
DSA(x) = ||h(x)-h(x_a)||2 / ||h(x_a)-h(x_b)||2
```

按 DSA 从高到低排序。参考特征只来自固定 D300 训练集。不得使用候选样本的正确/错误标签调节层、距离或排序方向。

在正式运行前，只允许用一个模型和 20 张样本做数值稳定性 smoke test。若某架构最后特征维度不同，统一使用其分类头输入特征，不做针对结果的逐模型选层。

### 4.5 图像嵌入 k-center：模型无关多样性基线

使用同一个冻结的通用视觉编码器为 200 张目标候选生成 L2 归一化嵌入。推荐固定为 DINOv2 ViT-S/14；若本地环境无法稳定复现，则在协议冻结前统一改为一个 ImageNet 预训练编码器，所有类别共用，不能根据结果分别选择编码器。

使用确定性的 farthest-first k-center：

1. 第一张选择离候选池几何中心最近的样本；
2. 后续选择与已选集合最小余弦距离最大的样本；
3. 并列时按 `sample_id`；
4. 一次生成 200 张完整嵌套顺序。

该基线回答“通用视觉多样性是否已经足够”，不读取类别状态标签或被测模型输出。

## 5. cat 人工复核与双人标注

### 5.1 全量单人复核

标注员 A 独立复核全部 200 张 cat：

- 同时查看原图、目标框标记图和裁剪图；
- 不显示 VLM 原标签、Coverage 排名、模型预测或模型是否出错；
- 按 `cat_v1.0` 逐项填写 23 个特征；
- 保存每次修改、时间戳、标注员 ID 和备注；
- 不确定时只能使用协议允许的 `unknown/not_visible/not_observable`，不得推断品种、身份、健康或性格。

### 5.2 双人独立标注子集

从 200 张中预先抽取 80 张，约占 40%，由标注员 B 独立标注。抽样必须在查看一致性结果之前冻结，并按以下因素分层：

- 40 张普通池、40 张困难池；
- Coverage 排名四分位各 20 张；
- 遮挡、截断、unknown 较多样本均有代表；
- 不按模型错误与否抽样。

标注员 B 同样看不到 VLM、标注员 A 和模型结果。

### 5.3 一致性指标

对普通枚举特征报告：

- 原始一致率；
- Cohen's kappa；
- Gwet's AC1，作为类别极不平衡时的稳健补充。

对 `occlusion_parts` 和 `truncation_parts` 这类集合特征，将每个允许部位展开为二元标签，报告：

- 每状态一致率；
- 宏平均 AC1；
- 样本级 Jaccard 相似度。

另外报告：

- 23 项特征的宏平均一致性；
- 单张样本 23 项完全一致率；
- VLM 与裁决标签的一致率和修正率；
- 每个特征的 unknown 使用率。

### 5.4 裁决与冻结

- 两人不一致的 80 张由第三方或两人共同复核裁决；
- 其余 120 张以标注员 A 的盲标结果为人工金标；
- 若某关键特征 `AC1 < 0.67`，必须先澄清规则并对涉及该特征的 200 张重新复核；
- `0.67 ≤ AC1 < 0.80` 时保留但在论文中列为中等可靠特征，并做去除该特征的敏感性分析；
- `AC1 ≥ 0.80` 视为可支持主分析；
- 最终生成不可再修改的 `cat_v1.0_human_frozen.csv`、标注指南版本号和 SHA-256。

阈值是本项目预先设定的操作规则，不应描述为普遍适用的统计定律。

## 6. 主要和辅助指标

### 6.1 主要指标：失败状态广度

对目标类别、模型 `m`、方法 `q`、预算 `b`，定义：

```text
FSB(m,q,b) = |{s : 至少一张包含状态 s 的入选样本被模型 m 错分}|
```

同时报告归一化版本：

```text
NFSB(m,q,b) = FSB(m,q,b) / 已选测试集中实际出现的状态数
```

主要统计量不是单独选择某个预算，而是整条曲线的标准化面积：

```text
AUC_FSB = trapezoid(FSB at 20,40,60,80,100) / 最大可能面积
```

这样可以避免看到 80 张结果最好后才把 80 设成主终点。

### 6.2 次要诊断指标

- 失败样本数；
- 目标类别错误率；
- 所有类别错误率；
- 失败状态比例；
- 状态宏平均 Recall；
- worst-5 状态 Recall；
- 不同失败状态组合的数量；
- 每发现一个失败状态所需样本数；
- 频次覆盖率与存在覆盖率。

### 6.3 性能指标的解释边界

- Accuracy、Macro-F1、目标类 F1 和 Recall 继续报告；
- 在冻结模型实验中，F1 较低只表示该选择方法构造了更强的压力测试集；
- 它不表示模型训练后性能退化；
- 该测试集不是部署分布的随机样本，因此不能用其 F1 估计真实总体性能。

## 7. 置信区间、效应量和统计检验

### 7.1 独立性单位

有效的模型重复单位是 24 个 `architecture × seed` 运行，但 3 个 seed 嵌套于同一架构。预算点是同一排序的重复测量。1000 条随机序列只描述随机选样的不确定性，不作为额外模型样本。

### 7.2 主检验

对 dog 和 cat 分别计算每个模型运行的 `AUC_FSB`，然后比较 Coverage 与四个基线：

- Coverage vs Random；
- Coverage vs DeepGini；
- Coverage vs DSA；
- Coverage vs k-center。

报告：

- 配对均值差和中位数差；
- 95% 分层 bootstrap 置信区间；
- 配对标准化效应量 `dz`；
- 配对秩二列相关，作为非参数效应量；
- 双侧配对置换检验 p 值；
- 四个主要比较使用 Holm 校正。

分层 bootstrap 共 10,000 次：先重采样架构，再在架构内重采样 seed；与 Random 比较时，每次 bootstrap 再从 1000 条随机排列中抽取一条，传播随机选样波动。

### 7.3 各预算分析

五个预算点上的 FSB、NFSB 和目标类别错误率属于次要分析：

- 报告配对差和 95% 置信区间；
- 每个指标内对 `4 个比较 × 5 个预算` 使用 Holm 校正；
- 不以某个未经预注册的单点显著结果替代主 AUC 结果；
- 同时报告 24 个模型运行中差值为正、为零、为负的数量。

### 7.4 跨模型混合效应分析

建立一个预先固定的混合效应模型解释整条曲线：

```text
FSB ~ method * budget_scaled * category
      + (1 + budget_scaled | architecture)
      + (1 | architecture:seed)
```

- `method`、预算和类别为固定效应；
- 架构具有随机截距和预算随机斜率；
- seed 嵌套在架构内；
- FSB 为计数，优先使用负二项 GLMM；若不收敛，则使用带稳健标准误的线性混合模型分析标准化 FSB；
- 不根据显著性反复更换模型族；任何降级方案都需写入日志。

主要关注：

- `Coverage × budget`：覆盖法的诊断优势是否随预算变化；
- `Coverage × category`：效果是否依赖类别；
- 三阶交互：dog 与 cat 的预算响应形态是否不同。

混合效应模型用于总体解释，不替代预注册的配对 AUC 主检验。

## 8. 第三类别 person 复现实验

### 8.1 为什么选择 person

现有固定模型在原始候选上的平均错误率约为 19.33%，明显高于其他未复现类别，更有机会检验失败状态发现能力。该选择在扩充候选池和定义状态协议之前冻结。

### 8.2 候选池构造

- 保留 Open Images test 中现有 100 张 person；
- 从与训练集无重叠的外部/独立 test 数据中增加 100 张 person；
- 总计 200 张 person 候选；
- dog、cat、horse、sheep 各固定 100 张；
- 检查 image ID、SHA-256、感知哈希和近重复；
- 明确排除非真实人物目标、严重框错和无法确认类别的样本；
- 新增 100 张的抽样仅使用元数据分层，例如小目标、遮挡、截断、动作和场景，不读取24个模型的错误结果。

### 8.3 person 状态协议原则

建立 `person_v1.0`，仍控制在约 20 至 25 项可观察特征。优先包括：

- 目标尺度、单人/多人上下文；
- 头部、躯干、手臂和腿部可见性；
- 身体与头部朝向；
- 站、坐、躺、走、跑、骑乘、交互等姿态动作；
- 遮挡程度与部位；
- 截断程度与部位；
- 目标可识别性；
- 室内外和场景类型。

不标注或推断种族、民族、健康、残障、性格、身份等敏感或不可见属性。年龄、性别等人口属性不进入当前覆盖指标，以免将伦理风险和识别偏差混入主要方法验证。

### 8.4 运行方式

person 完全复用 dog/cat 的五方法、五预算、24 个冻结模型和统计代码。person 的状态协议和人工抽查必须在模型结果分析前冻结。

若资源有限，先做 person 的 200 张特征标注和 20/60/100 三个预算 smoke analysis；只有数据和指标检查通过后，再补齐 40/80 并纳入正式联合统计。正式论文仍必须报告完整的五预算结果。

## 9. 执行顺序

### 阶段 A：冻结协议

1. 保存当前 dog/cat 候选清单、模型清单和所有输入哈希；
2. 冻结五种选样方法、五个预算、主终点与统计方法；
3. 在查看新增基线结果之前写入 `protocol.json`；
4. 所有后续修改追加版本，不覆盖原协议。

### 阶段 B：cat 标签可靠性

1. 生成盲标界面和 200 张标注任务；
2. 冻结 80 张双标子集；
3. 完成 A 全量标注和 B 独立标注；
4. 计算一致性并裁决；
5. 冻结人工版 cat 标签；
6. 重新生成 cat Coverage 排序和现有结果。

### 阶段 C：新增三个强基线

1. 从现有概率 CSV 直接生成 DeepGini 排序；
2. 提取训练集和候选集的最后层特征，生成 DSA 排序；
3. 一次性提取通用视觉嵌入，生成 k-center 排序；
4. 检查每种排序恰好包含 200 个唯一 ID 且预算嵌套；
5. 复用已有候选预测，无需再次运行分类器；
6. 聚合所有方法的五预算指标。

### 阶段 D：统计分析

1. 计算每个模型运行、方法、预算、类别的 FSB/NFSB 和错误指标；
2. 计算 AUC；
3. 运行分层 bootstrap、配对置换检验和效应量；
4. 运行混合效应模型；
5. 输出完整结果，不筛除结果不理想的模型或类别；
6. 生成主图和附录表。

### 阶段 E：person 独立复现

1. 扩充并清洁 person 候选池；
2. 冻结 `person_v1.0`；
3. VLM 标注加人工质量控制；
4. 运行五方法和五预算；
5. 加入三类别联合模型；
6. 只在全部结果完成后确定最终论文措辞。

## 11. 结果判定与论文措辞

### 强支持

若 Coverage 的 AUC-FSB 显著高于 Random 和至少两个强基线，并在至少两个类别方向一致，可以写：

> 在固定模型和相同测试预算下，显式类别内部视觉状态覆盖能够比随机及若干模型/嵌入驱动基线发现更广泛的状态相关失败。

### 部分支持

若 Coverage 始终提高状态覆盖，但 FSB 只在部分类别或预算占优，应写：

> 显式状态覆盖稳定改善测试输入的语义充分性，但其故障发现收益受类别、基础错误率和预算影响。

### 不支持诊断优势

若 Coverage 不能超过 DeepGini、DSA 或 k-center：

> 当前状态覆盖指标适合描述可解释的输入充分性，但没有证据表明其在故障发现方面优于现有测试选择方法。

该结果仍可保留为覆盖指标和边界分析，但不能将方法宣传为更有效的错误发现算法。
