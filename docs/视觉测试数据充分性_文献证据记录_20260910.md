## 检索范围与取舍

以 QE 项目任务说明为范围，检索测试充分性、输入分布、可解释特征、语义场景、需求驱动测试、错误切片、视觉语言幻觉和测试优先级。先从 IDC、TEASMA、属性覆盖和 Dataset Characterization 扩展；检查作者实验室工作时补入 CIT4DNN、S3C、RBT4DNN；随后纳入 DeepHyperion、Domino、LADDER，以及工具和简单基线。

检索也发现 Coverage-Guided Testing 综合综述（arXiv:2507.00496）、ADEPT（arXiv:2608.12144）和 Clotho（arXiv:2509.17314）。它们分别偏综述、工程集成和 LLM 输入测试，为使20篇名额集中于视觉方向与直接比较方法，未列入正式20篇。未纳入不代表质量差或无后续阅读价值。最终停止于主要方法类别已稳定、新增发现不再改变本轮核心定位；不声称检索穷尽。
