# Dog 正样本试验验收规则 v1

本阶段只验证固定 A 框中的 dog 是否能被识别，并统计犬类特征的可观察性。全部样本都是真实 dog，因此 `predicted_class=dog` 报告为 dog 识别命中率（等价于该正样本集合上的召回率），不称为通用分类准确率，也不评价假阳性率。

## 工程门槛

- 特征响应可解析率至少 99%。
- 整条响应严格符合协议的比例至少 90%。
- 每个字段出现率至少 98%。
- 每个字段枚举合法率至少 90%；95%以上为结构通过，90%-95%为警告。
- 分类响应率为 100%。
- Dog 识别命中率至少 90%。

## Unknown 规则

`unknown` 是合法的可观察性结果，不是失败，不得自动填补。`tail_position` 为条件可观察字段：只有尾巴可见时才评价位置；尾巴不可见导致的高 unknown 率只报告可观察率，不阻止试验通过。其他字段 unknown 超过 50%时标记低可观察性，但不等同于格式失败。

人工复核不是工程验收前置条件。若要声称某个特征值是正确真值，或报告模型与人工一致率，仍需独立人工标注。
