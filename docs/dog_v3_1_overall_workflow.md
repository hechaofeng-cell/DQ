# 犬类 v3.1 特征覆盖驱动数据集构建流程

![犬类数据集构建整体流程图](/home/hcf/project/QE/output/imagegen/dog_v3_1_workflow_zh_polished.png)

## 1. 流程概览

本流程以 COCO dog 图片为基础，先对固定500张初始数据集进行犬类视觉特征标注，再对400张候选池使用完全相同的 v3.1 schema 和提示词进行标注。程序根据初始数据的低频状态计算缺口，从候选池中选择100张最有补充价值的图片，最终形成清洁的596张犬类数据集。

流程的核心不是追求每个枚举状态达到100%，而是：

1. 固定一个可复现的犬类目标和输入协议；
2. 使用有限枚举和严格校验获得结构化特征；
3. 统计状态分布并识别缺失、稀疏和偏少状态；
4. 用缺口驱动候选图片选择；
5. 保留原始响应、哈希和人工复核记录；
6. 在不覆盖历史版本的情况下冻结正式数据集。

## 2. 六个阶段

### 阶段1：COCO数据源

- 初始数据集：500张；
- 候选池：400张；
- 每张图片由 COCO 标注程序固定一个面积最大的 dog 目标作为 A 目标；
- COCO 类别编号16表示 dog；
- 原始500张和候选400张始终分别保存。

### 阶段2：固定目标和三种输入

每张图片生成三种输入：

- 原图；
- 带 A 框的标记图；
- 未标记原图裁剪并放大的目标图。

裁剪放大只改善查看尺寸，不增加原始图像信息。目标框、目标面积、中心位置和画面边界由程序计算，不由模型选择。

### 阶段3：本地 Qwen VLM 标注

使用本地 `qwen3-vl:30b-a3b-instruct`，GPU运行，协议为 `dog_v3.1`。每张图片输出23项犬类特征：

- 毛发；
- 头部和面部；
- 身体与姿态动作；
- 遮挡与截断；
- 犬体可识别性和场景。

每个字段使用固定枚举，无法判断时使用 `unknown`。遮挡部位和截断部位使用数组。原始模型响应和解析结果分别保存。

### 阶段4：严格校验和分布分析

程序检查：

- JSON结构；
- 字段完整性；
- 枚举值合法性；
- 多选数组合法性；
- 部位字段互斥值；
- 嘴部、尾巴和可识别性依赖规则；
- image_id和target_instance_id一致性。

500张初始数据和400张候选数据的 v3.1 严格成功率均为100%。

对每个字段统计状态数量、比例、unknown率，并将非 `unknown`、非 `other` 的状态划分为：

- missing：数量为0；
- sparse：少于10张；
- weak：10至29张；
- covered：至少30张。

### 阶段5：缺口驱动选择

500张初始数据的 v3.1 分析得到：

- 可评价状态：123个；
- 初始覆盖指数：78.64%；
- 低频状态：45个；
- 候选池有效图片：396张；
- 选中补图：100张。

选择时排除4张已知非真实犬候选，并保持五类分层约束：

- tiny_target；
- small_target；
- multiple_dogs；
- boundary_target；
- person_cooccurrence。

每个分层选中15至30张，优先选择能覆盖初始缺口的图片。

### 阶段6：清洁发布和冻结

500张初始数据加100张补图形成600张原始合并集。原始500张中有4张犬形玩偶、雕像或其他非真实犬表现形式，因此正式清洁集为596张：

```text
500 + 100 - 4 = 596
```

清洁集结果：

- 严格特征成功率：100%；
- 覆盖指数：84.17%；
- 相比初始500张提升：5.53个百分点；
- 剩余低频状态：33个；
- 完全缺失状态：7个；
- 稀疏状态：10个；
- 偏少状态：16个。

## 3. 评价指标说明

### 严格特征成功率

```text
feature_status=ok的图片数 / 图片总数
```

它评价的是输出格式和字段是否合法，不是视觉识别准确率。

### 特征状态覆盖指数

```text
mean(min(状态数量 / 30, 1))
```

计算时排除 `unknown` 和 `other`。达到30张后，该状态不再继续增加覆盖分数。

### unknown率

```text
某字段unknown数量 / 数据集图片数
```

unknown不一定表示模型失败。例如尾巴未出现在画面中时，`tail_visibility=not_observable`，`tail_posture=unknown` 是符合协议的结果。

## 5. 结论边界

该流程支持以下结论：

- 缺口驱动选择在当前候选池和固定预算下提高了特征状态覆盖；
- v3.1协议可对900张图片产生100%严格成功的结构化输出；
- 596张清洁集的特征覆盖指数为84.17%。

该流程不支持以下结论：

- 特征覆盖指数等于犬类识别准确率；
- 补图后模型识别性能一定提高；
- 所有特征都经过人工验证；
- dog案例可以直接证明方法对其他类别同样有效。

如果论文需要识别性能结果，还需要对补图后的图片运行独立分类VLM，并保留一个未参与规则调整的独立验证集。
