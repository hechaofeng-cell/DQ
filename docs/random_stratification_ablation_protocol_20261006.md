# 随机分层与五维风险消融补强协议

本轮在历史结果已知后设计、在本轮新增统计前保存，属于事后缓存补充；不声称项目初始预注册。用户授权完成三池随机分层、Objects365删维消融及论文整合。复用B/COCO2400、C/VOC2007 600、D/Objects3652400目标，六类相等，24份既有预测及两套状态标签不变。无新训练、分类推理、VLM调用或人工复核。

## 随机划层对照

各池在每个类别内独立均匀随机排列全部目标，然后连续等分为五层。每类层大小B/D=80、C=20，总层大小480/120，与原完整风险层相同。所有目标每次恰好进入一层；所有24模型和两个标注来源共享同一随机划层。随机划层不读取预测、风险分数或错误，不能与已存在的层内随机选样混称。

正式重复10000次，池种子依次2026100611、2026100612、2026100613。保存完整排列（int16）、全部运行五层Macro-F1和六类Recall。两套VLM不改变该随机对照，因此共享池内随机分布，而非复制成两份独立样本。

主统计量T为先平均每架构三个种子、再平均八架构的Q5−Q1 Macro-F1差。原评分观测T重新从预测与冻结层身份计算，并与原完整层结果逐运行核对。随机分布报告均值、标准差、2.5/97.5百分位及极端次数。两侧Monte Carlo p=(1+#(|T_random|>=|T_observed|))/(10000+1)，采用1e-12数值比较容差；另列每架构随机区间和p为描述性结果，不增加主检验。新增主要族为三池×两来源六项，Holm校正；这不是替换历史主检验或重新挑选检验家族。

随机区间描述有限池内随机分组波动，不是T均值、模型总体或自然部署的置信区间。零极端次数只报告p=1/10001，不写p=0。10000次不是10000个独立数据集。支持条件：校正后观测差明显超出随机分布，则可排除类别内随机分组波动这一解释；不证明视觉状态因果、评分最优或所有条件分组都无差异。不同池单独解释，不人为设“5个百分点”阈值。

## 五维消融与旧结果复算

沿用原中点未知规则和sample_id同分次序。逐来源、类别计算完整H以及删除size/body_visibility/occlusion_level/truncation_level/body_orientation后的H；每个变体重新排序并等分五层。另复算既有equal_normalized变体，各维按最大分值归一化求和。补齐D；B/C复算用于核对已有均值、24运行方向与精确p，不覆盖历史结果。

报告全五层指标、每架构/种子Q5−Q1、变体差值相对完整H的变化、原/变体Q1及Q5的Jaccard与保留率，逐类别成员及风险分数均保存。删维后的条件集合已经改变，差值变化不解释为该维的独立因果贡献；相关维度可能保留类似信号。

统计沿用已有paired_stats：八架构先平均种子作双侧精确符号翻转，5000次架构/种子层级bootstrap及原随机种子规则。每池两来源×六变体为12项Holm补充家族，完整H不进入该族；不为使p<0.05事后减少比较数。变体−完整H的配对差也给区间，作为描述性敏感性，不另检索显著结果。旧B/C12项Holm p=0.09375的限制保留，不将方向一致写成所有消融获得校正显著支持。
