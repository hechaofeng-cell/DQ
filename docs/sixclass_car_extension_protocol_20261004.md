# car六分类扩展实验：运行前方案

登记日期：2026-10-04。原五类投稿冻结包保持为历史版本，新实验单独保存。

## 研究问题与假设

在dog、cat、horse、sheep、person中加入刚性非生物目标car后，视觉状态Coverage相对同预算Random是否仍有超出错误数量及类别构成的诊断多样性？不要求F1下降或方法获胜，不根据结果挑模型、预算、类别或状态。

主要指标族I1：六类宏平均逐类别等错误数混淆类型AUC及错误簇AUC，共两项Holm校正。car单类两项作为预定次要指标族I2，另作两项校正。四基线×两指标的全局Holm结果同时报告。正向效应且家族校正p<0.05视为该指标得到支持，只有一项通过为部分支持；无论方向均保留结果。

## 数据与模型

- 类别顺序：dog、cat、horse、sheep、person、car；标签0至5。
- 原五类训练1500张与候选2000张逐条复用。car从COCO train2017选300个固定目标训练，从Open Images官方test框标注选400个候选；每图只选一个固定car框。car候选沿用原候选构造中的小目标、遮挡和截断分层规则，排除group/inside/depiction标注。
- 复用原五类验证15张/类、独立基础测试50张/类；新增car验证15张和基础测试50张，从COCO val2017选取。验证集只选择checkpoint，不参与覆盖缺口或候选排序。基础测试仅作参考。
- 六类训练各300张，共1800；候选各400张，共2400；验证90；基础测试300。完成源图ID、裁剪哈希和近重复筛查，记录排除原因；不得用分类器错误决定排除。
- ImageNet预训练ResNet-18、ResNet-50、MobileNetV3-Small、MobileNetV3-Large、DenseNet-121、EfficientNet-B0、ConvNeXt-Tiny、Swin-T，训练种子20260916/17/18。每个模型重新训练六分类头及主干，而不是复用五分类预测。
- 沿用20轮、每轮3000次类别均衡加权采样、batch64、AdamW(lr=1e-4,weight_decay=1e-4)、余弦调度、同一增强和验证Macro-F1选checkpoint。训练完成后固定权重及预测，测试阶段只改选样。

## 特征与公平性

原19字段中删除头部可见、头部朝向、动作、腿部可见、截断部位五项。主比较统一使用14项共享状态加程序计算的目标尺度；原五类投影旧标签，car使用线上sensenova-6.8-flash-lite按共享规则标注。车辆正面定义为车头、背面为车尾；左右侧无法区分时unknown，不从车牌、品牌或车型推断。

车身颜色、车轮可见数、可见车辆部件、表面反光作为car专属解释字段，不参与主Coverage排序或六类宏平均覆盖分母。原五类全部19项字段保留，利用六分类冻结预测重新计算原生状态支持度、错误率、预算覆盖及失败状态；car的14共享+4专属字段亦完整保留。原生状态覆盖百分比只在各类别内部解释，不直接比较不同字段体系的百分比。unknown不算已覆盖状态，结构校验成功不等于语义正确。car线上标注与原五类本地标注存在标注器混杂，不能据此声称任意类别通用或因果归因。

## 测试与输出

- Coverage、Random、DeepGini、DSA、ViT k-center五方法，预算20/40/60/80/100张每类，总预算120/240/360/480/600；Random1000次；覆盖频数饱和阈值20，失败状态最低支持3。
- 全量运行24个模型/种子。保存预测、表征、所有排序、Accuracy/Precision/Recall/Macro-F1及每类指标。
- 混淆类型和错误簇作为与视觉标签无关的指标；错误簇在完整冻结预测上拟合，K上限8。0错误类别按覆盖0并报告不可评价比例；1错误为单例簇。逐类别等错误数用无放回稀释精确期望。
- 五组共享状态轮换留出，以降低用同一状态选样与评价的循环性；另输出六类和car分预算响应与严格控制结果。
- 按架构分层bootstrap5000次、架构级符号翻转检验，不把24个运行当24种独立架构。
- 五分类旧F1不能直接减去六分类新F1宣称退化；类别数、训练数据和状态协议均已改变。新实验独立作为跨类别扩展。
