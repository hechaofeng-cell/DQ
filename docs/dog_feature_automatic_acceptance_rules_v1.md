# 犬类特征自动统计与验收规则 v1

人工复核不作为工程流水线完成条件。自动报告固定以 500 张为分母，分别统计整条响应失败、字段缺失、非法枚举、`unknown` 和 evidence 缺失/过弱。

## 字段规则

- 出现率：字段出现数 / 500，至少 95%。
- 合法率：合法枚举数 / 字段出现数，至少 98%。
- unknown 率：unknown 数 / 合法值数；超过 20% 为警告，超过 50% 为缺口。
- 有效覆盖率：合法且非 unknown 数 / 500；至少 80% 为通过，60%-80% 为警告，低于 60% 为缺口。
- evidence 率：非空、至少 8 个字符且不等于枚举值的 evidence 数 / 500，至少 90%。

任一结构指标未达标或有效覆盖低于 60% 时字段为 `GAP`；结构达标但 unknown 超过 20%或有效覆盖低于 80%时为 `WARNING`；其余为 `PASS`。

## 总体规则

严格有效响应率至少 95%，并且 20 个字段全部为 `PASS` 时，自动工程验收为 `PASS`；否则为 `NEEDS_IMPROVEMENT`。人工复核只用于判断视觉语义正确性和模型与人工一致率，不能由结构统计替代。
