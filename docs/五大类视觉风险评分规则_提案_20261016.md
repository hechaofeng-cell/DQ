# 五大类视觉风险评分规则（候选方案 v1）

> **已被后续约定取代，仅保留追溯，不作为当前实施依据。** 2026-10-16后续讨论确定：五大类用于组织完整特征，尺度、可见性、遮挡、截断、朝向五维用于风险评分；外观、姿态动作、场景类型不按少见程度加入风险总分。当前口径见[视觉状态五大类与五维风险评分：当前约定](视觉状态五大类与五维风险评分_当前约定_20261016.md)。下文中的五类各20分、参考频次映射及新增聚合均为已搁置提案。

状态：设计提案，尚未接入评分代码、重新选样或进行实验验证。以下权重、映射与参考支持阈值均为本轮提出的候选规则，不是已有实验结论。本方案按用户要求，使空间几何、可见性与完整性、外观与形态、朝向与姿态、场景与图像质量五大类分别产生一个分值。

## 1. 总体架构与输出

总体机制保留：逐目标视觉状态同时进入风险分支与覆盖分支。风险分支产生类别内Q1—Q5和风险格配额；覆盖分支计算当前已选集合的覆盖边际增益；在仍有风险格名额的候选中贪心选择目标。每轮分别更新名额与状态支持，最终进行固定模型评价。

风险分支新增一个前置依赖：独立参考集的类别内字段频次。此频次只用于名义状态的固定映射，在选样前冻结，不从已选集合实时估计，不读取被测分类器的预测、错误或置信度。

本评分混合描述目标信息受限程度与相对于参考分布的非典型程度。总分称为“预定义视觉风险代理分数”，不解释为失败概率。少见状态不自动等于困难状态，背向也不必然比正向更难；这些假设需要后续评价。

每类评分先归一化到[0,1]，再各贡献最多20分：

R(x)=20[G(x)+V(x)+A(x)+P(x)+E(x)]。

G、V、A、P、E依次表示五大类，R范围为0—100。等权是初始规则，不能表述为最优权重。风险只在真实类别内排序，不将不同类别的相同分数解释为等难度。

## 2. 空间几何 G

首版仅使用已有的尺度字段，不因大类名称扩展就假设已有位置、长宽比等评分。

a为官方目标框面积与原图面积之比，分档沿用现有阈值：

| a | G |
|---|---:|
| a≥0.10，large | 0 |
| 0.03≤a<0.10，medium | 1/3 |
| 0.01≤a<0.03，small | 2/3 |
| 0<a<0.01，tiny | 1 |

必须从原图尺寸和官方目标框计算。裁剪缩放后的输入尺寸不能代替原图面积比。无效几何数据应修复或排除，不能静默当作小目标。

## 3. 可见性与完整性 V

先分别计算局部可见性损失L、遮挡O、截断T，然后取：

V=max(L,O,T)。

采用最大值是本提案为避免将同一缺失现象在三个子项中直接重复相加而做的保守聚合；它会忽略较小子项的额外贡献，不代表消除了所有相关性。三个子项及其具体部位仍保留用于覆盖和诊断。

### 局部可见性损失 L

- 犬、猫、马、羊、人：头部、躯干、适用肢体各占1/3，字段为head_visibility、torso_visibility、limb_visibility。
- 每项clear=0、partial=0.5、not_visible=1。
- 车辆首版使用body_visibility：full=0、most=0.25、partial=0.5、minimal=1。此映射是新候选规则，区别于旧版full与most均为0的评分。
- 首版不使用可见车轮数量作为缺失程度，也不把正常视角下看不到车尾或车顶直接算作缺失。
- 非车三个局部字段若旧缓存没有，应标为缺失并补标；不能根据整体可见性推造局部值。若改为旧字段兼容版本，应另列协议名称，不能混用分值。

### 遮挡 O、截断 T

| 词表版本 | 已知状态与分值 |
|---|---|
| 四级词表 | none=0、light=1/3、moderate=2/3、heavy=1 |
| 三级词表 | none=0、partial=0.5、heavy=1 |

必须记录schema版本。partial的0.5是本候选版本中的单独映射，不表示它等同于四级词表中的moderate。遮挡物来源与截断部位记录状态，不追加次数分。

## 4. 外观与形态 A

不预先规定黑色比白色难、卷毛比直毛难。按独立参考集中的类别内相对少见程度评分。

对类别c、字段f、已知状态s，在参考集中计数n(c,f,s)。令n_max(c,f)为该字段所有适用已知状态的最大计数，定义：

u(c,f,s)=1-[n(c,f,s)+1]/[n_max(c,f)+1]。

最常见状态为0，较少见状态较接近1。已注册但参考集中未出现的已知状态仍可计算；unknown、not_visible或无法观察不作为少见状态计分。枚举外的非法值应校验失败，不能自动视作未见状态。

这是相对频次偏离指标，不是分布外概率、模型熟悉程度或错误概率。若参考集不是训练数据，应仅称“相对于参考分布的偏离”，不能称训练暴露不足。

建议固定的类别字段如下，类内等权平均得到A：

| 类别 | 外观与形态评分字段 |
|---|---|
| 犬 | coat_primary_color、coat_pattern、coat_texture、ear_shape、body_shape |
| 猫 | coat_primary_color、coat_pattern、coat_texture、body_shape |
| 马、羊 | coat_primary_color、coat_texture |
| 人 | hair_color、hair_length、hair_texture、headwear、eyewear |
| 车 | car_color、reflective_surface |

字段数不代表该大类权重更大，A归一化后始终最多贡献20分。其他外观字段可以继续用于覆盖，不要求为了“全部打分”而强行纳入总分。

参考集及适用性规则：

1. 优先使用带同协议状态标注的训练集；若不具备，使用与最终确认集分离的固定参考池。参考标注可以复用VLM流程，但参考池存在不代表这些标注已经齐备。
2. 参考池ID、schema、标注器版本、计数表、评分字段、映射和权重需在读取新确认集结果之前冻结，跨来源确认继续使用同一映射。
3. 每个类别—字段至少需要100个适用且已知的参考记录才能估计u；100为初始设计阈值，不是经验验证的充分性保证。不足时该映射暂不可用，按未知分量保留区间，不能将其贡献记为0。
4. unknown、not_observable、not_visible不进入参考有效计数；已知“none”如无眼镜是有效状态，正常纳入。
5. 不适用与看不见分开处理。例如明确hair_presence=bald_or_shaved时，毛发颜色、长度、质地按预定结构规则不适用，人物A仅在头部与眼部配饰之间等权汇总；hair_presence=covered或unknown时不得以同样方式删除毛发分量，应保留未知区间。此结构规则应同时用于参考计数与待评分目标。
6. 不能按当前目标已知字段临时重新归一化；只有预先明确的类别或结构适用性规则允许调整适用字段集合。

## 5. 朝向与姿态 P

非车类别：P=0.5D+0.5B。

D为朝向子分数，B为姿态动作的参考相对少见程度。

### 朝向 D

非车：身体朝向与头部朝向各占1/2。

| 子项 | 状态与候选分值 |
|---|---|
| 身体朝向 | front、left_side、right_side、three_quarter及旧词表明确的斜向细分=0；back=0.5；overhead_or_unusual=1 |
| 头部朝向 | front、left、right=0；back=0.5；up/down及upward/downward=1 |

这些朝向分值沿用现有预定义评分的组织思路，不代表已证明的跨类别难度排序。若研究希望消除这种方向偏好，可另设“朝向也按固定参考频次映射”的敏感性方案，不能根据结果择优替换主规则。

### 姿态动作 B

使用第4节同一u函数：犬、猫使用posture_action_state；马、羊、人使用pose_action。不给奔跑、跳跃、躺卧预设统一高分。这里仅使用单图姿态动作标签，不从“奔跑”自动推断模糊程度。

车辆现有协议没有姿态动作字段，固定设P=D=body_orientation映射值；不虚构动作，也不将该情况当作unknown。其他类别若协议规定动作适用但标注缺失，B为未知分量，不得切换成车辆规则。

## 6. 场景与图像质量 E

采用五个子项等权：

E=(背景复杂度+模糊+光照异常+低对比+场景少见程度)/5。

| 子项 | 字段与候选映射 |
|---|---|
| 背景复杂度 | background_complexity：simple=0、moderate=0.5、complex=1 |
| 模糊 | blur_level：clear=0、mild=0.5、severe=1 |
| 光照异常 | illumination：normal=0；low_light、backlit、strong_shadow、overexposed、mixed_or_colored=1 |
| 低对比 | target_background_contrast：high=0、medium=0.5、low=1 |
| 场景少见程度 | 犬猫scene，其余类别scene_environment；使用第4节u函数 |

光照项是“正常/列举的非正常光照”的二值代理，不表示这些异常类型同样严重，也不从类型名称推造强度等级。室内、室外、草地、道路不直接按固定顺序赋分。

光照与对比度可能相关，等权平均不能被解释为各自独立的风险贡献。群体与交互字段首版仍用于覆盖，不自动叠加进E。

## 7. 未知、不适用与分数区间

已知基础分量是确定值；unknown、not_observable及因看不见而无法判断的名义属性为[0,1]。用所有合成公式逐层传播上下界：非负加权平均分别对下界、上界求平均；max聚合分别取各下界最大值、各上界最大值。

输出每一大类的下界、上界以及总分R_low、R_high。排序值R_mid=(R_low+R_high)/2，仅为固定组织规则，不解释成真实风险期望。记录总区间宽度以及未知分量数。整个大类未知时，不将另外四类的权重扩大，而是保留该类最多20分的不确定范围。

not_in_view需按具体协议及视角适用性解释。现有非车躯干和肢体规则禁止的值应判为语义校验问题；不得统一映射成高风险或0分。此首版车辆评分使用整体可见性，避免直接聚合视角不适用的局部部件。

只要必要映射的参考支持尚不齐备，所得总分就是部分信息下的区间评分；不能宣称已完整计算了五大类。

## 8. 与分层、配额和覆盖的连接

1. 每个真实类别按R_mid排序，同分按sample_id，等量划分Q1—Q5；报告边界并列及上下界重排敏感性。
2. 仍可在“类别—风险层”内部按R_mid与未知区间宽度建立风险格，按候选数量比例和最大余数法分配预算。
3. 风险配额内随机与覆盖选样共享相同格配额。覆盖贪心规则和两条反馈机制不变。
4. 覆盖使用预先列明的字段—已知状态词表，计算当前已选集合的支持数。风险中的u来自独立冻结参考集，选样中不会更新；覆盖支持数来自所选集合，每轮更新，两者不能替代。
5. 覆盖词表是否扩展必须单独注明：仅修改风险公式不会自动扩展覆盖分母。若同时扩展词表，相关覆盖结果和选样均重新计算。
6. 即使覆盖词表不变，新的风险分数也会改变Q层成员、格配额与最终集合，因此需重新分层、选样和出报告。目标、模型和实际推理输入不变时可复用已有逐目标分类预测。

## 9. 验证边界与最小比较

当前没有“五大类评分优于原五维评分”的实验结论。建议比较旧评分与新评分时使用同一目标、同一预测、同一覆盖词表及同一预算；分别运行各自的配额内随机与配额内覆盖，分开评价评分变化和选样变化。

至少检查：各类分值与未知比例、Q层规模与并列、Q1—Q5条件性能、相对于类别平衡随机划层的差异，以及删去相对少见程度项后的敏感性。独立参考映射冻结后，在另外来源确认。未经过验证前，只称“候选视觉风险代理规则”。

若这套规则能识别少见状态但不能区分错误，应明确报告其反映非典型程度；不能为了保留“风险”称呼，事后按确认集结果调整状态顺序或权重。
