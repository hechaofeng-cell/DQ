# 项目完整流程与论文总图绘制说明

日期：2026年11月17日。

本文是一份可以直接交给其他绘图人员或绘图模型的项目说明。内容对应正在修改的三段式方法总图，依据项目2026年11月的方法正文与P20实现整理。以下说明的是执行逻辑；解释性文字、逻辑节点和参数不必全部搬进一张图。

## 一、研究主题与任务边界

建议图题：**视觉状态驱动的模型测试与充分性分析**。

研究目标：在规定的测试规模与视觉风险构成下，组织能够提供视觉状态支持的测试集合，说明测试覆盖了哪些条件、哪些条件仍缺少样本，并评价固定分类模型在这些条件下的表现。

测试对象是由官方目标框指定的目标实例。分类器接收按固定预处理生成的目标裁剪图，任务是在已知目标区域上进行多类别分类。最终测试集包含狗、猫、马、羊、人、汽车六个类别；狗类可作为图中的解释实例。

项目中三类信息各自承担不同职责：

| 信息 | 来源 | 用途 |
|---|---|---|
| 目标位置与类别真值 | 数据集官方目标框及类别标注 | 指定观察对象，作为分类评价真值 |
| 目标视觉状态 | 固定状态字典、VLM提取；尺度由程序计算 | 风险组织、覆盖计算和条件分组 |
| 类别预测 | 参数与预处理固定的待测分类模型 | 总体、风险层和状态条件下的表现评价 |

选样不读取分类器预测、置信度或错误。状态提取可使用类别提示，但VLM不替代官方类别真值。测试过程不更新分类器权重。

## 二、整张图的三阶段主线

**视觉状态定义与提取 → 风险约束选样与覆盖条件调整 → 测试输出与模型评价。**

主线中发生变化的对象依次为：

**图像与目标标注 → 结构化状态记录 → 带风险层与单元身份的候选池 → 初始集合 → 经检查确定的最终集合 → 条件能力报告。**

整图保持三个大模块，第二阶段承担核心成员调整机制。第一、第三阶段可以更紧凑。内部构图可由绘图者调整，但必须保留上述信息依赖与下文分支。

## 三、第一阶段：视觉状态定义与提取

### 3.1 准备数据与目标身份

输入图像数据集及官方目标标注，为每个候选目标绑定唯一ID、原图、目标框和真实类别。每条后续记录都通过目标ID关联，避免同图多个目标之间发生错配。

图上可以使用一个简洁的图像数据集图标，并展示一个真实目标实例。该实例只用于帮助理解输入对象。

### 3.2 人工与LLM协同定义细粒度字典

研究人员与大语言模型在提取和选样前，共同整理字段定义、允许取值、未知值处理及必要的互斥和依赖规则，形成固定的细粒度状态字典。

字典按以下五类组织：

1. 空间几何。
2. 可见性与完整性。
3. 外观与形态。
4. 朝向与姿态。
5. 场景与图像质量。

区分跨类别共享字段与类别专属字段；用“命名空间—字段—取值”标识状态。图上可以只写“细粒度字典”，五类名称可酌情压缩，字典内部无需再塞照片实例。

### 3.3 图像、标注与字典共同约束VLM提取

提取时利用原图、目标框标记图及目标细节裁剪，分别提供场景、目标定位和局部外观证据。VLM按固定字典输出目标的结构化状态，不能判断的字段保留未知。尺度由官方目标框面积占原图面积的比例计算。

总图可将多视图输入合并为“图像与标注”，无需把三张视图全部画出来，但必须画出：

**人工＋LLM → 细粒度字典；细粒度字典＋图像与标注 → VLM状态提取。**

### 3.4 检查记录并编码

检查目标绑定、字段完整性、枚举合法性、多选去重，以及互斥和依赖关系，保存版本与原始响应。结构检查确认取值和格式合规；不代表语义准确率已经得到验证，不能在图中增加“全部人工校准通过”之类未经建立的结论。

输出完整结构化状态记录，并编码为目标—状态二值矩阵。每行对应一个目标，每列对应一个固定字典状态。一个目标可以同时支持多个状态；未知、缺失和不适用不增加已知状态支持。矩阵中的零表示记录未确认具有该状态，不能一概解释为确认不存在。

图上只展开一个正确对应照片的状态值即可，例如“坐姿”。这只是完整记录中的一个示例，不表示系统只提取姿态。

### 3.5 第一阶段输出及去向

- 目标身份、图像和标注继续用于成员选择与后续模型输入。
- 完整状态记录用于风险评分、覆盖检查、批量重选和条件诊断。
- 固定字典定义覆盖评价分母；候选池中暂未出现的合法状态仍保留在分母中。

## 四、第二阶段：风险约束选样与覆盖条件调整

### 4.1 从状态中计算五维综合风险

从状态记录中使用**尺度、可见性、遮挡、截断、朝向**五个风险维度，按固定映射赋分，再等权合成为0—100的视觉风险评分。

非汽车类别的可见性由头部与腿部各占一半合成，朝向由主体与头部各占一半合成；汽车使用整体可见性和主体朝向。未知基础分量保留其原定权重和可能贡献的区间，得到总分上下界、中点与宽度。

风险中点用于排序，区间宽度记录未知信息造成的评分范围。该风险是测试组织规则，不直接表示分类错误概率。

第一阶段的五类字典是描述体系，第二阶段的五个维度是风险计算用的字段集合，两者不能混写。其余合法状态仍参加覆盖与诊断。

### 4.2 类内划分Q1—Q5与细分单元

在每个类别内部，按风险中点升序排列目标，同分按目标ID排序，按数量划为Q1—Q5。它们是池内、类内的相对风险层，不能当成跨类别通用的绝对难度标准。

每个Q层内部，将风险中点和区间宽度相同的目标归为同一细分风险单元。

**Q1—Q5不是清晰、不可见、遮挡、截断、小目标五种状态。** 如放五张照片，必须各自取自真实对应风险层，以相同尺寸展示；照片只说明该层的一个成员。

### 4.3 分配固定配额并形成初始集合

当前每类400个候选、选择200个。五个Q层各80个候选、各入选40个；层内再按细分单元候选数量比例分配整数名额，采用最大余数法处理取整。

每个细分单元按名额无放回随机抽样，合并为该类别的初始集合。随后固定各单元配额。

初始集合此时满足数量和风险构成要求，覆盖是否达标由下一步检查。

### 4.4 在同约束下确定覆盖检查门槛

在同候选池、同测试预算和同风险单元配额下，从空集开始构造覆盖引导的贪心参照集合。每步只考虑单元名额尚未用完的候选，按截断对数支持的边际增益优先补充稀缺状态；状态支持达到20后不再增加该项增益，同分按目标ID决定。

取参照集合出现覆盖率与支持完成度的95%，分别作为该类别的两项检查门槛。门槛在读取本轮分类预测前确定。

这是相对于同约束参照的操作性要求，不是95%的置信度，也不要求95%的字典状态都已达到支持目标。参照集合不是全局最优上界，也不直接取代受成员保留限制的初始集合。

门槛确定是选样前的准备步骤，可以与初始集合构建并列理解。总图可把详细来源留在正文，但覆盖检查必须有既定判据。

### 4.5 对初始集合计算支持与覆盖

对每个合法状态，统计有多少入选目标支持它。同一目标对同一状态最多贡献一次。

| 内容 | 含义 | 在方法中的作用 |
|---|---|---|
| 出现覆盖率 | 字典中至少出现过一次的状态比例 | 调整触发与可接受性约束 |
| 支持完成度 | 各状态相对于支持目标的完成程度 | 调整触发、可接受性约束和优先优化量 |
| 达阈值覆盖率 | 支持数达到目标的状态比例 | 随最终集合报告 |
| 逐状态缺口 | 未出现、出现但不足、已达到目标 | 解释覆盖与候选池限制 |

当前每状态支持目标为20。支持完成度对每个状态最多计入20份支持，防止常见状态的大量重复掩盖其他状态不足。

同时查询完整候选池：某状态池内未出现或全池支持不到20时，单靠现有池内重选无法补到该状态的支持目标；数量足够时还要检查风险配额和改动上限。

### 4.6 根据初始检查决定是否调整

**两项检查均通过：保留初始集合，直接进入最终择集。**

**任一项检查不足：触发一次受改动上限限制的批量重选。**

这里的一次批量调整内部有两轮优化求解，但不形成每换一张图就循环重选、直到无条件成功的流程。

### 4.7 受限整批重选：联合核算损失与收益

从完整候选池重新决定最终成员，同时满足以下要求：

1. 每类测试数量仍为200。
2. 每个细分风险单元的入选数等于原配额。
3. 相对于初始集合最多移出20个成员，因此至少保留180个；补入数量与移出数量相同。
4. 出现覆盖率与支持完成度均达到各自门槛，且均不低于初始值。

每个移出成员可能减少多个状态的支持，每个补入成员也可能增加多个状态的支持。必须根据整批调整后的净支持，重新计算封顶支持和是否出现。多个成员的贡献相互重叠，不能将独立替换的收益简单相加。

保持配额要求的是各细分单元移出、补入数量相等，不代表算法先固定若干图片对再逐对独立优化。用一对照片展开机制时，应注明它们是批次中的成员示例，不能把整批平均收益归给这一对照片。

### 4.8 两轮求解的优先顺序

第一轮，在全部约束内尽可能提高封顶支持总量，即支持完成度。

第二轮，保持第一轮取得的实际封顶支持总量不下降，再尽可能增加出现状态数。

两轮共用同一个初始集合、同一风险配额及同一个最多20个初始成员移出预算。第一轮合格而第二轮没有可接受结果时，保留第一轮合格结果。

实现采用混合整数规划。求解受时限限制时，要区分可行解、取得最优性认证、已证不可行和未取得合格解等状态。

### 4.9 复核、采用与退出

根据实际成员名单与完整状态矩阵，重新核验目标身份、总数、每单元配额、改动数和两项覆盖指标。

- 取得合格调整结果：采用调整集合。
- 未取得合格调整结果：返回初始集合，报告缺口与求解状态。
- 不降低门槛继续补选，不将未达标的部分改进悄悄当成达标结果。

达到要求的调整结果，也不保证每个状态支持数或达阈值覆盖率都增加。固定候选池、配额和改动预算可能使要求无法实现。

### 4.10 第二阶段输出

每个类别输出一份确定的成员名单；合并为多类别最终测试集。保存风险构成、逐状态支持、三项覆盖指标、缺口与调整记录。

**核心科学机制应画为：保持风险配额与大多数初始成员，在覆盖不足时联合核算移出损失、补入收益，有限改变集合。**

## 五、第三阶段：测试输出与模型评价

### 5.1 固定多类别最终测试集

合并各类别最终名单，形成多类别测试集。当前六类各200个，共1200个目标。图中宜使用抽象的数据集图标，不放一张狗图暗示最终集合只有狗。

集合身份、预处理和待测分类器参数固定后，再评价模型。当前实证复用固定分类模型的历史预测缓存；图中可以概括为“固定模型评价”，不必把实现画成重新训练或重新推理。

### 5.2 总体、类别与风险层评价

将官方类别、分类预测、目标状态与风险层按目标ID关联。

先建立多类别混淆矩阵，计算整体Top-1准确率、各类别Precision、Recall和F1，以及宏平均F1。随后按Q1—Q5分别评价，观察视觉风险组织与实测表现的关系。

图中若使用狗类F1风险层曲线，表示狗类在不同风险层的识别表现；它不是宏平均F1，也不是初始集到调整集的性能增长曲线。

### 5.3 状态条件评价

针对每个“类别—模型—状态”建立两组：

- 状态组：同一真实类别中具有该状态的入选目标。
- 已知对照组：同类别、同命名空间、同字段具有其他已知取值，且不具有该状态的目标。

例如，分析狗类“背向”时，与朝向已知的非背向狗比较，不把朝向未知目标混入对照。对于多选字段，具有待分析状态的目标优先归入状态组。

计算两组条件召回率及差值。使用多个固定预测种子时，先在目标上平均正确性，再计算组内均值。

### 5.4 筛选候选弱状态

当前规则要求两组各至少20个目标，且各自来自至少20张不同原图；满足支持要求且状态组召回率比已知对照组低至少10个百分点时，记为候选弱状态。

支持不足的状态标记为不可评价并保留缺口；该门槛不是逐项显著性检验。当前主诊断保留全部符合规则的候选条件；每类每模型只保留差值最负三项的版本属于辅助分析，不能混为主流程。

### 5.5 冻结候选清单并跨来源复核

固定候选弱状态清单后，在没有原图重叠的其他来源参考数据中，使用相同字典、分组规则、支持门槛和召回差值要求复核。

- 支持足够且差异仍达到门槛：重复出现。
- 支持足够但差异未达到门槛：未重复。
- 支持不足：无法复核。

全部结果保留，不根据参考结果更换候选清单。当前证据使用已分析过的历史参考数据，因此应按历史跨来源重复分析报告，不标为首次盲验证。跨来源复核不回流改变本次成员名单或字典。

正文还包含可选的风险层内比较，用于检查状态组与对照组的风险构成差异。它可以在详图或补充图中展开，无需挤入总图主通路。

### 5.6 输出条件能力与充分性报告

最终报告同时回答：

1. 测试集包含哪些状态、各有多少支持，哪些仍不足。
2. 固定模型总体、各类别与风险层表现如何。
3. 哪些状态下出现可评价的表现差异。
4. 候选弱状态在其他来源中是重复出现、未重复，还是无法复核。

报告保留数据与标注版本、模型、类别、状态、组内目标数和原图数、条件召回率、差值与复核状态。状态关联不被解释为分类错误的因果根源。

## 六、给绘图者的连接关系

下列编号表示逻辑依赖，不要求每个编号都成为独立框。相近节点可合并，以免总图过碎。

### 6.1 第一阶段

| 起点 | 终点 | 关系 |
|---|---|---|
| 人工＋LLM | 细粒度字典 | 协同定义 |
| 细粒度字典 | VLM状态提取 | 约束字段及取值 |
| 图像与官方目标标注 | VLM状态提取 | 提供指定目标的视觉证据 |
| VLM状态提取＋程序尺度 | 完整状态记录 | 产生结构化表示 |
| 完整状态记录 | 第二阶段 | 评分、覆盖与优化输入 |

### 6.2 第二阶段

| 起点 | 终点 | 关系 |
|---|---|---|
| 状态记录 | 综合风险评分 | 使用五个风险维度 |
| 综合风险评分 | 类内风险层与细分单元 | 排序、分层、细分 |
| 风险单元与测试预算 | 固定配额 | 分配各单元名额 |
| 固定配额＋候选池 | 初始集合 | 单元内随机抽样 |
| 同池同配额参照 | 两项检查门槛 | 选样准备，可在图注交代 |
| 初始集合＋完整状态记录 | 覆盖检查 | 统计支持与覆盖 |
| 覆盖检查 | 最终择集 | 两项均达标，保留初始集 |
| 覆盖检查 | 受限批量重选 | 任一项不足时触发 |
| 完整状态记录＋固定配额＋初始集合 | 受限批量重选 | 联合核算，约束成员改动 |
| 批量重选 | 复核择集 | 重算完整集合指标与约束 |
| 复核择集 | 最终集合 | 合格则采用调整集，否则初始集并报缺口 |

复核可以并入批量重选的出口，不必再画一个很大的独立判断框。保持原始类别、目标身份等信息的传递可由共享输入表示，无需逐一拉长线。

### 6.3 第三阶段

| 起点 | 终点 | 关系 |
|---|---|---|
| 各类别最终集合 | 多类别最终测试集 | 合并并固定名单 |
| 固定模型＋目标裁剪输入 | 类别预测 | 推理或关联既有固定缓存 |
| 类别预测＋官方真值＋风险层 | 总体、类别与风险层评价 | 计算分类指标 |
| 类别预测＋真值＋完整状态记录 | 状态条件评价 | 状态组与已知对照组比较 |

## 十、可直接复制给绘图模型的任务说明

请根据本说明绘制一张横向三段式、可编辑的中文科研方法总图，题为“视觉状态驱动的模型测试与充分性分析”。三个大模块为视觉状态定义与提取、风险约束选样与覆盖条件调整、测试输出与模型评价，中部是核心机制区。用浅底色区分大模块，字数适中，短标签为主，不写公式，不要求加a/b/c。内部排版可调整，不必把每个说明步骤都框成独立盒子。

第一阶段画人工和LLM协同定义细粒度字典，字典与图像、官方目标标注共同输入VLM，结合程序计算的尺度得到完整结构化状态记录。字典含空间几何、可见性与完整性、外观与形态、朝向与姿态、场景与图像质量五类。只需展示一个与真实照片对应的状态取值，其余状态概括表示。

第二阶段从记录中的尺度、可见性、遮挡、截断、朝向计算综合视觉风险，在每类内部划分Q1—Q5，再建立细分风险单元及固定配额，按配额随机形成初始集合。风险层是综合分数层，不能命名成五种独立状态。覆盖检查使用完整状态字典，主要检查出现覆盖率和支持完成度。初始已达标直接输出；不足才执行一次受限批量重选。核心展开一个细分风险单元的前后成员与状态支持变化，体现整批联合核算移出损失和补入收益，同时保持样本总数、单元配额以及大多数初始成员。两轮优化为支持优先、出现其次，共用最多替换20个初始成员的预算。复核合格采用调整集合，未取得合格集合则保留初始集合并报告缺口，不能画成替换必然成功或无限循环换图。

第三阶段汇合各类最终成员为多类别测试集，用抽象数据集图标。固定模型和预处理，关联官方真值、类别预测、风险层与状态记录，输出总体、类别和风险层指标，同时分析状态条件召回率，筛选候选弱状态并按同一规则跨来源复核，形成条件能力与测试支持报告。模型预测与跨来源结果均不回流改变本次风险、门槛和成员名单。右侧可用狗类状态支持前后对照与风险层F1展示已有真实输出实例；不用虚构热力图或曲线。

请突出对象和表示的转换：图像与标注→状态记录→带风险身份的候选池→初始集合→条件调整后的择集→模型条件能力报告。可合并次要步骤，以清晰的主通路和少量条件分支连起三段，重点让读者看懂覆盖不足为什么触发调整、整批调整如何保持配额，以及调整不成功如何退出。
