# 第二阶段：风险约束选样与覆盖条件调整

本说明对应三段式总图的中间部分，依据项目方法正文与 P20 选样实现整理。目的是把机制讲清楚，再决定图中突出什么；本文的解释性文字无需全部搬进总图。本轮没有改动选样算法、门槛或实验结果。

## 1. 第二阶段要解决什么问题

在给定的测试规模和风险构成下，先形成初始测试集；只有其状态覆盖或样本支持未达到预先确定的门槛时，才有限调整成员。调整时联合考虑移出损失和补入收益，并保持测试数量及细分风险单元配额。

这里有两类要求：风险约束规定测试集的构成，覆盖要求检查这套构成下的测试内容是否得到足够支持。两者共同作用于成员选择。

这一阶段既不训练分类器，也不依据分类器预测选择成员。模型是否答对、置信度多高、F1 如何变化，均不进入风险计算、门槛确定或成员优化。

## 2. 输入与输出

输入来自第一阶段：候选目标身份、类别、图像及官方目标标注，固定的细粒度状态字典，以及每个候选目标的完整状态记录。状态记录编码为目标—状态矩阵：每行一个目标，每列一个合法状态。一个目标可以支持多个状态；未知、不适用或缺失不增加已知状态支持。

选样前还要确定测试预算、风险配额、状态支持目标、覆盖门槛和成员改动上限。下文的 200、20 和 95% 是当前实现设置，不是方法普遍适用的唯一取值。

输出为每类固定的最终成员名单、风险层和细分单元构成、各状态支持数、三类覆盖指标、逐状态缺口，以及调整是否触发、改动数和求解状态。各类别名单合并后形成多类别测试集。狗类只是总图的说明实例。

## 3. 风险评分、分层与初始选样

### 3.1 五类描述与五个风险维度是两个层次

第一阶段的五类字典组织为：空间几何、可见性与完整性、外观与形态、朝向与姿态、场景与图像质量。

第二阶段从相关状态字段中选取尺度、可见性、遮挡、截断、朝向五个风险维度。外观、姿态和场景等其他合法状态仍参加覆盖评价，不都被转成风险分数。

### 3.2 风险如何得到

各维度按固定映射转成分值，再以相同权重合成 0—100 的视觉风险评分。尺度来自目标框面积占原图面积的比例。尺度越小、可见性越低、遮挡和截断越重，映射分值越高；朝向按正文的固定规则赋值。

非汽车类别的可见性由头部与腿部可见性各占一半合成，朝向由主体与头部朝向各占一半合成；汽车使用整体可见性和主体朝向。未知分量保留其可能贡献的区间和原定权重，由此记录总分上下界、中点与宽度。中点用于排序，宽度用于记录未知信息带来的评分范围；宽度不是统计置信区间。

分数组织的是本文定义的视觉风险，不能直接解释为模型分类错误概率。

### 3.3 Q1—Q5 与细分单元

在每个类别内部按风险中点从低到高排序，同分按目标 ID 排序，再按目标数量划为 Q1—Q5。当前每类 400 个候选，每层 80 个。

**五层是综合风险排序的结果，不是五种视觉状态。** 不能将 Q1—Q5 分别命名为清晰、不可见、遮挡、截断、小目标。每层照片应取自该层的真实成员，照片是实例，不定义该层的语义。

在每个 Q 层内部，风险中点与评分区间宽度相同的目标归入同一细分风险单元。精确成员控制发生在这个层次，不能只画成“同一 Q 层内任意替换”。相同中点和宽度也不要求五个原始风险维度逐项相同。

### 3.4 配额与初始集合

当前每类选 200 个目标，均分至五层，每层 40 个。层内再按各细分单元的候选数量比例分配整数名额，采用最大余数法处理取整。

每个细分单元按名额无放回随机抽样，合并为初始集合。此时已经满足数量与风险配额要求，尚未要求覆盖门槛通过。随后固定单元配额，后续只改变合法范围内的成员。

## 4. 覆盖检查：检查什么，门槛从哪里来

### 4.1 三项指标与缺口

| 内容 | 回答的问题 | 在当前方法中的作用 |
|---|---|---|
| 出现覆盖率 | 固定字典中，有多少状态至少出现过一次？ | 调整触发与可接受性检查 |
| 支持完成度 | 每个状态相对支持目标积累了多少支持？ | 调整触发与可接受性检查，也是优先优化的量 |
| 达阈值覆盖率 | 有多少状态已达到支持目标？ | 随结果报告；不是当前双门槛的第三项硬约束 |
| 逐状态缺口 | 哪些状态未出现，哪些出现但不足，还差多少？ | 解释汇总指标与未达标原因 |

支持数按目标计数，同一目标对同一状态最多贡献一次。字典中暂未在候选池观察到的合法状态仍留在分母中。

当前每个状态的支持目标为 20。支持完成度对每个状态最多计入 20 份支持，超过的部分不再提高该指标。因此，重复增加已经很充足的状态，不能替代其他状态的支持缺口。达到 20 是达到规定的样本支持要求，并不自动建立统计充分性。

### 4.2 门槛的确定

在同一候选池、同一测试预算和同一风险单元配额下，先构造一个覆盖引导的贪心参照集合。参照选择从空集开始，逐次选择仍有单元名额、且截断对数支持边际增益较高的目标；同分按目标 ID 决定。该增益偏向支持不足的状态，状态支持达到 20 后不再获得额外增益。

分别取参照集合出现覆盖率、支持完成度的 95%，作为该类别的两项门槛，并在读取本轮分类预测前确定。

95% 是相对于参照指标的比例，不表示字典状态全部达到 95%，也不是置信度。参照集合是同约束下的可行比较基准，不是全局最优上界；它不直接取代需要保留大多数初始成员的集合。

图中可以只保留“覆盖检查”和两个指标名称，门槛来源放正文或图注；判断依据仍然需要在正文保留。

### 4.3 触发规则

初始集合两项指标都达到门槛，直接采用初始集合。任一项不足，才启动一次受限批量调整。这里的“一次”指一次批次重选调用，内部包含下述两轮求解，不是保证只求解一次，也不是无限循环换图。

## 5. 核心机制：受限批量调整

### 5.1 哪些东西固定

| 约束 | 当前设置或含义 |
|---|---|
| 测试数量 | 每类仍为 200 个目标 |
| 风险构成 | 每个细分风险单元的入选数量保持原配额 |
| 改动幅度 | 最多移出 20 个初始成员，因而最多补入 20 个，至少保留 180 个 |
| 出现覆盖 | 既达到门槛，也不低于初始集合 |
| 支持完成度 | 既达到门槛，也不低于初始集合 |

两轮求解始终相对于同一个初始集合计算最多 20 个移出成员，不是第一轮换 20 个、第二轮再换 20 个。

### 5.2 为什么要把移出和补入一起算

移出一个目标，会同时减少它所支持的多个状态；补入一个目标，也会同时增加多个状态。优化必须重算整批调整后每个状态的净支持，再进行封顶与覆盖统计。

例如，下面仅用假设数字解释机制，不是实验结果：

| 状态 | 初始支持 | 整批移出造成的减少 | 整批补入造成的增加 | 调整后支持 |
|---|---:|---:|---:|---:|
| 背向 | 8 | 2 | 5 | 11 |
| 正面 | 26 | 6 | 2 | 22 |
| 抬头 | 1 | 1 | 0 | 0 |

“背向”增加了，但“抬头”可能消失；“正面”虽然从 26 降至 22，在支持完成度中仍只计入 20。是否接受这一整批，要回到完整状态空间和全部约束判断，不能只看新成员新增了哪些标签。

这也说明不能简单累加各次独立替换的收益：多个目标的状态贡献会重叠，且封顶与是否出现的判断取决于整批调整后的支持。

### 5.3 两轮求解在做什么

第一轮在全部约束内，尽可能提高封顶支持总量；固定字典与支持目标后，这等价于尽可能提高支持完成度。

第二轮保住所取得的实际封顶支持总量，再尽可能增加出现状态数。这是支持优先、出现其次的顺序，不能交换画成“先补全所有状态，再增加支持”。

实现采用混合整数规划。两轮共用相同初始集合、成员改动上限与风险配额。若求解受时限限制，只能按实际状态报告可行解或最优性认证，不能一概称为全局最优结果。

从图形表达看，可以把它放在同一个“联合重选”区域：展示保留成员、移出成员和补入成员；用同单元边界或配额刻度说明构成保持；用局部状态支持变化说明损失和收益如何共同影响结果。照片仅用于对应成员身份。

### 5.4 可以保证和不能保证的内容

被接受的调整集合必须通过数量、单元配额、改动上限及两项指标约束。它不保证每一个状态的支持都增加，也不保证达阈值覆盖率上升。

同样，方法不保证在所有候选池与改动预算下都存在达标调整集合。状态在候选池中缺失、全池支持不到 20、可替换单元容量有限，以及求解时限，都可能导致没有得到合格结果。必须区分已证不可行和时限内未取得合格解。

## 6. 复核与退出

根据实际成员身份和完整状态矩阵重新计算数量、各单元配额、移出数、状态支持和覆盖指标，而不是仅使用求解器的中间变量。

| 情形 | 采用的集合与处理 |
|---|---|
| 初始集合已通过双门槛 | 初始集合，不触发调整 |
| 得到合格调整结果 | 采用调整集合 |
| 第一轮合格，第二轮无可接受结果 | 保留第一轮的合格集合 |
| 没有取得合格调整结果 | 返回初始集合，报告缺口和求解状态；不降低门槛继续补选 |

所以“复核”在实现上需要存在，但总图未必需要再画一个与覆盖检查同样大的框。可以并入调整模块的出口，用“合格调整集 / 否则初始集并报缺口”说明择集规则。

## 7. 根据机制，第二阶段图应强调什么

### 7.1 必须让读者看懂的四件事

1. **先按风险组织测试。** 综合风险排序产生五层；固定配额产生初始集合。五层的照片不能代替这个关系。
2. **调整有条件。** 初始集合覆盖已达标，直接输出；不足才进入调整。
3. **整批重选保留原有构成。** 同细分单元移出与补入数量相等，且受到总改动上限约束。核心是成员与状态支持的联合核算。
4. **没有无条件成功承诺。** 调整后复核，通过则采用；未得到合格结果则保留初始集合并报缺口。

### 7.2 视觉信息的优先级

| 优先级 | 内容 | 适合怎样画 |
|---|---|---|
| 最高 | 保留成员、移出损失、补入收益、单元配额不变 | 一个局部细分单元的前后成员对照，加少量相关状态的净支持变化；让这部分成为中部主体 |
| 高 | 初始达标则跳过调整，不足才调整 | 一条主通路和一条条件支路，条件写在出口；无需两个菱形 |
| 中 | 综合风险分层与初始选样 | 一条五层风险带、少量统一尺寸且真实属于各层的照片、对应配额标记 |
| 中 | 支持优先、出现其次 | 联合重选区域内两行短标记；详细数学形式留正文 |
| 低 | 求解器、容差、随机种子、全部字段映射 | 放正文或附录，不挤入总图 |

局部机制可以只展开一个单元，其他单元用省略号或概括的成员组表示。需要画的是各组的关系，而非完整陈列 200 个图标。完整成员数组可留作补充图。

### 7.3 可直接使用的短标签

“综合风险分层”“固定配额初选”“覆盖检查”“覆盖不足时”“受限批量重选”“移出损失”“补入收益”“细分单元配额不变”“支持优先，出现其次”“复核择集”。

这些是候选标签，不必全部出现。数量设置、参照门槛来源、求解细节与失败原因可放图注，避免再次把总图画成说明书。

## 8. 对上一版图的具体取舍

上一版用真实的 200 个成员前后对应，能够核对保留与改动身份，但它重复了大量成员图标；“联合核算”仍主要依靠文字，尚未把状态支持的净变化画出来。

后续重绘宜压缩完整成员阵列，展开一个真实细分单元，把同一批次的移出贡献、补入贡献与调整后支持放在一处。不能把整批实验的平均覆盖收益标到这一个局部替换上，也不能由两张照片推断整个集合必然达标。
