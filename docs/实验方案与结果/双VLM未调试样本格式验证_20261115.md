# 双 VLM 未调试样本格式验证（2026-11-15）

使用未参与前两轮调试的60张冻结原图：六类的 selection/reference 各5张。每张执行原生协议；horse、sheep、person、car另执行细粒度协议，共100个语义任务、A/B各一次，总计200次调用。

预设的200/200结构可用条件：未达到。独立审计从200份原始响应重放，计数一致。

规范化仅作用于 native `evidence` 中 schema 要求字符串、模型却返回非空字符串数组的字段；使用紧凑 JSON 文本保存，可由 `json.loads` 无损恢复。任何 feature、fine 字段、样本身份和语义取值都未修改。

该结果只验证格式与传输可用性。A/B字段一致不等于标注正确；完整标注、选样和分类器推理尚未启动。
