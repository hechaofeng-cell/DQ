# 跨VLM核验结果（2026-11-12）

核验按用户要求全自动执行。A为Qwen3-VL 30B，B为SenseNova 6.8 Flash Lite。两套答案独立保存，任一模型都不作为语义真值；本轮检验一致性及下游结论对标注来源的敏感性。

**核验结论：标签来源对结果有明显影响，现有证据不能支持“方法结论不依赖VLM来源”。**原Qwen P20选集在Qwen标签下293/300次达到冻结门槛，改用SenseNova标签核对同一门槛后仅6/300次达标；即使用SenseNova自身重标定的评价门槛，也只有47/300次。重新按SenseNova标签选样和重标定后，P20相对随机选样仍有收益，但不能据此宣布两套标签可互换或一致优于Greedy20。

## 数据与执行范围

- 当前COCO候选池2,400个目标（每类400），历史Objects365参考池1,200个目标（每类200）。
- 校验并复用7,200份原生字段历史标注；另复用2,400份Qwen细粒度标注，新增2,400份SenseNova细粒度覆盖标注，逐目标配对马、羊、人、车四类。
- 新标注使用原冻结字典、原语义提示及逐目标原证据图；不提供Qwen答案、分类器输出或选样结果。
- 格式不合规时只重试原目标；最后10个车类枚举违规目标使用严格schema请求及原字典“其他主色”判据重述，实际模型答案保留，不在本地映射标签值。
- 每类选200，最多移出20个原成员，保持各自标注来源所定义的精细风险单元配额，沿用50个历史选样起点。
- 分类器沿用5模型×3种子冻结预测；没有重新训练或新增分类器推理，也没有人工核验。
- 原生字段缓存使用历史模型别名和提示，包含旧版截断措辞；新增覆盖字段在本轮真实调用。不是所有字段都在同一天重新标注。

## 1. 状态标签是否可互换

原生字段共67,800条配对记录，精确一致率为**61.12%**（包含unknown）。新增细粒度字段共33,600条配对记录，精确一致率为**60.29%**。这些比例不等于标签准确率。

双方均已知时，原生字段一致率为62.69%（65,267条），细粒度字段为65.62%（23,933条）。这两个子集由模型输出决定，不能当作全体标签准确率，也不能忽略被排除的未知记录。

| 原生字段 | 目标数 | 精确一致率 |
|---|---:|---:|
| 整体可见性 | 3,600 | 51.11% |
| 头部可见性 | 3,000 | 80.63% |
| 腿部可见性 | 3,000 | 69.53% |
| 头部朝向 | 3,000 | 64.83% |
| 遮挡程度 | 3,600 | 47.61% |
| 截断程度 | 3,600 | 46.58% |
| 身体朝向 | 3,600 | 46.42% |

分字段表同时报告双方unknown比例、双方均已知时的一致率、Cohen κ，以及集合字段的Jaccard。不因两模型一致就标记“正确”，不把分歧直接裁成SenseNova答案。

来源：`native_field_agreement.csv`、`specific_field_agreement.csv`、`native_value_transitions.csv`。

## 2. 风险分层是否稳定

候选池更换标注来源后，**56.79%**的目标改变Q层，**89.54%**改变精细风险单元。后者按单元含义（Q、分数、不确定性宽度）比较，不按独立编号比较。

|---|---:|---:|---:|
| 狗 | 11.42 | 0.778 | 54.75% |

Q层是类内相对排序，不是错误概率。单元变化不等于相同比例的配额或最终选集变化。来源：`risk_summary.csv`、`risk_per_target.csv`。

## 4. 可支持的结论与边界

- 原生字段的一致性与风险分层结果表明，当前自动标签来源具有明显敏感性，不能把两套标签当作可互换真值。
- 固定原Qwen选集时，P20相对Greedy20的历史重复弱条件数差，从Qwen评价下的+2.00条，变为SenseNova评价下的-0.84条。因此，本轮不支持P20在不同VLM评价下都优于同改动预算Greedy20的强结论。
- Qwen标签下，P20相对R的支持完成度变化为+2.92个百分点，历史重复弱条件变化为+17.94条；P20相对Greedy20为+2.00条。
- SenseNova标签下，P20相对R的支持完成度变化为+2.42个百分点，历史重复弱条件变化为+9.14条；P20相对Greedy20为+0.42条。
- 本轮验证的是历史数据上的跨VLM稳健性；没有语义真值，所以不报告准确率，也不宣布分歧已经裁决。
- Objects365已用于历史分析；本轮重新标注或重算不能使其成为未见数据验证。
- 风险配额受控不保证实际错误率相同；重复弱条件更多也可能受错误数量和可评价支持变化影响，不证明失效根因种类增加。
- 标签压力测试、跨VLM复核、新数据验证回答不同问题；本轮只补齐跨VLM证据。
