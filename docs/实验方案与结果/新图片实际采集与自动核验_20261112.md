- 对最初 524 张原图及目标裁剪与全部 68,463 个历史唯一内容执行冻结规则的小规模实际去重检查。发现 2 对需要 ViT 确认的裁剪候选，4 张图像执行了去重编码，均未达到联合排除阈值。原图/精确 SHA/裁剪联合阈值共排除 0 张。该结果只适用于这 524 张，不能外推为全部 5,400 张通过。
- 18 项实现测试通过：采集 7 项、资格判断 4 项、自动接续与双模型传输 7 项。覆盖范围包括 gzip 尾部损坏、错误 Range、错误官方尺寸、重复成员、技术备份角色与顺序、两模型输入字节一致、数据关卡、丢失响应计入重试上限、鉴权失败停止及密钥脱敏。
- 实际使用的 27 份历史协议文件与已冻结准备包逐一核对 SHA，一致。严格 JSON Schema 校验依赖固定为 `jsonschema==4.23.0`，完整运行库版本记录于 `pipeline_runtime.json`。

## 正在运行的自动顺序

1. **采集冻结名单。** 共 18 个包、5,400 张原图，其中 4,800 张正式样本和 600 张技术备份。15 个缺失包需读取约 99.59 GiB。只在内存中顺序读取分块，保留目标图片和校验记录，不落地整个新压缩包。提取但尚未读完来源包的图片不计为来源已验证。
2. **完整资格检查。** 全部来源通过后，执行历史及新池内部的 SHA、含镜像的原图 dHash、裁剪 pHash 与冻结 ViT 相似度检查。技术替补只能按已冻结的本类、本角色顺序使用。每类 selection/reference 各 400 张不足时停止，不靠标注结果换样本。
3. **独立内容审计。** 重新计算正式名单 19,200 个原图/裁剪/特征裁剪/标框图文件的 SHA，重新计算原图和裁剪的感知哈希，核对来源、官方目标、角色、替补顺序及历史/跨角色近重复排除。审计不调用 VLM 或目标分类器。
4. **六类双 VLM 小样本检查。** 资格和独立审计同时通过后，每类取正式 selection 池中冻结排名最先的合格样本。六类原生标注 × 两模型，加四类原始细粒度标注 × 两模型，共 20 个任务。使用 Qwen3-VL 和 SenseNova，任务文本、证据字节与验收 schema 相同；分别保留答案，不互相提示。每任务最多 3 次尝试，丢失响应也消耗尝试次数。鉴权失败立即停止；无法解决的任务保留并阻止后续全量运行。

步骤 2—4 已由独立后台接续进程接管。接续进程核对采集进程启动身份，避免误认复用 PID；使用进程锁避免重复启动；每个阶段前后核对代码与输入 SHA。若文件变化、采集中断、样本不足、审计失败或小样本检查失败，写入 `pipeline_failure.json`，不自动改协议继续。

**全量 16,000 个标注任务、选样和目标分类器推理尚未启动。** 小样本通过后仍需执行完整标注和历史选样适配复现，之后才能按冻结方案产生新的实验结论。小样本字段一致率只描述两个模型的一致性，不是人工真值或标注准确率。
