# 跨VLM分歧修订与复验方案

本方案回答：统一字典和证据呈现后，自动标注能否更稳定；方法收益能否在两套独立标签下保留。全程无需人工核验，不把任一VLM、多数投票或文字解释当作真值。当前仅完成方案和固定样本准备，尚未运行本方案的新标注。

## 既有证据与修订目标

依据已完成的[核验报告](跨VLM核验结果_20261112.md)，原生字段一致率61.12%，新增细粒度字段60.29%；原Qwen P20选集在Qwen标签下293/300次达到原门槛，改用SenseNova标签核对同一门槛后仅6/300次达标。固定原选集时，P20相对Greedy20的历史重复弱条件数差从+2.00条变为−0.84条。因此要检验协议依赖和门槛迁移，不能预设修订后P20应当获胜。

原报告及artifacts/cross_vlm_verification_20261112/保持原样。新规则、新标注和新结果单独版本化。原生风险字段与细粒度覆盖字段继续使用不同命名空间；不能因同名而覆盖彼此。

## 第一步：先修订有实际歧义的判据

优先处理遮挡、原图截断、整体／部位可见性、身体／头部朝向，并检查车类body_profile、light_shape等细粒度字段。后两字段历史一致率分别17.00%、24.33%，数值来自specific_field_agreement.csv按目标数加权聚合；低一致性只用来确定排查优先级，不证明哪套答案错误。

| 字段或机制 | 需要固定的判据 | 自动核验方式与边界 |
|---|---|---|
| 遮挡 | 与模糊、光照、原图截断分开；正向遮挡要求指出可见遮挡物及目标部位；自身遮蔽另行定义 | 输出结构化遮挡来源与部位；检查逻辑矛盾，不能仅凭解释文字证明图中确有遮挡物 |
| 截断 | 只依据原图边界；裁剪图边界不是截断；原框接触边缘不自动等于截断 | 原图尺寸和框坐标由程序提供；框位置是辅助证据，不默认框内侧即可证明完整物体未出画 |
| 部位可见性 | 区分轮廓可见但细节不清、被遮挡、原图外缺失、正常视角不呈现、无法判断 | 输出可见状态及原因；unknown与其他状态排他；不同原因不得被统一重写为同一个答案 |
| 朝向 | 身体与头分别判断；明确左右是相机／图像坐标还是目标自身坐标；固定侧面和斜侧的判定规则 | 两模型共享完全相同的定义及例示文字；证据不足保留unknown |
| 色彩及集合字段 | 合法ID、other类别、数组类型和互斥规则直接进入schema | 两模型使用相同约束；不允许模型A合法色名被模型B的另一套字典替代；不在本地映射非法答案 |

现有run_qe_full_fine_annotations_v5.py已实现部分澄清，但它属于另一套全量细粒度协议，不能直接替换本次历史评分输入。其“框完全位于原图内部→截断必须none”的强规则，以及按解释关键词拒绝回答的规则，均需单独审查：不能把这些程序规则产生的吻合当作语义正确的证据。烟雾与实体遮挡可以共存，解释中出现“模糊”等词也不自动使实体遮挡不成立。

第一轮保留已有字段和枚举，只澄清含义与输出格式。不为提高一致率而删字段、合并类别或改风险权重。如果确有字段不可操作，应另立字典版本和研究决策，不能在同一对照中悄悄改变任务。

## 第二步：240目标的小规模配对试验

固定六类各40目标：COCO每类30、Objects365每类10，按旧Qwen风险Q1–Q5等额抽取，不读分类器预测，也不按两模型是否一致挑样。源图全局去重。分为开发120目标和锁定复核120目标，每组六类各20、COCO90及Objects36530；复核组在本轮修订期间不用于调规则。由于原图和历史结果已使用过，这不是新数据验证。

准备脚本：scripts/prepare_label_protocol_pilot_20261112.py。固定清单及输入哈希：artifacts/label_protocol_pilot_20261112/。

模型为现有Qwen与SenseNova。先记录本地模型digest、远端实际返回的模型标识／可得版本、调用日期、解码配置、完整提示、schema及逐目标证据哈希。两模型看相同目标和视图，彼此答案不可见，分类器及方法结果不可见。远端别名无法保证权重版本时如实记录。

开发组：两模型各按旧语义协议和候选新语义协议标注同一120目标，共480次基本请求。旧、新协议使用相同的严格输出约束和证据视图，区分语义修订与格式约束；历史缓存另作参考，不能取代同时期旧协议对照。源别旧提示若本来不同，需分别保留、注明，不能声称完全隔离了模型因素。

最多一次语义修订，仅允许依据开发组的输出冲突、逻辑违规和未知原因调整。冻结最终规则后，锁定组再做相同两模型×两协议对照，共480次基本请求；完整小试验基本请求上限960。无法在上限内完成的答案按缺失保留，格式／网络重试另记次数、成本与失败率，禁止无限重试到答案吻合。锁定组出结果后不再调本轮规则，不自动全量扩展。

先选每类1个开发目标做真实调用烟测（包含在上述预算内）；验证目标绑定、合法ID、原始响应与保存标签一致、没有跨模型答案泄漏后，再跑余量。统一证据解释可以作为修订，但不能给第二模型第一模型的答案。

## 第三步：预先定义“修订有效”，不只看一致率

主要比较各字段新旧协议的配对变化，同时报告每类、两数据池和旧风险层结果：

- 包含unknown的精确一致率、双方均已知时的一致率、双方均已知的比例、双方各自unknown率、集合Jaccard、枚举／格式失败率。
- 两模型内部的旧→新状态转移，及新版跨模型风险分数差、Q层变化；字段定义不变时保持原评分规则。
- 逻辑违规率仅衡量规则符合性；解释是否符合规则不能冒充图像语义准确率。
- 按源图成组、保留模型与协议配对的2,000次bootstrap；按类别和来源分层。报告区间及支持量；小样本字段标记证据不足，不据点估计宣布改善。

采用以下预定的工程筛查标准，不能称为准确率或普适科学标准：每个优先字段锁定组均已知一致率至少提高5个百分点，且双方均已知比例下降不超过5个百分点；同时展示完整一致率及其区间。如果旧协议双方均已知记录少于30，或原本已达到95%，该字段只报告描述结果，不套增幅门槛。明显增加unknown、某类退化或区间不支持明确方向时记为混合／不足，不能只保留有利字段。达标仅说明值得扩展验证，不能据此选定某个VLM作为真值。

失败后的处理事先限定：记录残余分歧；不添加第三模型投票后将其称为真值，不将一致子集替代全样本主分析。可以将不稳定字段退出主结论，但这属于明确版本化的研究范围调整，不能作为本轮“修订成功”。

## 第四步：通过小试验后再做方法复验

先在原3600目标池进行完整新版双VLM标注，再沿用每类选200、最多移出20、相同起点及R／C20／Greedy20／P20。标签和门槛在读取本轮分类器结果前冻结。旧历史结论与新版结果分表，不用新版结果覆盖旧版失败。

必须区分三个问题：

1. **只换评价标签**：固定同一选集、风险单元和方法，分别用两套覆盖标签评价。这回答评价来源敏感性。
2. **只换覆盖标签**：风险组织、初始集合、配额和预算固定，仅更换覆盖标签来重选。来源各自门槛使用相同的、预测不可见的G×0.95规则。另保留同数值门槛对照。这回答覆盖输入及其预定标定规则的影响，不能把来源独立标定解释为同一绝对任务。
3. **换完整来源**：风险组织与覆盖标签一起改变，按各来源重选，并在A/B发现与A/B历史参考四种组合中评价。这回答完整流程敏感性，不能归为某个单字段的因果作用。

覆盖指标、实际错误率、可评价支持量、弱条件提案数／历史重复数及求解状态同时报告。P20相对R和Greedy20都做同起点配对；50起点来自同一个池，不当作50个独立数据集。未达标、不可行、效应反转和逐类失败均保留。

如果相对随机选样的收益保留、相对Greedy20没有稳定优势，论文只陈述前者及具体适用设置，不改变论文中心论点，也不以追加调参追求P20获胜。

## 独立新数据验证另立一次冻结试验

历史修订完成后，另建未参与规则开发、门槛标定及模型／方法选择的图像池。先按源图哈希与可得来源ID排除历史重复，并报告去重边界，再冻结字典、模型版本、评分、预算和评价规则，执行一次自动验证。诊断条件在发现集提出，在独立参考集检查，两者均不用于回调字典。新数据上仍是自动标签与方法稳健性验证；没有语义真值时依旧不报告人工意义上的标签准确率。

本阶段不新增模型、不训练分类器、不启动大规模标注。准备工作的完成标准是方案、确定性样本清单和输入哈希可复查；后续运行的完成标准是按上述预算执行并如实报告所有结果，而不是一致率或P20优势必须提升。
