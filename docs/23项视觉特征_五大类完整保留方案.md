# 23项视觉特征：五大类完整保留方案

早期dog_v3.1的23项特征是一套细粒度描述协议；当前风险评分使用五个整体字段。两者用途和粒度不同，某字段未进入当前评分不代表该特征错误，也不能据此认定其标注准确性或诊断价值。为了保留全部23项并沿用五个大类，本方案扩展尺度、可见性和朝向三个大类的范围，采用“尺度与场景、可见性与可见外观、遮挡、截断、朝向与姿态动作”的组织结构。

本文档是特征组织修订方案。它完整保留早期字段标识、枚举值与依赖规则；当前分类器、标注缓存、共享状态矩阵及风险评分代码尚未因此改变。早期23项为犬类协议，其他类别需使用相应的部件和字段，不能将尾巴、毛发等字段强制用于车辆。人物头发字段也不是这23项犬类字段的一部分。

| 五大类 | 早期字段数 | 具体字段 |
|---|---:|---|
| 尺度与场景 | 1 | 场景 |
| 可见性与可见外观 | 14 | 毛发颜色、毛发图案、毛发质地、头部可见性、耳朵形状、口鼻部可见性、嘴部可见性、眼睛状态、嘴部状态、舌头可见性、身体外形、腿部可见数量、尾巴可见性、犬体可识别性 |
| 遮挡 | 2 | 遮挡程度、遮挡部位 |
| 截断 | 2 | 画面截断程度、截断部位 |
| 朝向与姿态动作 | 4 | 头部朝向、身体朝向、尾巴姿态、姿态动作状态 |

早期字段总数为1＋14＋2＋2＋4＝23。新增尺度、整体身体可见性等另记为扩展字段，不计入这23项。

## 尺度与场景

尺度维度扩展为目标的空间呈现与场景上下文。新增目标尺度仍按官方框面积占比描述，早期场景字段单独作为上下文子组保留；场景不等同于尺度，也不自动转换为尺度风险。

| 字段 | 标识 | 类型 | 全部枚举值 |
|---|---|---|---|
| 场景 | scene | enum | indoor_home / indoor_pet_store_or_clinic / indoor_other / outdoor_grass / outdoor_street / outdoor_park / outdoor_forest_or_wild / outdoor_beach / outdoor_snow / outdoor_water / outdoor_other / vehicle / multiple_scenes / unknown |

- 可见情况：头部可见性、口鼻部可见性、嘴部可见性、舌头可见性、腿部可见数量、尾巴可见性。

- 可见外观：毛发颜色、毛发图案、毛发质地、耳朵形状、身体外形。

- 面部局部状态：眼睛状态、嘴部状态。

- 整体可识别性：犬体可识别性。

朝向维度扩展为身体朝向、头部朝向、尾巴姿态和整体姿态动作。朝向与动作分别保留字段，不将站立、奔跑等动作换算成观察方向。

## 既有字段依赖

鼻子、吻部和口鼻区域整体；mouth_visibility仅表示上下颌、嘴角或嘴缝。

tail_visibility=not_observable时tail_posture必须为unknown。

mouth_visibility=not_visible时mouth_state和tongue_visibility必须为unknown。

none和unknown不能与其他部位同时出现。

dog_recognizability独立评价犬体主体是否足以识别；严重遮挡或截断不自动禁止reliably_identifiable，只有犬体主体无法确认时才使用not_identifiable。

已知室内但无法细分使用indoor_other；已知室外但无法细分使用outdoor_other；已知水边、湖边或河边使用outdoor_water；只有无法判断室内外时使用unknown。

## 在测试中的使用方式

1. 覆盖与条件评价：将23项的“字段—已知枚举值”用于状态支持统计、覆盖引导选样和分类预测后的条件评价，保留unknown。各类别使用适用的专用字段，并明确各类别状态词表与分母。进入实际分析前，需要核对目标ID对应的23项标注是否存在、是否有效；缺少字段时重新标注，而不是从整体字段推断。

2. 风险分层：五个大类不等于五个数值。可以在保留全部细项进行覆盖与诊断的同时，继续用原来的五个整体字段生成风险分数。毛色、耳形、场景等字段不应未经实验依据就被设定为高风险或低风险。

3. 版本兼容：早期遮挡与截断使用none／partial／heavy，当前规则使用none／light／moderate／heavy；早期朝向也有更细的斜向值。复用早期数据时必须明确版本映射，不能将partial直接当作moderate。尺度和整体身体可见性是当前评分另需的字段，不能假设早期23项已具备。

4. 如果希望局部可见性、部位遮挡或姿态动作也影响风险分层，需要另行定义聚合、权重、unknown和重复信息处理规则，并重新验证分层与模型表现。本文档不为这类尚未验证的聚合生成数值权重。

5. 重做评价范围：将23项纳入当前覆盖或选样会改变状态词表、覆盖分母及选样增益，因此相关覆盖、选样和条件报告需要重新计算。若被测模型与推理输入不变，原有逐目标分类预测可以复用。

## 可用于正文的表述

为保留局部可见性、可见外观和姿态动作等细粒度信息，本研究拟将原有特征按五个大类组织：尺度与场景、可见性与可见外观、遮挡、截断、朝向与姿态动作。以犬类协议为例，保留毛发、头部面部、身体、遮挡截断与场景相关的23个具体字段，并逐字段定义有限枚举状态。大类用于组织字段，具体状态用于覆盖与条件评价；风险评分另由预定义的整体尺度、身体可见性、遮挡程度、截断程度和身体朝向计算。局部字段及外观状态不因归入某一大类而自动获得风险权重。

上述正文使用“拟”表示尚待落实的组织方案；标注与分析完成后，应按实际使用范围更新时态和字段数量。
