# 3.2 视觉条件定义与状态表示

> 本节为两阶段方案的方法草案；类别字段生成环节尚待实现与验证。

为了分析模型在不同视觉条件下的识别表现，需要先明确观察哪些属性，再将图像中的属性表现记录为统一状态。本节采用“类别特征字典构建—图像状态标注”两个阶段：第一阶段确定某一类别需要描述的字段及状态词表，第二阶段依据该字典逐目标标注。同一个本地视觉语言模型可承担两阶段任务，分别使用字段生成提示和图像标注提示。

## 3.2.1 候选特征与字段生成

第一阶段向模型提供目标类别、其他待测试类别、通用视觉条件定义和字段设计要求。提供其他类别是为了明确区分对象，例如，犬与猫的区分需要关注相近动物的外观差异，犬与车辆的区分则涉及更明显的结构差异。模型据此提出两类候选特征。

**类别区分特征**描述可能有助于区分类别的外观与结构属性，例如犬类的口鼻形态、耳部形态、身体比例和被毛特征。模型需说明属性的可观察内容及其相对于其他类别的区分依据。这些属性允许类别内部存在差异，不要求所有犬类目标都呈现同一种耳形或被毛，也不将单一属性作为类别判定规则。

**通用视觉特征**描述不同类别均可能出现的呈现条件。尺度、可见性、遮挡、截断和朝向作为五个核心维度，模糊、光照及背景复杂度等作为关联条件。核心维度沿用统一定义，其下的部位字段根据类别结构设置，例如动物描述头部、躯干和肢体，车辆描述车头、侧面和车轮区域。

| 维度 | 定义 | 字段示例 |
|---|---|---|
| 尺度 | 官方目标框面积与原图面积之比 | 原图目标尺度 |
| 可见性 | 目标整体及部位的可观察程度 | 头部、躯干、车轮区域可见性 |
| 遮挡 | 目标被其他可见物体遮蔽的情况 | 遮挡程度、部位、来源 |
| 截断 | 目标超出原始图像边界造成的缺失 | 截断程度、部位 |
| 朝向 | 目标整体或部位相对于观察视角的方向 | 身体朝向、头部朝向 |

模型将候选特征转化为字段，每个字段需包含名称、定义、所属维度或属性类型、允许状态及判断依据。例如，“口鼻形态”描述外观结构，“口鼻可见性”描述该部位是否可观察，二者分别记录。外观与结构属性单独归类，不强行纳入五维。字段设计限定为静态图像中可观察的属性，避免加入无法直接观察的行为意图、习性或内部属性。

## 3.2.2 字段检查与字典固定

模型生成的是候选字典，正式使用前需要检查与修订。程序检查字段是否齐全、标识是否重复、状态词表是否完整；方法设计者审核类别适用性、字段含义和状态划分。例如，将同义字段合并，将含义过宽的字段细分，删除无法从图像稳定判断的属性。模型提供的区分依据作为候选解释，其实际区分作用需要后续验证。

随后使用少量样本试标，检查目标部位是否适用、状态之间是否容易区分，以及是否频繁出现信息不足。发现歧义时修订字段定义或判断依据，再固定类别字典。涉及程度或比例的状态需给出判定依据；尚无可靠边界的细分状态保留为待修订项，避免仅列出“长、短”等取值而缺少解释。试标与修订均不依据被测分类器的预测调整字段。

共用字段保持统一定义与状态，类别专用字段依据结构设置；最终字段数量由保留的字段确定，无需各类别相同。字典在正式标注和选样前固定，同一类别的所有目标使用同一版本。新增类别时，沿用共用规则，重新生成并检查类别专用字段，再建立独立字典。记录生成提示、模型版本、修订内容及最终词表，使字段来源可以追溯。

## 3.2.3 图像状态标注

第二阶段针对每个官方标注目标，提供固定的类别字典、原图、目标框标记图和放大裁剪图。原图提供场景与图像边界信息，标记图明确待描述对象，裁剪图展示局部细节。模型按字典填写全部字段，并为状态提供简短观察依据，不随单张图像新增字段或自由改写状态名称。

尺度由程序依据原图计算，面积占比小于1%为极小，1%至不足3%为小，3%至不足10%为中，10%及以上为大。截断按原图边界判断，放大裁剪图的边缘不作为原图截断证据。遮挡需要存在可见物体遮蔽，模糊与光照不足通过对应字段描述。整体与局部可见性分别观察，头部朝向与身体朝向分别记录。

无法可靠判断的字段记为 unknown，不能将未知解释为无遮挡或完整可见。适用部位明确不可见时，记录相应不可见状态；正常视角不呈现的部位，仅在字段字典允许时使用对应状态。允许多值的字段按集合记录，例如同时存在多个遮挡部位。

输出需检查字段完整性、取值合法性、目标对应关系及字段间冲突，未通过检查的记录重新标注或保留为待处理。格式检查不等同于语义准确性验证，状态标注质量仍需通过样本复核评估。最终记录与目标ID及官方类别绑定，保存字段取值、观察依据和字典版本。模型在这一阶段不读取分类器预测，也不直接输出风险分数。

## 3.2.4 状态表示与分析用途

将“字段—取值”对定义为一个状态。下面以一个犬类目标说明两类特征如何共同进入记录，内容为示意，形态字段及取值尚待字典构建阶段确定。

| 特征类型 | 字段 | 示例状态 |
|---|---|---|
| 类别区分属性 | 口鼻形态 | 细长 |
| 类别区分属性 | 耳部形态 | 下垂 |
| 通用视觉条件 | 原图目标尺度 | 小 |
| 通用视觉条件 | 头部可见性 | 清楚可见 |
| 通用视觉条件 | 遮挡程度 | 部分遮挡 |

一个目标可以同时支持多个状态。覆盖统计在各真实类别内计算支持数，同一目标对同一状态最多贡献一次支持，unknown 不计为已知覆盖。覆盖分母依据固定字典中的有效状态集合确定，不因某一状态尚未出现而将其删除；不同选样方法使用同一字典进行比较。

类别外观、结构属性和通用条件均可用于覆盖统计与条件评价。覆盖选样补充支持不足的状态，条件评价将状态与分类预测关联，分析相应条件下的识别表现。风险组织仅使用评分协议明确的字段及映射，不因某个属性具有区分依据就自动赋予高低风险；具体评分在后续小节定义。单字段覆盖不代表所有状态组合均已覆盖。
