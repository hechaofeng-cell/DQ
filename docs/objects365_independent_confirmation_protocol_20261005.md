# Objects365独立来源确认：预先冻结方案

日期：2026-10-05。用户授权范围：仅补强优先级最高的新来源确认，不新增人工复核、训练、模型或统计模型调优。

## 研究问题与范围

在不同数据集发布来源的未用目标上，既有风险层性能差异及A发现的薄弱状态能否复现？保持原六类任务、24份分类器权重、状态协议、双VLM、风险定义及指标。Objects365在本研究历史池中未被使用，但仍需排除重复照片；不同数据集名称本身不保证照片独立，也不能排除ImageNet预训练图像重叠。

## 数据来源修订

原未用Open Images计划因历史排重后sheep不足停止；本次用户授权补充新来源。改用Objects365 v2 validation。官方来源说明见[Objects365](https://www.objects365.org/download.html)，公开数据接口来自[MMDetection维护者的下载实现](https://github.com/open-mmlab/mmdetection/blob/main/tools/misc/download_dataset.py)。先检查完整标注、六类映射和可用图像数，再下载目标所在分包。不下载全量训练集，不自动换到其他来源或降低每类数量。

正式六类：dog、cat、horse、sheep、person、car，分别只映射官方Dog、Cat、Horse、Sheep、Person、Car；不合并SUV、Truck、Donkey等。每图只选一个目标，每类400图，共2400。每类最多60技术替补。目标框来自官方标注，不让VLM选择框。按图像面积比例至少0.001、合法框、非crowd和非ignore筛选；同类别同图取最大合法框。Objects365不存在的Open Images depiction/inside属性不得虚构；数据来源的标签资格差异单独报告。

抽样种子20261005。按照SHA256(seed,source,class,image_id)排序，类别按合格数量从少到多分配，图像不跨类重复。各类预定排重候选最多900；去重后按顺序取前400和最多60替补。下载/损坏/重复仅为技术排除，不读取分类正确性、VLM unknown或状态困难程度选图。若不足400，停止在分类预测之前并保存审计。

历史排除范围包括既有训练、验证、测试、发现、确认和候选清单。原图与裁剪精确哈希排除；近重复沿用pHash汉明距离≤4且ViT余弦≥0.980，或距离≤8且余弦≥0.995。全新池内部使用相同规则。图像来源ID无法跨数据集直接比较，必须检查实际文件。哈希未匹配也不能证明照片毫无关联。

## 模型与标注

### 元数据审计后的split修订（新预测前）

完整validation元数据仅含227张合格sheep图像，初始验证集方案不满足预算；数量审计保留。改查同一Objects365 v2的train发布分包，**仍仅作冻结分类器的测试输入，不训练**。先按SHA256(seed,source,"package",patch)对全体分包排序，选第一个达到每类至少600个合格目标图像的前缀；累计分包不得超过40GiB，下一分包超限时停止，不按模型结果或低价分包跳选。只在该前缀内依原图像排序和排重规则构建每类400图；不混入validation补足。该池是预定分包前缀条件下的确认样本，不代表全Objects365自然分布。若前缀仍不足，记录失败而不自动放宽。

2026-10-05 15:07（新分类预测与新状态标注前）：完整train标注中合格sheep图像3514；初次40GiB前缀为7包、37.64GiB，仅含379张sheep。记录并保留初次审计后，将本轮图像分包上限一次性修订为80GiB；当时文件系统剩余约330GiB，分包及恢复分块即使同时保留也可容纳。仍按原SHA256分包顺序和≥600/class停止规则，不跳包、不选模型错误、不再次提高上限。以下执行预算以80GiB修订为准，保留上文初始预算作为历史。

原8架构×3种子，24份权重不变；分类输入沿用5%扩框裁剪及原预处理。双VLM分别采用原本地Qwen3-VL和线上SenseNova适配器、原三视图及原严格枚举校验。保存每次请求与响应。每图最多两轮已有技术重试流程，仍失败仅按同类、同程序尺度优先的冻结替补顺序替换；不得因为标签分歧或unknown删图。没有新增人工状态真值验证。

候选清单、代码、配置、模型权重和原A薄弱状态清单在新分类预测之前保存哈希；严格标注完成后冻结最终图像清单和选样计划。使用独立目录artifacts/objects365_independent_confirmation_20261005，保留原A/B/C及失败的D阶段。

## 主要与次要结果

主要确认：两来源下完整类别内五层（每类每层80目标）的Macro-F1、Accuracy、Macro-Recall，Q5−Q1及原6项风险检验族；unknown中点主结果，上下界敏感性。风险层是本类别相对排序，不保证逐层下降。

冻结状态确认：沿用A的175条类别/状态/模型组合，不基于新预测重选。状态支持至少20，沿用既有参考与聚合实现。先导出两标注来源的支持表，再运行分类；完整报告复现、未复现和不可评价结果。一般池不会保证所有低频状态≥20，不能将不足支持伪装为“迁移失败”，也不无限追加样本直到得到支持。

次要：原Coverage、1000次Random、DeepGini、DSA、k-center、删字段Coverage；共同风险配额和精确风险匹配分开报告。预算每类20/40/60/80/100，即总体120/240/360/480/600。等错误数诊断广度及原五点AUC、原主要4项/强基线12项/全20项检验族全部保留。不把不显著改写为零效应，不增加独立架构数。

采用原架构/种子区间和源图重采样结果；不重跑未收敛GLMM来寻求显著性。不新增训练或修复实验。图表保留真实点。新池状态覆盖分母仍为该池的预定义可行状态集合，不直接与旧池覆盖百分比比较。

## 预算、完成和停止

完整元数据约270MB，先验证HTTP字节范围/完整长度和JSON，再统计类别。下载仅候选所在validation分包，运行前统计字节预算；本轮图像分包上限40GB、正式目标2400、替补最多360、成功状态响应至少4800、固定模型预测57600。下载保留可恢复分块，完整后仅提取预选图片；不运行全量数据集下载器。

只有输入排重、双标注、24预测缓存、风险/状态确认和完整负结果报告通过后才称实验完成。中间日志、阶段状态与失败均保留。若获取失败、数量不足或技术替补耗尽，明确报告未完成，不填入计划数值。

补强结论按真实结果决定：风险差异复现但弱状态支持不足时，只增强风险层关联证据；状态复现时增加对应条件的外部证据；若不复现，保留该条件的来源限制。无法保证录用或Coverage普遍优势。
