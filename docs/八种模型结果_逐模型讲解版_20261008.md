# 8种模型，分别看成绩

补充到进度汇报中：每种模型单独展示，数据来自已经保存的最新核验结果。

8个模型名字代表8种图片分类模型，每种都有3份已完成的训练结果，共24份。它们负责判断狗、猫、马、羊、人和车；两套AI负责描述状态，是另一项任务。

图M1  在每批全部目标上计算的F1，再对同一模型的3份训练结果取平均；满分100，越高越好。

![图M1  在每批全部目标上计算的F1，再对同一模型的3份训练结果取平均；满分100，越高越好。](/home/hcf/.codex/worktrees/2fec/QE/artifacts/model_results_report_20261008/figures/01_eight_models_overall.png)

## 先看这个总览，再看后面8页

每行是一种模型，每列是一个图片来源。这里计算的是整批目标的总体分，不是把五组F1简单平均，也不受采用哪套AI分组影响。

## 当前结果可以怎样讲？

“我比较了8种模型。当前三批目标上，ConvNeXt-Tiny的平均总体F1最高。但总体高不代表各类图片都一样好，后面要看每种模型在五组中的具体变化。”

这只是本任务和已测目标上的数值比较，没有据此证明某模型在所有任务都最好，也没有进行模型优劣的显著性检验。

“ResNet-18在COCO全部目标上的平均F1是84.2分，但较困难组只有68.0分。把它单独展开，就能看到总体成绩没有反映出来的条件差别。”

同一个分组中还可以比较不同模型；组间分差较小不自动表示模型更强，要同时看总体分和困难组的实际分数。
