# 特征覆盖缺口驱动的定向图像生成：拟议方案

状态：方法设计建议，尚未实现或验证生成模块。已有覆盖缺口驱动的真实候选池补样不等同于生成新图像。

## 可用于引言的表述

为此，本文围绕预先定义的目标视觉状态空间，研究一种基于目标特征覆盖的测试集充分性评价方法。首先，构建由目标尺度、身体可见性、遮挡程度、截断程度和身体朝向组成的评价框架，并为不同目标类别定义相应的细粒度特征。其次，利用视觉语言模型对测试图像中的目标进行特征标注，依据预先确定的映射规则计算五维状态分值，建立候选风险分层。最后，依据预先规定的特征状态及最低样本需求计算特征覆盖率，识别缺失或证据不足的测试条件。该评价刻画定义状态空间内的覆盖情况，不构成整个图像输入域完备性的证明。

针对上述覆盖缺口，拟进一步设计一种特征覆盖缺口驱动的可控图像编辑与生成方法。该方法将缺失的目标类别、特征状态和状态组合转换为结构化编辑条件，以真实图像为基础，结合可控扩散模型与几何变换生成候选样本；随后重新标注候选图像，核验目标状态、类别保持、图像质量与重复性，仅将通过验收的样本纳入合成补充测试集，形成覆盖诊断、定向生成、特征验证与覆盖更新的闭环。

## 五维条件与操作

| 维度 | 候选操作 | 验收重点 |
|---|---|---|
| 尺度 | 场景中的目标尺寸或距离调整、保持几何含义的缩放与合成 | 重新核验目标框、尺寸和评分所用比例；单纯放大显示不等同于改变目标尺度 |
| 可见性 | 定向编辑头部、躯干、肢体或车辆部件的呈现状态 | 正常视角不呈现、遮挡和截断分别标注；不假定五维彼此独立 |
| 遮挡 | 合成遮挡物或局部编辑遮挡区域 | 遮挡对象、部位和程度是否满足条件 |
| 截断 | 改变原始图像取景边界 | 不把分类器的紧裁剪边界误标为原始图像截断 |
| 朝向 | 使用目标朝向的结构条件进行生成或编辑 | 变化后的头部及身体朝向；不能用保持原姿态的结构图强制要求新姿态 |

生成图像应重新核验类别和目标框。原图的官方标注不能无条件继承。合成测试结果与真实数据测试结果分别报告。评价生成方案应同时考虑目标状态命中率、有效样本率、覆盖增量、相同预算下的错误发现收益，以及独立真实数据上的适用范围。
