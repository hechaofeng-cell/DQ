# 无人工复核的视觉状态测试论文补强方案

日期：2026-10-05。状态：方案稿，尚未启动本方案的新数据下载、VLM请求或实验。本方案按用户要求取消人工复核；作为下一阶段的工作方案，替代上一份建议中的人工校验分支，保留旧方案和全部既有结果。

## 1 目标与可行性判断

其他补强建议可行，但执行目的需要调整：扩大确认样本、检验自动状态协议的稳定性、验证冻结诊断条件、补充适当的统计分析，并交付可重复运行的测试资产。暂不新增模型训练，不把F1上升或更多显著结果作为完成标准。

核心论点保持为：**可见视觉状态组织与风险分层能够揭示固定分类器在不同测试条件下的能力差异，并提供总体指标之外的条件诊断信息。** Coverage相对其他选样方法的额外诊断收益仍是待检验、受条件限制的次要结论。

人工复核的缺席不会直接让已经测得的分类Accuracy/F1降低。分类指标根据官方类别与冻结模型预测计算；缺少人工验证主要影响自动状态标签、风险分层和状态解释的可信度。自动核对可以提供部分参考和稳健性证据，但不能证明全部状态标签准确，也不称为“零人工真值验证”：官方数据标注本身具有其原有来源。

## 2 固定对象与已有证据

| 项目 | 沿用内容 |
|---|---|
| 六类对象 | dog、cat、horse、sheep、person、car；person不改写成人脸类别 |
| 分类器 | ResNet-18、ResNet-50、MobileNetV3-Small、MobileNetV3-Large、DenseNet-121、EfficientNet-B0、ConvNeXt-Tiny、Swin-T |
| 权重 | 每架构三个既有种子，共24份冻结权重；不重新训练或挑选“表现更好”的种子 |
| 状态标注 | 本地Qwen3-VL与线上SenseNova分别标注，均保留原始三视图输入、响应及严格枚举校验 |
| 状态与风险 | 当前共享字段、程序尺度、五维H、unknown上下界及中点规则；五层为类别内等数量风险层 |
| 选样对照 | Coverage、Random、DeepGini、DSA、k-center和删风险字段Coverage；共同配额与精确风险匹配分别报告 |
| 历史数据 | A发现池；B为COCO独立样本池2400；C为VOC2007外部来源池600 |
| 冻结诊断 | A形成的175条状态—模型组合；涉及33个唯一类别/字段/状态，含标注来源为48项 |

现有B/C结果支持风险层条件性能差异，但不支持“逐层必然下降”“Coverage全面优越”或“所有弱状态跨来源复现”。B/C的状态复现、强基线、统一表征与负结果继续保留。

## 3 第一步：冻结补强协议与自动核对

### 3.1 在新分类预测之前保存配置

记录数据来源及split、六类映射、历史排除清单、目标框选择规则、去重阈值、抽样种子、候选预算、标注版本、权重与代码哈希、风险规则、状态支持门槛、检验族和技术重试上限。新增目录保存结果，不覆盖B/C。

VLM技术失败可以按事先保存的重试/替补规则处理；分类正确与否、unknown比例或VLM之间的分歧，不能成为删除样本或替换图片的理由。若来源可用数量不足，在读取新分类结果之前记录修订；不根据实验结果更换来源。

### 3.2 官方属性核对

先复用历史Open Images目标中的框级属性及双VLM结果；不足的字段仅在新增Open Images目标中补齐。官方格式提供IsOccluded、IsTruncated等框级属性，可按明确的二值映射对照。[官方格式说明](https://storage.googleapis.com/openimages/web/download_v7.html)

| 当前字段 | 冻结映射 | 输出及边界 |
|---|---|---|
| occlusion_level | none=0，light/moderate/heavy=1 | 对照IsOccluded；输出支持量、混淆矩阵、正负类一致率、kappa及区间 |
| truncation_level | none=0，light/moderate/heavy=1 | 对照IsTruncated；输出相同项目 |
| unknown/无官方值 | 不归为0或1 | 单独报告比例及不可核对数量 |
| 目标尺度 | 官方框面积/原图面积 | 重新计算，核对程序尺度、图像尺寸及框坐标 |
| 裁剪 | 冻结扩框及裁剪规则 | 核对原图、目标框、标记图和分类输入的目标一致性 |

上述标签取值以现有协议的实际枚举为准，运行前在配置中保存完整映射。官方属性对照是不同标注体系之间的参考一致性，不能据此宣称严重程度等级准确，更不能外推到头部朝向、背景复杂度等无官方参考字段。

按类别、数据split、官方属性正负类分别报告，避免大量无遮挡样本掩盖少数遮挡样本的分歧。IsDepiction、IsGroupOf等条件遵循既有候选资格规则并记录，不为得到更高一致率重新过滤。

### 3.3 双VLM与风险稳健性

复用已有响应，输出各字段一致率、unknown率、风险中点排序相关性及层级变动。共享14项字段与程序尺度分别处理；单值、多值字段分别使用精确一致率与集合一致指标。双VLM一致不等于两者正确。

预测结果按“一致/分歧/至少一方unknown”作描述性分组；这些组的错误率差不能解释为标注质量造成的因果效应。不只保留一致样本，不让第三个VLM投票冒充真值。

优先整理已完成的unknown上下界、删字段和风险敏感性结果。新增池按同一规则复评五次逐维删除及预定等权归一化风险；不从中挑选下降最明显的版本替换原主分析。

**产物：**官方属性对照表、字段分歧/未知率表、风险稳定性图、目标与输入审计报告。这一步回答自动协议的哪些方面有参考支持、哪些方面仍不确定。

## 4 第二步：新增一般确认池D

### 4.1 来源与规模

优先从Open Images尚未使用的目标建立D：六类各400个，共2400个目标。先仅做官方元数据可用性检查，再下载合格清单；不需要下载整个数据集。每源图一个目标，官方目标框和类别映射沿用，排除训练、验证、旧测试、历史候选及其近重复。

来源split、ID排序规则和资格过滤在抽样前保存。D的一般样本抽取不使用VLM状态、被测分类器输出或薄弱状态配额，避免把一般确认池变成困难样本富集池。

Open Images不同于COCO训练来源，但已经参与A发现。因此D是“不同于训练来源的未用图像确认池”，不是“从未参与规则形成的全新数据来源”。它主要补强新样本诊断复现；C的VOC独立来源证据继续保留。如果必须加入第三个全新来源，应单独先核对类别映射、许可、下载条件和可用数量，不能直接承诺ObjectNet或ImageNet-A能替代六类框级任务。

### 4.2 固定评测设置

1. 双VLM分别生成完整状态标签，不合并成所谓真值。
2. 每类五个风险层、每层80个候选；层内选择20个，累计预算为每类20/40/60/80/100，即总体120/240/360/480/600。
3. 24份冻结权重预测全部D目标；每个图像/训练run仅保存一次原始预测，预算分析复用预测。
4. 使用原共同配额、强基线、精确风险匹配和等错误数诊断流程；保留所有方向的差异。
5. 先用状态标签报告175条冻结组合的支持量，再读取新分类结果分析迁移；支持不足不降低门槛。

主要报告风险层Macro-F1、Accuracy、Macro-Recall及Q5−Q1差；辅助报告条件Recall和模型能力差异。Coverage的主要有效性指标继续为等错误数诊断广度及预算AUC，不以错误率或F1下降替代。

新池coverage仍以其预定候选状态空间为条件，不能把不同池的绝对覆盖百分比直接当同一标尺比较。图中同时显示预算、支持量和标注来源。

**产物：**D数据清单与审计、双VLM状态、24份预测、五层/五预算曲线、完整基线与状态复现结果。

## 5 第三步：低频条件确认套件E

D的400个目标/类无法保证低频状态达到支持门槛；因此一般池与状态富集套件分开设计。

### 5.1 预定条件与有限预算

在读取任何D/E分类预测之前，从A冻结清单预选至多12个“类别—字段—状态”条件，每类最多两个。按A中已冻结弱模型组合数量排序，同数时按预定字段顺序及状态名称排序；完整条件、标注来源和被确认模型清单保存。不得依据D结果改选条件。

E候选储备最多六类各300个，共1800个新目标，与D和历史数据按图像及近重复互斥。可以依据官方属性增加预定遮挡/截断候选，但不能用分类器错误挑图。全部储备双VLM标注；主要样本身份按事先指定的本地标签确定，线上在同一图像上独立评价，不只保留双VLM一致目标。

每条件目标为30个状态目标，加30个同类别非该状态参考；至多720个目标入选，条件间不重复使用源图。不满额时报告实际数量。状态支持和合格匹配各不足20时，该条件的相应确认记为不可评价，不无限扩充储备直至得到正结果。

参考按当前H中点及unknown维数共同支持匹配，同单元内按固定哈希排序。匹配不读取模型预测；若可用参考不足，不事后放宽匹配条件。按整体H匹配不等于全部视觉因素一致，也不构成因果隔离。

### 5.2 分开回答问题

- D估计一般候选池中风险/状态与模型表现的关联。
- E估计预定义条件在新目标中的相对表现，并检验旧诊断能否复现。
- E具有状态富集，不能与D合并计算自然总体F1或状态出现概率。

E主要报告冻结模型清单的状态Recall、参考Recall、配对条件差及支持量；先平均同架构种子，再对冻结架构集合等权汇总。单模型结果完整保留。线上字段与本地字段的支持量分别计算，线上不足20则不作相应线上状态确认；不能以本地支持代替线上支持。

以源图/匹配对为重采样单位提供区间，保留同一图像在全部固定模型上的预测相关性。若作多条件显著性声明，事先冻结条件×标注来源的检验族与Holm校正；不把每模型、每预算、每条件中任意显著结果汇总成统一成功结论。

**产物：**条件清单、支持/匹配可评价率、复现/未复现/不可评价表、失败与成功实例。E只确认预选子集，不声称验证全部175条旧组合。

## 6 第四步：统计补充，保留原主检验

### 6.1 逐图错误的混合模型

风险分析可增加二项GLMM。观测单位是唯一“图像×训练run”的0/1分类错误，两种标注来源分别拟合。初始候选规格为：

```text
error ~ risk_tier * dataset + class + architecture
        + (1 | run_id) + (1 | image_id)
```

架构固定，run_id为架构×种子；同一图像在多个模型上的相关性由image_id处理。风险层按分类变量处理，不预设线性下降。先冻结拟合实现、收敛检查、奇异拟合及替代规格，失败时报告不能可靠拟合，不按p值选模型。[GLMM作者文档](https://lme4.github.io/lme4/reference/glmer.html)

输出调整后Q5相对Q1的错误优势比、边际错误概率差和区间；这是条件关联，不是F1差的直接检验，也不保证提高统计效力。

### 6.2 诊断广度与方法对照

五预算先汇总为每run/池/来源/方法一次AUC配对差。F1、分数化期望广度和AUC不作为二项GLMM成功次数。1000次随机选择用于估计对照期望，不能充当1000个独立数据集。

继续保留原架构级精确检验、主次检验族和全20项结果。可预定AUC差的配对线性混合模型作为敏感性分析，先检查残差、异方差和收敛；如果新增非线性诊断的bootstrap推断，须先做零效应模拟检查偏差和误报率，校准未通过则不用于正式结论。不要因为新方法显著而删掉原不显著结果。

**产物：**效果量与区间森林图、类/池/标注来源异质性表、拟合诊断、主次结果对照。新增模型训练不是本阶段前提。

## 7 第五步：测试资产与论文呈现

将有足够支持的冻结条件导出为回归测试清单：类别、状态枚举、目标ID、目标框、输入哈希、标签来源、模型版本、预测分数、正确/错误及执行命令。重复执行同一权重与输入应得到可追溯结果。

正文增加2×3真实案例面板，展示两项预定条件的失败与同条件成功，并保留未复现反例。按固定ID规则取图，不生成替代样本，不把可见现象解释为已证实的模型内部根因。

## 8 执行顺序、预算和停止条件

| 顺序 | 工作 | 新VLM/模型工作量 | 完成标准 |
|---|---|---|---|
| 1 | 冻结配置、整理已有自动检查和负结果 | 优先复用缓存 | 配置、输入与证据可追溯 |
| 2 | 官方属性核对、双VLM/风险敏感性报告 | 历史缓存不足才补数据 | 对齐范围和剩余不确定性均报告 |
| 3 | D可用性审计、2400目标双VLM与固定模型评测 | 4800个成功标注响应；57600次目标×权重预测 | 六类清单冻结，方法及来源完整报告 |
| 4 | E储备与预定条件确认 | 最多3600个成功标注响应；入选最多720目标×24权重 | 条件完成或按门槛标记不可评价 |
| 5 | 统计补充与拟合审计 | 利用预测缓存，无新训练 | 不更换主检验，不因显著性改规格 |
| 6 | 图表、回归套件、论文与复现附录 | 利用缓存及实际图像 | 完整正负结果、成本与范围写入 |

上述响应数不包含技术重试，预测数不等于API请求数。不从中承诺运行小时数或货币成本：并发、下载与当前服务状况影响实际时长。开始运行后用真实进度日志估算剩余时间。

若合格来源不足，在新分类结果之前停止该数据阶段并保存数量审计；不自动改来源。E最多1800个候选，不因某条件未复现继续找图。统计拟合或校准失败如实报告。结论为负或不显著仍是完成结果。

当前优先完成1–3；4用于补足低频条件证据，5–6形成最终补强材料。微型修复与新增架构暂不加入执行包：本论文可以交付诊断与回归测试，不必同时承担模型改进研究。

## 9 补强后允许写的结论

若结果支持，可以写：在所评估的六类对象与冻结模型中，自动视觉状态协议组织的风险分层揭示了可重复的条件性能差异；部分预定义薄弱条件在未用样本中得到确认，并被导出为可复用测试资产。

Coverage对诊断广度的增益按实际基线、池、来源与控制条件分别陈述。若E只复现部分条件，写“部分”；若不复现或支持不足，保留边界，不把协议有效性与Coverage优越性混为一项。

不宣称全部视觉状态真值已验证、无人工校验不影响构念有效性、覆盖增加必然导致性能下降、全面优于强基线，或补强后保证录用。
