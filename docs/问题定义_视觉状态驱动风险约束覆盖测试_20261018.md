# 3.1 问题定义

图像分类模型的测试结果反映其在给定样本上的识别表现，而对测试结论的解释还需要明确这些样本包含哪些视觉条件。仅给出类别比例、样本数量和整体分类分数，仍无法判断同一类别内部的外观差异、目标可见情况及观察条件是否得到测试。例如，一个以大尺度、完整可见目标为主的测试集，即使获得较高的分类分数，也不足以说明模型对小尺度或重度遮挡目标的识别表现。因此，本文关注测试样本的视觉条件与模型识别表现之间的对应关系。

这里存在两个相互关联的不足。一方面，类别层面的样本均衡不等于类别内部视觉条件的充分覆盖。同一类别可能包含不同的外观、部件形态和呈现状态，仅按类别计数无法识别哪些条件缺失、哪些条件只有少量样本支持；增加样本也可能只是重复已有的常见条件。另一方面，整体分类指标将不同条件下的结果汇总，难以展示各条件之间的性能差异。因而，测试需要同时说明“哪些视觉条件获得了多少样本支持”以及“模型在相应条件下表现如何”，才能明确评价结论所依据的测试范围。

有限测试数量进一步增加了样本组织的困难：在总量一定时，为某些条件补充样本会占用其他条件的测试名额。同时，选入更多不同视觉条件的目标，也可能改变测试集的难度构成。如果不同测试集合的数量、类别比例与难度构成同时变化，就难以区分状态支持的差异与测试构成变化。因此，需要在明确这些约束的前提下研究样本选择，并分别评价条件支持和分类表现。

据此，本文将研究问题界定为：给定具有目标框和真实类别标签的候选目标集合，以及参数固定的图像分类模型，在有限测试预算和指定的类别、视觉风险构成下，如何组织测试目标，使预先界定的视觉条件获得更广泛且更充足的样本支持，并据此评价模型在不同风险条件下的识别表现。测试以目标框确定的单个目标实例为单位，研究范围包括测试条件的描述、受约束的样本选择与条件化性能评价。

该问题的目标是使测试集合的条件范围、样本支持和模型表现能够对应说明。所需结果包括具有明确条件构成的测试集、各视觉条件的样本支持情况及模型在不同风险条件下的分类结果。条件覆盖描述测试证据的范围，分类结果描述模型在所测条件下的表现；条件覆盖增加本身不能证明模型能力提高，视觉风险与实际识别表现之间的关系也需要通过实验检验。
