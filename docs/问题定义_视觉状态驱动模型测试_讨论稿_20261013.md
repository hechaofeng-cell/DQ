# 3.1 问题定义

> 本版按拟采用的两阶段方案调整；类别字段生成环节尚待实现与验证。

本文关注图像分类模型测试中，测试集合的视觉状态覆盖、视觉风险构成与模型识别表现之间的关系。仅以准确率、F1等整体指标评价模型时，可以了解模型在给定测试集合上的总体表现，但难以直接判断测试样本覆盖了哪些视觉条件、包含多少不同风险层的目标，以及模型在哪些条件下表现较弱。同时，测试样本总量不能直接说明视觉条件的覆盖情况：增加大量具有相同常见状态的目标，仍可能使其他状态缺少测试支持。例如，若犬类测试样本主要是大尺度、完整可见的目标，较高的整体识别分数仍不足以说明模型对小尺度、重度遮挡或背向犬类目标的识别能力。因此，模型评价需要同时报告测试条件与相应分类表现。

因此，本文需要解决的核心问题是：在给定测试样本数量下，如何依据视觉状态覆盖和风险构成组织测试，并将模型的整体表现细化为可复查的条件能力评价。具体包括：不同选样方法提供了多少状态支持；风险分层能否区分模型的识别表现，改变风险构成时测得性能如何变化；哪些视觉状态对应较弱的表现，以及相应薄弱方向能否在新数据中复现。这里，视觉条件包括两类可观察信息：一类是可能有助于类别区分的外观与结构属性，如口鼻形态、部件形态和身体比例；另一类是通用视觉条件，如尺度、可见性、遮挡、截断和朝向。类别区分属性的实际作用需要验证，通用条件中的五个核心维度用于风险组织。薄弱条件指具有一定样本支持、且模型识别表现低于对应类别总体水平的视觉状态。

每个类别的字段与状态词表在正式标注和选样前固定，不同选样方法沿用同一套字典。覆盖评价区分状态是否出现与状态获得多少支持。例如，“身体朝向—背向”是一个状态，具有该状态的目标数量为其支持数。状态出现覆盖率表示已有至少一个目标支持的状态占固定状态集合的比例；频次覆盖率表示各状态达到预设支持要求的程度，也称支持完成度。后者设置支持数饱和阈值，使常见状态的重复样本在达到阈值后不再增加该状态的覆盖贡献。两类覆盖指标均先在类别内计算，再对类别等权平均，并结合逐状态支持数定位需要补充测试的条件。覆盖衡量预定义状态的测试支持，模型识别能力和失败发现效果需要另行评价。

风险评价同时描述测试集合的构成和模型在相应条件下的表现。依据预定义视觉评分，在各类别内将目标划分为由低到高的Q1—Q5，报告各层目标数、比例和风险分数分布。随后计算各层的分类指标，并以Q1与Q5的Macro-F1差值描述端点性能差异。保持测试总量和类别比例一致时，进一步改变Q5目标占比，记录分类指标及模型排名随高风险占比变化的情况。风险分数用于组织视觉条件，高风险占比用于描述测试构成；模型实际表现由分类预测评价。

本文的测试对象为已训练的多类别图像分类模型，当前任务包含犬、猫、马、羊、人和车六个类别。给定带有官方目标框和真实类别标签的候选图像集合，以官方目标框确定的单个目标作为测试单位，评价目标裁剪区域上的分类表现。官方类别标签提供分类真值，用于判断预测是否正确；本地视觉语言模型（VLM）先根据目标类别、其他待测试类别和共用规则生成候选特征字段，经检查与小样本试标后固定类别字典，再根据图像描述各字段的状态；被测分类器对目标裁剪图输出类别预测，用于评价识别表现。字段构建与状态标注均不读取被测分类器的预测，生成的字段也不改变分类器的输入或参数。测试阶段保持模型参数和推理处理一致，通过选择样本与调整视觉条件构成，评价模型在不同测试条件下的识别表现。

围绕这一问题，本文开展三项工作。首先，在给定测试数量下优先选择能够补充支持不足状态的目标，比较不同选样方法的覆盖情况与获得的失败信息；在控制风险构成的对照中，各方法沿用共同配额。其次，依据预定义视觉风险组织测试，分析不同风险层的性能差异和风险构成变化下的性能响应。最后，将具体视觉状态下的识别表现与对应类别的总体表现比较，筛选薄弱条件，固定条件清单后在新数据中复查，判断相应薄弱方向是否再次出现。

本文按下表组织评价信息，具体计算定义在后续方法小节展开。

| 评价方面 | 指标或报告量 | 回答的问题 |
|---|---|---|
| 整体分类表现 | Accuracy、Macro-Precision、Macro-Recall、Macro-F1，以及各类别表现 | 模型在给定测试集合上的识别表现如何？ |
| 视觉状态覆盖 | 状态出现覆盖率、频次覆盖率（支持完成度）、逐状态支持数；总体及类别内覆盖 | 哪些视觉状态已得到测试，各状态获得多少样本支持？ |
| 视觉风险构成 | 风险分数分布、Q1—Q5各层数量及比例、高风险目标占比 | 测试集合包含怎样的视觉风险条件？ |
| 风险条件表现 | 各层分类指标、Q1与Q5的Macro-F1差值、不同高风险占比下的性能与排名变化 | 模型在不同风险条件下表现如何，测得性能如何随测试构成变化？ |
| 条件诊断与复查 | 状态条件Recall、相对类别Recall的差值、错误数量与失败信息广度、复查结果及支持数 | 模型在哪些状态下表现较弱，测试获得哪些失败信息，薄弱方向能否复现？ |

方法最终输出包含上述指标的状态覆盖、风险构成、条件性能与失败分析报告，以及薄弱条件复查结果。复查保留薄弱方向复现、未复现和样本支持不足三类情况。上述输出共同说明测试条件、模型表现与证据范围，为后续重点测试条件的确定提供依据。
