# 当前项目的方法、重点流程与画图提示词

更新日期：2026年10月10日

## 1. 当前方法定位

当前项目研究的不是新分类模型，也不是通过补图提高模型准确率，而是一套面向图像分类模型的**视觉状态风险分层测试与条件诊断方法**。

核心问题是：

> 当分类器权重保持不变时，测试集内部不同视觉条件的构成，是否会显著改变测得的模型性能；进一步，能否将总体指标拆解成可解释、可复现的薄弱视觉条件？

方法将三类信息严格分开：

1. **官方标注**提供目标框和类别真值；
2. **视觉语言模型（VLM）**只描述目标的视觉状态，不提供分类真值；
3. **冻结分类器**提供预测结果，只用于评价模型行为，不参与风险评分。

因此，论文的主要贡献位于测试协议、测试集组织和条件诊断，而不是分类器结构创新。

## 2. 输入、对象与输出

### 2.1 输入

- 六类固定目标：dog、cat、horse、sheep、person、car；
- 官方目标框与类别标签；
- 原图、目标框标记图和目标框放大裁剪图；
- 两个独立自动状态来源：本地Qwen3-VL与线上SenseNova；
- 八种分类架构、每种三个随机种子，共24个冻结分类器。

### 2.2 分析对象

分类器处理固定目标框裁剪后的目标区域，任务是六分类。该设置不评价目标检测、目标定位、开放世界识别或完整场景理解。

### 2.3 输出

- 每类及总体的视觉状态覆盖；
- 类别内部的Q1至Q5相对风险层；
- 各风险层的Accuracy、Macro-F1、类别Recall等性能；
- 测试构成变化时的性能响应与模型排名变化；
- 可在新目标和新数据源上复查的薄弱视觉条件；
- Coverage相对随机及强基线的诊断广度，以及其适用边界。

## 3. 方法的重点流程

### 步骤1：固定目标与建立数据隔离

从COCO、Open Images、VOC2007和Objects365中读取官方目标框与类别。根据用途划分训练/验证数据、发现池A和确认池B/C/D，并通过官方ID、图像哈希、裁剪哈希、感知哈希及视觉表征相似度检查重复和近重复。

其中：

- 发现池A用于发现候选薄弱状态；
- 确认池B用于新目标确认；
- 确认池C和D用于外部来源确认；
- 确认池不能反向修改发现阶段的薄弱状态清单。

### 步骤2：双VLM生成结构化视觉状态

对每个目标同时提供原图、目标框标记图和目标框裁剪图。两套VLM分别输出有限枚举状态。通用对象协议和车辆协议统一映射为14项共享字段：

1. 身体可见性；
2. 朝向；
3. 遮挡程度；
4. 遮挡物类型；
5. 截断程度；
6. 群体关系；
7. 交互关系；
8. 场景；
9. 背景复杂度；
10. 模糊；
11. 照明；
12. 目标—背景对比；
13. 可识别性；
14. 呈现形式。

程序再根据目标框面积与原图面积的比值计算目标尺度，最终形成15项分析字段。无法判断的状态保留为`unknown`，不能把结构化输出成功率解释为语义准确率。

### 步骤3：计算视觉状态覆盖

将一个状态定义为“字段—枚举值”对。对类别 \(c\) 的测试集合 \(S\)，频次覆盖为：

$$
C_c(S)=\frac{1}{|U_c|}\sum_{s\in U_c}\min\left(\frac{n_s(S)}{20},1\right),
\qquad
C(S)=\frac{1}{6}\sum_{c=1}^{6}C_c(S).
$$

其中，\(U_c\)是固定的类别状态宇宙，\(n_s(S)\)是状态支持数，20为饱和阈值，`unknown`不计为已覆盖证据。

覆盖回答“哪些状态获得了多少测试证据”，不回答“模型是否更准确”，也不是现实世界全部状态组合的绝对覆盖率。

### 步骤4：构造类别内视觉风险层

使用五个预定义、可见且不读取分类器输出的维度形成0至13分风险分数：

- 目标尺度：0至3分；
- 身体可见性：0至3分；
- 遮挡：0至3分；
- 截断：0至2分；
- 朝向：0至2分。

在每个数据池、每个真实类别内部按风险分数排序并等分为Q1至Q5：

- Q1：相对低风险；
- Q2至Q4：中间层；
- Q5：相对高风险。

Q5只表示当前类别和候选池中的相对高风险，不是跨类别、跨数据集通用的绝对难度标签。

### 步骤5：训练一次并冻结分类器

八种ImageNet预训练骨干分别使用三个随机种子训练六分类模型，得到24个分类器。模型通过固定验证集选择权重后全部冻结，每个目标的预测与logits只计算一次并缓存。

后续改变的是测试样本组织方式和分析条件，不再改变模型权重。因此，风险层上的性能变化表示测试构成下测得能力的变化，而不是模型发生了退化。

### 步骤6：执行三条互补评价线

#### 6.1 风险区分线

比较Q1至Q5的Macro-F1和类别Recall，重点检验Q1与Q5端点差。设置以下对照：

- 类别内随机划层10000次；
- unknown取值上下界敏感性分析；
- 逐风险维度删除与等权归一化评分；
- 只使用官方目标面积的连续面积对照。

该分支回答：预定义风险组织是否比随机分组更能区分模型表现，以及多维VLM状态是否提供超出简单尺度变量的信息。

#### 6.2 固定预算风险混合线

固定测试集总量为120个目标、每类20个，只将Q5占比从0%调整到100%，步长5%，共21个实际比例点；每个比例重复无放回抽样1000次。B和D另做480目标规模检查。

该分支只改变测试条件构成，控制测试数量和类别比例，回答：同一个冻结模型的总体性能与相对排名如何响应高风险样本比例变化。

#### 6.3 选样与失败诊断线

Coverage按稀缺状态的凹增益贪心选样，并与Random、DeepGini、DSA和基于冻结ViT表征的k-center比较。主要比较在相同的“类别—风险层—风险格”配额下完成。

评价不仅统计错误数量，还统计：

- 错误涉及的视觉状态广度；
- 真实类别—预测类别混淆类型广度；
- 错误目标的表征簇广度；
- 逐真实类别匹配错误数量后的期望诊断广度。

该分支回答：Coverage是否在相同预算和风险构成下提供额外失败信息，而不是仅仅因为选择了更多困难样本或产生了更多错误。

### 步骤7：冻结薄弱条件并进行独立确认

在发现池A中筛选满足以下条件的“状态—架构”组合：

- 状态支持量至少20；
- 状态Recall比对应类别总体Recall低至少10个百分点；
- 每类、每架构最多保留三项。

得到清单后先冻结，再在B、C、D中验证。若新池支持量不足，则标记为不可评价，不能改换为新的有利状态。对非尺度条件，进一步在类别内面积五分位层中进行描述性标准化，以检查关联是否完全由粗尺度构成解释。

### 步骤8：统计分析与证据边界

- 主要统计单位是八种架构，先在架构内平均三个种子；
- 配对比较使用精确符号翻转检验；
- 多重比较使用Holm校正；
- bootstrap与重复抽样区间分别描述有限架构/样本和选样波动，不解释为部署总体区间；
- 两套VLM、unknown敏感性与消融只能评价标注不确定性的影响，不能证明自动状态全部正确。

## 4. 一句话方法主线

> 官方标注固定测试对象，双VLM将目标转为有限视觉状态，预定义评分在类别内形成相对风险层，冻结分类器用于测量条件性能，再通过随机划层、面积对照、固定预算混合、等错误数控制和跨来源冻结确认，判断视觉状态组织能否提供稳定且可执行的模型能力诊断。

## 5. 与早期方案的区别

| 早期探索 | 当前主方法 |
|---|---|
| 根据dog状态缺口补图并重新训练模型 | 冻结模型，只改变测试组织与分析条件 |
| 主要关心覆盖提高后F1是否提高 | 主要关心测试构成是否揭示条件能力差异 |
| 以dog为单一案例 | 扩展为dog、cat、horse、sheep、person、car六类 |
| 单一覆盖线与训练性能线 | 分离覆盖、风险、性能和失败诊断广度 |
| gap与random补图比较 | Coverage与Random、DeepGini、DSA、k-center公平对照 |
| 同一数据来源内验证 | 发现池冻结条件，并在COCO、VOC2007、Objects365确认 |
| 希望形成模型侧创新CUA-VSL | 当前论文不提出新分类器，CUA-VSL保留为未完成探索支线 |

## 6. 论文主流程图的文字版画图提示词

### 6.1 完整版提示词

请绘制一张适合机器学习/软件测试论文的横向方法流程图，画布比例16:9，白色背景，扁平化矢量风格，线条清晰，信息密度中等，所有文字使用简体中文，字体统一为无衬线字体。不要使用照片背景、渐变、3D、阴影、装饰性插画或大面积单一蓝紫色。使用深灰作为文字和连线颜色，数据模块用蓝绿色，视觉状态模块用橙色，冻结分类器模块用蓝色，评价与确认模块用绿色；只在关键处使用红色表示薄弱条件。每个模块使用轻微圆角矩形，模块之间使用实线箭头，禁止交叉连线。

图标题为“基于视觉状态风险分层的多类别模型测试框架”。整张图从左到右分为五个阶段，并在顶部明确标出三条相互独立的信息线：“官方类别真值”“VLM视觉状态”“冻结分类器行为”。

第一阶段“固定目标与数据隔离”：画出四个数据来源COCO、Open Images、VOC2007、Objects365，进入官方目标框与六类标签dog、cat、horse、sheep、person、car；随后分成训练/验证集、发现池A、确认池B、确认池C、确认池D。旁边用小锁图标标注“ID、哈希、近重复检查”和“确认池不回流”。

第二阶段“双VLM状态描述”：对每个目标展示三个输入小缩略框，分别标注“原图”“A框标记图”“目标裁剪图”，进入两个并列模块“本地Qwen3-VL”和“线上SenseNova”。两者输出一个结构化状态表，写明“14项共享视觉状态 + 程序尺度 = 15项分析字段”，并列出五个代表性字段：可见性、朝向、遮挡、截断、场景；在状态表下标注“unknown保留，结构成功不等于语义正确”。该阶段不要把VLM连到类别真值。

第三阶段“测试组织”：由状态表分成上下两条支路。上支路为“状态覆盖”，显示字段—枚举状态、支持数n_s、饱和阈值20和Coverage贪心选样；下支路为“风险分层”，显示五个评分维度“尺度、可见性、遮挡、截断、朝向”，汇总为0—13分，然后在每个类别内部划分Q1、Q2、Q3、Q4、Q5，颜色由浅绿逐渐过渡到浅红，并明确标注“Q5为池内、类内相对高风险”。

第四阶段“冻结模型评价”：画出八个分类骨干汇合成“24个冻结分类器（8架构×3种子）”，旁边加雪花或锁图标；分类器接收固定目标裁剪图并输出缓存预测和logits。状态覆盖与风险层只连接到测试集合组织，不能连接到训练更新；冻结分类器输出只流向评价模块。将评价模块分为三个并列子面板：A“Q1—Q5条件性能与随机划层/面积对照”，B“固定120目标、每类20个，Q5占比0%—100%的21点风险混合”，C“Coverage、Random、DeepGini、DSA、k-center同预算比较与等错误数控制”。

第五阶段“薄弱条件确认与报告”：从发现池A的错误分析进入“筛选薄弱状态：支持量≥20，状态Recall低于类别Recall至少10个百分点”，再进入带锁的“冻结状态—架构清单”，随后分别指向确认池B、C、D。输出三个报告卡片：“总体与类别指标”“条件Recall与模型排名响应”“失败状态/混淆类型/表征簇广度”。最右侧形成最终结论框：“输出可解释的条件能力报告和下一步测试条件，不把覆盖增长等同于模型提升，不把相关条件解释为因果根源”。

在图底部增加一条细横栏“关键控制”：类别平衡、共同风险配额、10000次随机划层、1000次成对抽样、unknown敏感性、面积单独对照、Holm多重校正。右下角增加一个简洁图例：实线表示数据/计算流程，锁表示冻结，虚线边框表示补充敏感性分析。

确保图中最醒目的主路径为：固定目标 → 双VLM状态 → 覆盖与风险组织 → 冻结模型评价 → 跨来源薄弱条件确认。不要画成模型训练框架，不要出现反向传播、损失函数或“提高准确率”的表述。
