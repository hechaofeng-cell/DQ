# 视觉状态覆盖与难度递增模型诊断实验方案

版本：`visual_state_diagnostic_v1.0`  
日期：2026-09-28  
状态：方案冻结草案，可进入实现

## 1. 研究目标

本实验不再研究“增加训练数据是否提高模型F1”，而是研究：

> 在预先冻结的类别内部视觉状态空间中，构造覆盖率逐步提高、后续批次视觉难度逐步增加的诊断集，比较不同冻结模型的性能衰减、尾部状态鲁棒性和失败模式。

核心问题包括：

1. 不同模型在容易、一般、困难和极难视觉条件下的能力差距是否一致？
2. 整体性能较高的模型，是否也具有更高的最差状态Recall？
3. 哪些状态会在多个模型中稳定形成失败？
4. 哪些模型对小目标、关键部位不可见、遮挡、截断和非典型姿态更敏感？
5. 在难度相同的条件下，提高状态覆盖是否能暴露更广的失败状态？

## 2. 实验定位

本实验属于固定模型诊断，不属于模型训练实验。

- 不在诊断图片上训练或微调；
- 不使用诊断结果选择模型超参数；
- 不使用模型预测、置信度或错误结果定义难度；
- 所有模型使用相同图片、目标框、裁剪和预处理；
- 诊断图片不得与本地D300训练清单重叠或近重复；
- 全部特征、难度规则和样本顺序必须在读取模型结果前冻结。

因此，本实验的数据统一称为`D_diagnostic`，不再人为划分训练集、验证集和测试集。

## 3. 第一阶段实验对象

第一阶段只使用dog作为主诊断类别。原因是：

- `dog_v3.1`及现有200张独立候选图已经完成状态标注；
- 已保存8种架构、3个种子的逐样本预测；
- 已有随机、DeepGini、DSA和k-center结果可供补充比较；
- dog当前基础错误率高于cat，更容易区分模型能力边界。

冻结候选池：

| 类别 | 候选目标数 | 用途 |
|---|---:|---|
| dog | 200 | 构造难度与覆盖递增诊断集 |
| cat | 100 | 五分类辅助指标 |
| horse | 100 | 五分类辅助指标 |
| sheep | 100 | 五分类辅助指标 |
| person | 100 | 五分类辅助指标 |

主结论基于dog条件Recall和状态指标。Macro-F1属于辅助指标，因为当前只有dog按照视觉难度分级。

## 4. 精简视觉状态协议

建立`dog_diag_v1.0`，从`dog_v3.1`中删除或合并重复、依赖性较强的字段。

### 4.1 计入主要覆盖率的状态维度

| 组别 | 状态维度 |
|---|---|
| 外观 | 毛发主色、毛发图案、毛发质地、耳朵形状、身体外形 |
| 姿态 | 头部朝向、身体朝向、姿态动作状态 |
| 可见性 | 头部可见性、关键面部部位可见性、腿部可见数量、尾巴可见性 |
| 退化 | 遮挡程度、截断程度 |
| 整体 | 犬体可识别性、场景 |

共16个主要维度。

`关键面部部位可见性`由`muzzle_visibility`、`mouth_visibility`和`eye_state`确定性合并：

- `clear`：口鼻、嘴部和眼睛证据均基本可见；
- `partial`：至少一个关键部位部分可见，但仍有充分头部证据；
- `severe_loss`：头部不可见，或者两个及以上关键部位不可见；
- `unknown`：证据不足。

### 4.2 不计入主要覆盖率但保留审计的字段

- `mouth_state`；
- `tongue_visibility`；
- `tail_posture`；
- `occlusion_parts`；
- `truncation_parts`。

这些字段仍用于错误解释，但不重复增加主要覆盖分数。旧`dog_v3.1`结果保留，不能用新协议覆盖旧结果。

## 5. 覆盖率定义

设精简协议包含`K`个有效状态，第`s`个状态在集合`D`中的频数为`n_s(D)`，频数充分阈值为`T=20`：

```text
Coverage(D) = (1/K) * sum_s min(n_s(D) / T, 1)
```

同时报告：

- 频数覆盖率：主要覆盖指标；
- Presence覆盖率：状态是否至少出现一次；
- 低频状态数：`1 <= n_s < 5`；
- 缺失状态数：`n_s = 0`。

不能通过删除难覆盖状态提高覆盖率。任何协议变动都必须产生新版本号。

## 6. 模型无关难度分数

每张dog图片计算模型无关难度`H(x)`。难度只使用目标标注和冻结视觉状态，不读取任何模型输出。

### 6.1 目标尺寸，0--3分

使用原图中目标框面积占比`r`：

| 条件 | 分数 |
|---|---:|
| `r >= 10%` | 0 |
| `3% <= r < 10%` | 1 |
| `1% <= r < 3%` | 2 |
| `r < 1%` | 3 |

### 6.2 关键证据可见性，0--3分

头部可见性与关键面部部位可见性属于同一证据组，使用二者的最大严重度，不重复相加：

| 状态 | 分数 |
|---|---:|
| 清晰 | 0 |
| 部分可见 | 2 |
| 不可见或`severe_loss` | 3 |

### 6.3 遮挡程度，0--3分

| 状态 | 分数 |
|---|---:|
| none | 0 |
| partial | 2 |
| heavy | 3 |

### 6.4 截断程度，0--2分

| 状态 | 分数 |
|---|---:|
| none | 0 |
| partial | 1 |
| heavy | 2 |

### 6.5 非典型朝向，0--2分

| 状态 | 分数 |
|---|---:|
| 正面、侧面或常规三分之四朝向 | 0 |
| 后向身体或头部向上/向下 | 1 |
| 身体后向且头部证据缺失 | 2 |

最终：

```text
H(x) = size + visibility + occlusion + truncation + orientation
```

理论范围为0--13。`dog_recognizability`用于难度审计和敏感性分析，不再加入总分，避免与遮挡、截断和可见性重复计数。

## 7. 诊断集构造

### 7.1 难度分层

将200张dog按照`H(x)`升序排列，并按等数量划分为5个候选层，每层40张：

```text
Q1：最容易40张
Q2：较容易40张
Q3：中等40张
Q4：困难40张
Q5：最困难40张
```

分数相同时使用`sample_id`排序，保证完全可复现。

### 7.2 每层覆盖选样

从每个难度层选择20张，共100张dog：

1. 从Q1中贪心选择20张，使当前边际覆盖增益最大；
2. 保留Q1已累积的状态频数，从Q2继续选择20张；
3. 依次处理Q3、Q4和Q5；
4. 并列时优先选择当前层难度更低者，再按`sample_id`决定。

得到5个互斥批次：

```text
B1：容易，20张
B2：较容易，20张
B3：中等，20张
B4：困难，20张
B5：极难，20张
```

以及5个嵌套累计集合：

```text
D20  = B1
D40  = B1 + B2
D60  = B1 + B2 + B3
D80  = B1 + B2 + B3 + B4
D100 = B1 + B2 + B3 + B4 + B5
```

累计覆盖率应单调不下降，批次难度中位数应单调不下降。如果两项检查失败，停止模型评价并检查构造代码；不能根据模型结果手工换图。

## 8. 对照组

### 8.1 难度匹配随机组，主要对照

在每个Q层的40张候选中随机选择20张，重复1000次。每次随机组与覆盖组具有完全相同的难度层数量，因此检验：

> 在难度预算相同的情况下，覆盖选样是否暴露更多失败状态？

### 8.2 全局随机组，辅助对照

从200张dog中随机生成1000条嵌套顺序，用于说明“覆盖与难度联合序列”相对普通随机测试的综合差异。

### 8.3 既有方法对照，论文扩展

复用现有DeepGini、DSA和k-center排序。它们用于比较故障发现效率，不用于定义本实验的难度。

## 9. 冻结模型

主实验使用现有D300训练完成的8种架构，每种3个种子：

1. ResNet-18；
2. ResNet-50；
3. MobileNetV3-Small；
4. MobileNetV3-Large；
5. DenseNet-121；
6. EfficientNet-B0；
7. ConvNeXt-Tiny；
8. Swin-T。

共24个固定检查点。模型不重新训练，直接读取已保存逐样本预测。

新基础模型AIMv2、SigLIP2、DINOv2和PE-Core作为第二阶段扩展，不与第一阶段混在一起改变主结论。

## 10. 评价指标

### 10.1 主要指标

| 指标 | 计算方式 | 解释 |
|---|---|---|
| 批次dog Recall | 分别只在B1--B5计算 | 新加入图片是否逐步变难 |
| 最困难批次Recall | `Recall(B5)` | 模型尾部能力 |
| 状态平均Recall | 对合格状态等权平均 | 类别内部平均鲁棒性 |
| 最差5状态Recall | 最低5个合格状态均值 | 模型能力下限 |
| 失败状态广度 | 至少出现一次错误的状态数 | 错误类型覆盖范围 |
| 难度鲁棒性AUC | B1--B5 Recall曲线面积 | 全难度范围综合能力 |

状态至少具有10张支持才进入单状态排名；支持不足的状态只作探索性报告。

### 10.2 辅助指标

- 累计`D20--D100`的dog Recall和dog F1；
- 五分类Accuracy、Macro-Precision、Macro-Recall和Macro-F1；
- dog误分类到cat、horse、sheep和person的比例；
- 每个模型的覆盖敏感度和难度衰减斜率；
- 模型种子标准差。

### 10.3 两套曲线必须同时报告

1. **新增批次曲线**：B1、B2、B3、B4、B5，直接反映后续图片是否更难；
2. **累计集合曲线**：D20、D40、D60、D80、D100，反映逐步扩展诊断集后的总体测得性能。

累计F1可能因分母变化而回升，不能用它单独判断后续图片是否更难。

## 11. 模型比较与排名

不产生一个脱离场景的“通用最好模型”，而是报告四类排名：

1. 整体排名：D100 Macro-F1；
2. dog类别排名：D100 dog Recall；
3. 困难状态排名：B5 Recall与最差5状态Recall；
4. 稳定性排名：难度鲁棒性AUC与跨种子波动。

主排名按照预先指定的`难度鲁棒性AUC`排序；B5 Recall作为关键尾部指标。若不同指标排名不同，应直接报告排名反转，而不是事后更换主指标。

## 12. 统计分析

- 对相同图片上的模型差异使用配对bootstrap，重复10,000次；
- bootstrap同时在图片层重采样，并保留架构内3个种子的层级；
- 多模型、多状态比较使用Holm校正；
- 报告均值、95%区间和配对效应量；
- 场景共现时只表述关联，不表述单个状态的因果作用；
- 难度分数的有效性由B1--B5的实际错误响应检验，但检验后不得反向修改本轮难度规则。

## 13. 预注册假设与判定

### H1：难度阶梯有效

预期B1到B5的跨模型平均dog Recall总体下降。

- 支持：B5 Recall低于B1，且至少6/8架构方向一致；
- 部分支持：总体下降但架构方向不一致；
- 不支持：B1--B5没有稳定难度差异。

### H2：模型具有不同难度敏感度

- 支持：模型的AUC或B5 Recall排序不同于容易批次排序，并具有稳定配对差异；
- 不支持：所有模型仅保持相同相对差距。

### H3：覆盖提供独立诊断信息

- 支持：在难度匹配条件下，覆盖组选出的失败状态广度高于1000次随机组95%上界；
- 部分支持：覆盖率更高，但失败状态广度未超过随机区间；
- 不支持：覆盖和失败状态广度均无优势。

### H4：整体指标不能替代状态鲁棒性

- 支持：D100 Macro-F1排名与B5 Recall或最差5状态Recall排名发生稳定反转；
- 不支持：各指标产生相同排序。

## 15. 执行步骤

1. 冻结`dog_diag_v1.0`特征协议；
2. 验证200张dog与D300训练图片无ID、哈希或近重复；
3. 从现有标注确定性生成精简状态矩阵；
4. 计算每张图片的模型无关难度分数；
5. 将200张dog划分为Q1--Q5；
6. 在每层进行覆盖贪心选样，形成B1--B5；
7. 冻结样本清单、排序原因和输入哈希；
8. 读取24个冻结模型的逐样本预测；
9. 计算独立批次和累计集合指标；
10. 生成1000次难度匹配随机对照；
11. 计算bootstrap区间、效应量和Holm校正；
12. 生成模型状态热力图和错误台账；
13. 人工复核所有稳定错误和类别争议样本；
14. 冻结结果表、图、研究日志和结论边界；
15. 再决定是否扩展到cat、face和新基础模型。

## 17. 可以与不能得到的结论

### 可以检验

- 模型在视觉难度增加时的性能衰减是否不同；
- 哪个模型在极难批次和最差状态上更稳健；
- 整体模型排名是否掩盖尾部状态弱点；
- 难度匹配后，覆盖选样是否仍能暴露更多失败类型；
- 哪些视觉状态与跨模型稳定错误相关。

### 不能直接声称

- 某个单独视觉状态导致模型错误；
- 当前模型排名适用于所有数据集和任务；
- 诊断集上的F1代表真实部署分布性能；
- 覆盖率提高导致模型本身退化；
- 如果没有强基线优势，Coverage是最优故障发现算法。
