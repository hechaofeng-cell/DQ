# 五组近期模型独立比较：冻结实验方案

## 目的与范围

在同一固定六类任务中，比较五组近期模型的整体识别表现、风险条件下的能力落差及测试构成改变时的排名。仅比较本组五种模型，不将历史八模型结果混入表格、排名或统计分析。训练完成后冻结权重，测试组成变化不触发再训练。结果允许上涨、下降或无差异，不预设最优模型。

## 数据与划分

类别固定为dog、cat、horse、sheep、person、car；person指现有目标对象分类，不改成人脸身份识别。使用既有固定目标框裁剪：训练1800目标，每类300；验证90，每类15；基础测试300，每类50。外部池B为2400目标、C为600、D为2400，均类别平衡。沿用既有清单和已有重复检查，启动时补充训练／验证／测试／候选目标裁剪内容重叠检查。有跨划分重叠则中止并记录，不能为保持样本量跳过。

本地与线上VLM状态、五维风险分数和类别内Q1—Q5成员沿用冻结版本。读取历史NPZ只取sample_id、风险组成和分层成员，历史分类器预测不用于新组比较。不新增人工复核、不重跑VLM、不用测试错误修改特征定义。

## 共同训练条件

所有模型使用公开预训练视觉部分，加相同形式的LayerNorm＋六类线性头，全量微调。YOLO分类版取分类头线性层之前的1280维特征；视觉语言模型只用图像编码器，不用文本零样本分类。20轮；AdamW学习率1e-4、权重衰减1e-4；余弦退火；每轮按类别逆频率有放回抽3000目标。三个种子20260916、20260917、20260918。

微批8、梯度累积至有效批64；轮末不足64的批次按实际样本数归一化。共同几何预处理为短边缩放到输入边长的256/224倍，再裁剪；训练随机裁剪、水平翻转、轻量颜色扰动，评测中心裁剪。归一化使用各自公开预训练配置。MobileCLIP2原生256，其余224。使用BF16、梯度范数裁剪1。以验证Macro-F1最高的首次出现轮次选择权重；不使用任何测试池进行权重或超参数选择。

这是一套统一、有限训练预算下的适配比较，不能据此宣称模型各自最佳可达到性能。模型预训练数据和参数量不同，存在外部池与大规模预训练数据潜在重叠，需保留这一边界。冒烟测试训练样本用于检查前向、反向和显存，不报告其指标为正式结果。

## 评价与交付

1. 基础测试和B/C/D整体：Accuracy、Macro-Precision、Macro-Recall、Macro-F1；每类Precision、Recall、F1；混淆矩阵。按三个种子报告均值和标准差。
2. B/C/D两种标注来源分别评价冻结Q1—Q5，报告Q1−Q5的F1落差及每类Recall。与整体指标并列，不能只根据整体F1判定困难状态能力。
3. 固定120目标、每类20，在Q1与Q5间改变高风险数量0—20，每档1000次无放回抽样，21个真实计算点。所有模型与种子复用同一抽样。区间是样本构成重抽样区间，不等同于独立新数据来源的不确定性。
4. 对已有状态枚举统计错误暴露的状态广度，固定可评状态全集、标明支持量，作为描述性诊断；它依赖自动标签，不宣称语义真值准确率。展示总体与高风险排名及其变化，全部只含这五组。
5. 输出预测缓存、训练日志、配置／输入哈希、每轮验证记录、参数表、CSV结果表、中文MD报告。科学图表在正式结果齐备后生成；不平滑制造未计算数据。

后台过程依次执行五组×三个种子，共15次训练。单任务失败记录堆栈，继续其他任务，最终状态须区分complete与incomplete；仅15个完成记录且分析审计通过才能标记完成。保存轮级恢复检查点，重启复用已完成训练和预测。
