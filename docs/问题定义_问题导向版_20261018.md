# 3.1 问题定义

本文关注图像分类模型测试中的一个问题：**在测试样本数量有限的情况下，如何明确测试覆盖了哪些视觉条件，在控制风险构成的同时补充不足的测试支持，并判断模型在不同风险条件下的识别表现。** 仅报告测试集规模、类别比例和整体分类分数，仍难以回答“测试了什么条件”“这些条件是否得到充分测试”以及“模型在不同条件下表现如何”。围绕这一问题，本文从测试条件描述、测试样本选择和模型分层评价三个方面展开研究。

首先，类别相同并不意味着测试条件相同。同为马类目标，其鬃毛形态、面部斑纹和肢体可见情况可能不同；同为汽车目标，车身轮廓、车灯和格栅形态也可能不同。仅用类别标签组织测试，无法区分这些细粒度差异；仅用通用视觉属性描述目标，也难以充分表达类别专属的外观和部件特征。因此，第一个需要回答的问题是：**如何将不同类别目标的视觉差异转化为可记录、可统计的测试条件？** 本文结合共享字段与类别专属字段构建视觉状态字典，由语言模型提出字段及取值，经人工审查后固定，再由视觉语言模型自动提取目标状态。由此，将类别层面的样本清单细化为目标层面的状态记录，为说明测试条件及其样本支持提供依据。

其次，增加样本数量并不必然补充缺失的测试条件。具有常见状态的目标可能被重复选入，而部分状态始终缺失或只有少量样本支持。同时，若不同选样方法获得的风险构成不同，覆盖差异与难度构成变化就会混在一起。因此，第二个需要回答的问题是：**如何在相同测试预算和风险配额下，优先补充缺失或支持不足的视觉状态？** 本文固定使用尺度、可见性、遮挡、截断和朝向五个维度进行风险评分，在各类别内部排序并划分为Q1—Q5；随后在既定配额内，依据状态支持的边际增益选择目标。类别专属特征用于覆盖编码和选样，风险评分沿用固定规则。通过同预算、同风险配额的对照，评价覆盖选样能否增加状态出现范围及样本支持。

最后，整体分类分数汇总了不同视觉条件下的预测结果，难以反映模型在不同风险层中的表现差异。即使两个模型的整体F1接近，其在较低风险与较高风险目标上的表现也可能不同。因此，第三个需要回答的问题是：**如何将总体分类表现细化为可比较的风险分层结果，并同时保留各类别的误识别信息？** 本文将各类别同一风险层的目标合并为类别平衡的多类别评测集，依据分类混淆矩阵计算各类别F1和整体Macro-F1，比较不同模型在Q1—Q5上的表现。该评价同时计入某类目标被误判，以及其他类别被误判为该类的情况，用于检验风险分层是否对应实际性能差异。

因此，本文解决的是**测试条件难以明确描述、有限预算下状态支持难以安排，以及整体指标难以展示风险条件差异**这三个相互关联的问题。方法以具有目标框和真实类别标签的候选目标为输入，以单个目标实例为测试单位，输出风险构成明确的测试集、视觉状态覆盖报告和模型分层性能报告。测试期间保持分类模型固定，风险评分与选样不读取其预测结果；状态覆盖描述预定义条件获得的测试支持，分层性能描述模型在相应测试条件下的识别表现。风险升高是否伴随F1下降由实验检验，覆盖增加也不直接等同于模型能力提高。
