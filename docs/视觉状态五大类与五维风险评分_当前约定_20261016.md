# 视觉状态五大类与五维风险评分：当前约定

- 记录日期：2026-10-16。
- 版本：v1.1。
- 用途：记录本轮讨论确定的概念、图中文字和方法边界，作为后续修改的对照。
- 状态：特征组织与评分范围已确定；具体数值映射、维内聚合及权重需与最终选用的评分协议一致。本记录不表示已经修改代码或重新完成实验。

## 1. 当前核心约定

**五大类用于组织完整视觉特征；五维用于风险评分。两者不是一一对应的关系。**

完整特征字典按“空间几何、可见性与完整性、外观与形态、朝向与姿态、场景与图像质量”五大类组织。

风险评分从中选取“目标尺度、目标可见性、遮挡程度、截断程度、目标朝向”五项信息。不要求每个特征大类都产生风险分，也不要求每个字段都参与评分。

外观、姿态动作和场景类型等字段用于状态覆盖与条件分析，不预先赋予高低风险。模糊、光照、目标背景对比度等当前也作为覆盖与诊断字段；是否纳入风险评分，留待单独定义和验证。

总体仍为“风险配额约束下的覆盖贪心选择与模型评价”架构。

## 2. 五大类视觉特征

| 特征大类 | 内容示例 | 当前评分用途 |
|---|---|---|
| 空间几何 | 目标尺度；其他几何属性按具体协议保留 | 目标尺度参与风险评分；不因扩大大类名称而自动新增几何评分字段。 |
| 可见性与完整性 | 整体与局部可见性、遮挡程度与来源、截断程度与部位 | 可见性、遮挡程度、截断程度参与风险评分；具体部位和来源等用于覆盖与条件分析。 |
| 外观与形态 | 毛色、纹理、耳形、体形、头发、配饰、车身颜色等 | 当前不评分，用于覆盖与条件分析。 |
| 朝向与姿态 | 头部与主体朝向、站立、坐卧、行走、奔跑等 | 选定的朝向字段参与评分；姿态动作当前不评分。 |
| 场景与图像质量 | 室内、街道、草地、群体与交互、光照、模糊、目标背景对比度等 | 当前用于覆盖与条件分析，暂不纳入五维风险总分。 |

说明：

- “完整”指当前研究明确采用的字段范围，不表示穷尽所有现实视觉条件。
- 各类别采用适用的字段和枚举状态，不能把犬类毛发或尾巴字段强行用于车辆。
- 五大类是组织层，实际标注、覆盖和诊断仍以具体字段及其状态为单位。
- 字段应遵循现有类别协议；图中举例不代表每类均已拥有所有示例字段的有效标注。

## 3. 五维视觉风险评分

### 3.1 维度及含义

| 风险维度 | 描述内容 | 图中简写 |
|---|---|---|
| 目标尺度 | 官方目标框面积占原图面积的比例 | 大 → 微小 |
| 目标可见性 | 目标整体或选定适用部位的可见程度；采用哪种版本需明确 | 完整 → 少量可见 |
| 遮挡程度 | 被其他物体遮蔽的程度 | 无 → 严重 |
| 截断程度 | 因图像或裁剪边界造成的缺失程度，具体边界口径以协议为准 | 无 → 严重 |
| 目标朝向 | 主体及协议选定局部相对观察视角的方向 | 按预定义视角映射 |

“目标”统一适用于犬、猫、马、羊、人和车；涉及具体字段时，仍使用协议原有标识，如body_visibility、body_orientation。

### 3.2 当前保留的规则边界

1. 尺度由官方目标框及原图尺寸计算，不能用裁剪缩放后的显示尺寸替代。
2. 可见性描述可见结果，遮挡与截断描述不同缺失情况，分别标注。三者相关，汇总方式需明确，不宣称维度相互独立。
3. 朝向不能只用“正向→背向”概括；还需保留侧向、斜向、俯视或非常规视角等适用状态。
4. 车辆的可见车轮数量不能直接解释为可见性风险；正常视角可能只看到部分车轮。
5. unknown表示无法可靠判断，不等于无风险、无遮挡或无截断。计分及上下界处理应遵循选定评分协议；覆盖时不将unknown计为有效已知状态支持。
6. 风险分是预定义组织指标，不是分类失败概率；不读取被测分类器错误、置信度或预测来生成当前风险分。
7. 五个风险维度不等于五个整体字段。若使用局部细粒度版本，一个维度可以由多个适用字段聚合，但仍需明确字段、权重和适用性。

### 3.3 尚未在本记录中重新确定的数值细节

本次确认评分范围，不新增一套数值公式。后续落实时，需记录：

- 使用原整体五维版本，还是已有局部细粒度版本。
- 每个字段的状态—分值映射及schema版本。
- 可见性、朝向等维度内部使用哪些局部字段、如何聚合。
- 五维之间采用何种权重和总分范围。
- unknown、不适用和缺少字段如何处理。
- 可见性与遮挡、截断的重复信息如何控制或进行敏感性分析。

不能把先前讨论过的候选参数直接写成此次已确定的最终规则。

## 4. 不采用的上一版候选方案

此前的《五大类视觉风险评分规则（候选方案v1）》提出五大类各占20分，并按固定参考频次给外观、姿态动作、场景类型评分。**该方案已被本轮后续讨论取代，不作为当前实施依据。**

当前不采用：

- 五大类必须各有一个分数、各占20分的要求。
- 把毛色、纹理、体形、姿态动作和场景类型的少见程度直接加入风险总分。
- 为此额外建立参考频次表的前置依赖。
- 未经本次确认的max聚合、新权重及新增质量评分映射。

少见状态仍可通过覆盖支持统计得到关注，但“少见”不自动等于“高风险”。

旧提案保留作追溯材料：[五大类评分旧提案](五大类视觉风险评分规则_提案_20261016.md)。如其内容与本文冲突，以本文为准。

## 5. 总体架构

```text
已知类别与代表样本
        ↓
人工 + VLM 协同制定五大类视觉状态字典与标注规则
        ↓
对候选目标提取逐目标视觉状态
        ├───────────────────────────┐
        ↓                           ↓
风险分支                         覆盖分支
选定五维评分字段                 采用范围内的完整状态编码
        ↓                           ↓
预定义风险评分                   已选集合状态支持
        ↓                           ↓
类别内Q1—Q5分层                  覆盖边际增益
        ↓                           ↓
风险格配额 ──────────┐    ┌─────────┘
                     ↓    ↓
              风险约束覆盖贪心选择
              ① 筛选名额允许的未选目标
              ② 选择覆盖增益最大的目标
                     ↓
       更新所在风险格名额及已选状态支持
                     ↓
              保留风险层标签的测试集
                     ↓
              覆盖报告与多模型分层评价
```

两条分支的作用：风险配额限定可选范围，覆盖增益决定范围内的选择优先级。风险分与覆盖增益不直接相加，不由覆盖分数推导风险。分类评价发生在选样之后，不画分类错误反馈选样的箭头。

## 6. 图中文字：可直接替换

### 6.1 细粒度视觉状态字典

```text
细粒度视觉状态字典

空间几何
目标尺度：微小 / 小 / 中 / 大

可见性与完整性
头部：清晰 / 部分 / 不可见
遮挡：无 / 部分 / 严重
截断：无 / 部分 / 严重
部位：头部 / 躯干 / 肢体 …

外观与形态
颜色：黑 / 白 / 棕 …
形态：毛发、耳形、体形、头发、配饰、车身 …

朝向与姿态
头部、主体朝向：正 / 侧 / 背 …
姿态动作：站立 / 坐卧 / 行走 …

场景与图像质量

各类别采用适用字段与枚举状态
```

“无/部分/严重”等是图中文字示例，不统一替换所有类别协议的词表。已有四级词表和三级词表仍按版本区分。

### 6.2 目标视觉状态

```text
目标视觉状态

可见情况：部分遮挡、无截断
外观：棕白毛色
朝向：左前侧向
场景与质量：草地、清晰

尺度由原图目标框面积占比计算
其他状态由 VLM 按字典提取
```

以上对应当前图中的犬类示例。最终使用前应与实际目标及保存标注核对，不将图示文字当作经过核验的标注真值。图中空间允许时可另外展示尺度标签，其值来自程序计算。

### 6.3 风险评分框

```text
视觉风险评分

              风险分值
              低 → 高

目标尺度      大 → 微小
目标可见性    完整 → 少量可见
遮挡程度      无 → 严重
截断程度      无 → 严重
目标朝向      按预定义视角映射

状态映射 → 五维风险汇总
```

框下小字：

```text
从五大类特征中选取评分字段
```

标题使用“视觉风险评分”，底部保留“五维风险汇总”，不写“五大类风险评分”。色带只示意分值高低，不表示每项有五个枚举值。

### 6.4 覆盖分支

```text
视觉状态编码 → 已选状态支持 → 覆盖边际增益
```

覆盖编码可展示尺度、可见性、遮挡、外观、朝向、场景等部分字段—状态。五大类不各自压缩成一个二值列；参与覆盖的具体字段与有效状态词表需明确。

### 6.5 覆盖大模块的具体改图方案

保留“视觉状态覆盖”总标题、三个并排子框、正向箭头及“更新状态支持”的反馈线。以下状态、计数和候选关系仅为机制示意，不能当作实际数据或实际贪心选择结果。

#### 左栏：视觉状态编码

在状态矩阵上方增加按五大类分组的标题，组内仍以具体字段—状态为列。建议展示八列，按大类用细横线或浅色分组，不必将完整大类名称挤入每一列。

| 所属大类 | 字段标题 | 状态示例 |
|---|---|---|
| 空间几何 | 尺度 | 小目标 |
| 可见性与完整性 | 可见性 | 头部清晰 |
| 可见性与完整性 | 遮挡 | 部分遮挡 |
| 外观与形态 | 毛色 | 棕色 |
| 朝向与姿态 | 朝向 | 侧向 |
| 朝向与姿态 | 姿态 | 站立 |
| 场景与图像质量 | 场景 | 草地 |
| 场景与图像质量 | 模糊 | 严重模糊 |

矩阵行仍为目标1、目标2、……、目标N。上述示例不包含截断列，但完整覆盖词表仍按实际协议保留截断及其他已纳入字段；不是为了放下图就删除覆盖字段。矩阵勾选组合应按真实目标标注填写，或明确整块是机制示意。

底部文字：

```text
各字段的有效枚举值展开为二值状态列
✓ 表示该目标具备对应状态
仅展示部分状态，unknown不计入有效支持
```

#### 中栏：已选状态支持

中心“已选集S”保留。节点统一使用与左栏一致的字段—状态示例：

| 状态节点 | 支持数示例 |
|---|---:|
| 头部清晰 | 24 |
| 侧向 | 8 |
| 草地 | 5 |
| 棕色 | 3 |
| 严重模糊 | 1 |
| 小目标 | 0 |

以K=20为例，24对应的增益已饱和；1与0分别表示低支持和缺失。数字始终表示已选目标中支持该状态的目标数量，不表示风险分或权重。同一目标对同一状态最多计一次。

底部文字：

```text
节点大小 / 数字 = 状态支持数
从空集开始时为0，逐轮更新
```

若已有初始已选集，则从该集合的实际支持数开始，不能一律标为0。

#### 右栏：覆盖边际增益

保留候选A/B/C和三个状态节点，给状态节点加具体名称，避免只画24、1、0：

```text
头部清晰：24（增益已饱和）
严重模糊：1（低支持）
小目标：0（缺失）
```

示例连线：A连接“头部清晰”和“严重模糊”；B连接“严重模糊”和“小目标”；C连接“头部清晰”。三者均在风险配额允许的范围内，且未画出的其他状态增益相同。在现有饱和对数增益规则下，B的示意增益最大。

底部文字：

```text
示例优先选择B
补充缺失状态，增强低支持
仅比较名额允许的候选；本例K=20
```

“增益已饱和”只表示该状态在当前规则下不再贡献新增增益，不表示该视觉条件已获得全面测试或可靠性保证。

外观、场景等无需风险分，也能凭状态支持不足贡献覆盖增益。三栏必须使用同一覆盖词表；左侧只画少数目标行，中间的24等数值来自整个示意已选集，并非左侧可见行数之和。

## 7. 与现有实验的关系

- 仅修改特征分组名称和图中文字，不自动改变原有标注、风险分数或覆盖结果。
- 若改变评分字段、数值映射、维内聚合或权重，需要重新计算风险分、Q层成员、风险格配额与选样结果。
- 若扩展覆盖词表，需要重新计算状态支持、覆盖分母、覆盖增益与覆盖引导选样，不能沿用旧覆盖百分比。
- 目标、被测模型及实际推理输入不变时，可以复用已有逐目标分类预测。
- 不因特征更多、描述更细就宣称风险区分更强或方法更好，相关效果需重新评价。
