## 2 当前主张与证据边界

| 可保留的主张 | 必须同时保留的边界 |
| --- | --- |
| 相同风险配额下，相对随机的状态覆盖和支持得到改善 | 限定当前字典、自动标签、候选池和预算 |
| 专属状态改变测试内容并增加专属支持 | 共享支持下降，不能描述为无代价增益 |
| 当前风险分层对应多模型端点性能下降 | 中间层不严格单调，风险不是错误概率 |
| 一部分薄弱条件在外部样本上方向复现 | 回顾性复核；方向标准宽松；支持不足必须单列 |
| 覆盖与诊断的排序存在不一致 | 不应改成当前方法诊断全面领先或覆盖没有任何价值 |
| 自动标注具有固定协议下的重复性 | 未测量独立人工语义准确率，不将重复性替代正确性 |
| 风险层内比较没有得到可评估结果 | 不能把不可评估写成零效应或已排除风险混杂 |

按照最新要求，没有安排新的人工环节，也不以人工工作作为这份初稿的完成前提。语义准确率未测量仅作为当前结论的限制，如实写入正文。
