# 局限性：视觉状态与风险分层测试的结论边界

依据截至2026年10月6日的完整论文与已核验实验整理，与“优点.docx”配套使用。

## 一、先明确：局限性具体限制什么

当前已经支持的结果是：在三个确认池、六个类别及冻结模型面板中，预定义风险分层形成了超过随机分组波动的性能差异；固定预算与类别比例后，风险构成变化也对应明确的平均性能响应。

局限性主要约束更强的解释：这些结果是否可以推广到全部任务；自动描述是否等同于真实状态；哪个字段独立导致错误；覆盖选样是否全面优于其他方法。上述问题与“已测风险层存在差异”并不是同一个命题。

| 局限性 | 主要影响 | 当前应采用的结论口径 |
|---|---|---|
| 自动状态标签缺少完整语义真值 | 状态与风险层的解释可信度 | 自动描述下的条件诊断，不称全字段准确 |
| 覆盖、风险和性能是不同指标 | 核心结论的概念边界 | 风险构成响应，不称覆盖率导致F1下降 |
| 风险评分与分位层有设定依赖 | 风险层定义及可迁移性 | 类别内相对风险，不称统一绝对难度 |
| 状态相关且删维改变样本成员 | 单字段解释与因果归因 | 条件关联，不称某状态独立导致失败 |
| 额外诊断广度收益不一致 | Coverage选样的优越性 | 有条件的增量价值，不称全面最优 |
| 重复抽样及模型运行存在依赖 | 显著性与区间的解释 | 以实际抽样单元、家族及面板为准 |
| 模型排名依赖权重与测试构成 | 架构总体优劣判断 | 冻结配置下的平均排名与不确定性 |
| 类别、数据池及任务范围有限 | 向其他任务和部署的推广 | 六类固定框分类与已评估来源 |
| 稀有状态和一致子集支持不足 | 细粒度状态及稳健性评价 | 只对支持足够的组合报告结果 |
| 探索历史和预标注池条件 | 确认性与实际流程的适用性 | 冻结后的补充确认与离线测试池 |

## 二、局限性1：自动状态标签尚不能作为完整真值

视觉状态由本地和线上VLM生成。结构校验可以保证字段齐全、枚举值合法、格式可解析，但不能保证图片中每个状态都被正确识别。两个模型描述一致，也不等于它们一定正确；两个模型描述不一致，则不能仅据表现更好的一方判断谁是正确标注。

已有Open Images二值属性提供了遮挡和截断的部分参考。与本地/线上VLM结果归并比较后，字段间确实存在不同程度的分歧。

| 字段 | 状态标注来源 | 参考一致率（%） | 二值参考F1（%） | Kappa |
|---|---|---|---|---|
| 遮挡 | 本地 | 61.16 | 66.84 | 0.238 |
| 遮挡 | 线上 | 66.07 | 69.67 | 0.331 |
| 截断 | 本地 | 67.50 | 65.46 | 0.384 |
| 截断 | 线上 | 79.62 | 74.08 | 0.576 |

这里的F1是状态属性与官方二值参考的对齐指标，不是对象分类F1。官方二值属性与VLM严重程度枚举也并非完全等义，参考本身不保证无误差。因此不能把这张表当成全部状态的准确率；但它明确说明，自动字段的可靠性并不相同，遮挡描述尤其需要谨慎解释。

这项局限主要影响“样本被命名为某个视觉条件是否准确”。当前最稳妥的表述是：模型在自动状态协议定义的风险层上表现不同。不能进一步宣称模型一定在全部真实严重遮挡样本上表现如何。

不进行人工复核，不意味着所有标签一定错误，也不意味着分类器F1会自动降低。它意味着缺少一种直接核验状态语义的证据。本文可继续使用自动标签，保留官方参考、双来源和敏感性结果，明确其解释范围；本说明不将新增人工复核列为必须执行步骤。

## 三、局限性2：覆盖率提高不是风险增加的同义词

覆盖描述哪些状态出现及其证据数量；风险描述预定义困难条件；F1描述模型在当前测试集合上的分类表现。三者不能合并解释。

例如，加入一个以前没有出现、但容易识别的毛发状态，可能同时提高状态覆盖与F1。重复加入大量严重遮挡目标，可能增加错误，却主要重复同一批条件。两种情况都说明，覆盖率、样本困难程度和测得性能之间没有预设的单调关系。

最新固定预算实验直接改变的是Q5目标的占比。它控制了测试总量和六类比例，所以支持“风险构成变化对应性能响应”；它没有单独操纵覆盖率，因此不支持“覆盖率增加导致F1下降”的因果结论。

覆盖指标还依赖状态枚举、unknown处理、频次阈值及支持门槛。单字段状态覆盖高，不意味着多字段组合、真实场景或所有可发生条件均已覆盖。当前论文应将覆盖作为有限状态证据指标，不能将其解释为完整视觉世界的充分性。

## 四、局限性3：风险评分和分位层依赖规则设定

当前风险评分采用尺度、可见性、遮挡、截断和朝向五维，并固定分值、unknown处理与同分排序规则。哪些条件得到较高分、不同维度如何累计，都会影响最终层成员。

Q5是每个候选池、每个类别内部的相对最高风险五分位层。COCO的Q5与Objects365的Q5并不保证相同绝对难度；dog的Q5也不能直接当作car的同等难度。跨池落差不同，既可能与条件分布有关，也可能与对象、背景、标注资格和具体样本有关。

逐维消融已经补充了规则敏感性证据：删除任一维后仍保留负向层差。但各池12项消融家族的Holm校正p均为0.09375，没有达到0.05标准。因此应说“观察方向保留”，不能说“所有删维结果均获得校正显著支持”或“风险权重已经最优”。

这项局限约束的是风险评分的普遍性与最优性，不取消当前冻结规则在已测池中的经验区分度。

## 五、局限性4：状态关联还不能解释为单字段因果

视觉条件会共现。小目标可能同时模糊、可见部位少；背向目标可能缺少面部线索；复杂背景也可能伴随遮挡。即使某状态上的Recall较低，仍不能确定错误独立由该状态造成。

删除一个风险维后，会重新评分、排序和划层，从而改变比较对象。例如，删除遮挡后落差仍存在，说明观察方向不依赖遮挡分值单项；它不证明遮挡没有作用，也不证明遮挡标签准确。其他维度可能携带相关信息，新层也可能保留大量原层目标。

分类器使用目标裁剪图，VLM同时查看原图、标记图与放大图，两者获得的视觉信息并不相同。部分背景或相对尺度条件可能对VLM分层可见，却没有完整保留在分类器输入中。这也限制了直接将VLM描述当作分类器内部失败原因的解释。

因此，状态诊断适合报告“这个条件下观察到较低表现”，当前不能写成“已经定位并证明这个特征是缺陷根因”。研究尚未通过受控图像编辑或条件干预隔离单字段作用。

## 六、局限性5：风险分层有效不等于Coverage选样全面优越

风险分层与Coverage选样回答不同问题。前者检查预定义条件能否区分模型表现；后者检查在同预算和相应控制下，覆盖驱动选样能否比其他策略揭示更多不同失败。

现有Coverage相对Random的增量结果依赖来源、控制方式和错误表征。部分共同风险配额设置得到正向收益，但VOC本地未复现相同收益；精确风险匹配、强基线和统一表征下也没有确立普遍优势。不能用随机分层检验显著，替代Coverage与DeepGini、Surprise Adequacy、k-center等选样策略的比较结论。

固定预算风险混合中，原始失败状态广度终点增加，但逐类别等错误数后的混淆类型和错误簇广度没有一致正向收益。暴露更多错误，可能是已有几种混淆变得更频繁；这与发现更多不同问题不是一回事。

当前可以把Coverage定位为测试条件组织与解释工具，并说明它何时增加诊断信息。不能将“错误率更高”“原始失败状态更多”单独作为测试方法全面优越的证明。

## 七、局限性6：重复次数很多，但独立证据单元有限

八架构各三个种子提供了24份模型运行，但同一架构的种子不等于三个独立架构。1000次风险混合抽样或10000次随机划层来自同一有限池，也不等于新增了1000或10000个独立数据来源。

统计区间具有不同含义，必须按计算方式解释。

| 统计材料 | 主要描述的不确定性 | 不应解释成什么 |
|---|---|---|
| 随机划层95%百分位范围 | 同池、固定预测和类别配额下的随机分组波动 | 风险差均值CI或部署总体区间 |
| 风险混合95%抽样范围 | 同池、固定模型面板下替换目标的波动 | 所有模型及未来自然分布的CI |
| 架构/种子层级bootstrap | 所测架构与种子面板的重采样变动 | 自动标签语义误差已经被覆盖 |
| 固定模型源图bootstrap | 已选模型及池中目标的抽样变动 | 架构总体或VLM版本的全部不确定性 |

多重比较会限制显著性结论。随机划层六项校正通过，但消融12项校正未通过；其他强基线家族也必须分别报告。不能把一个家族的显著性沿用到另一个家族。

同池两种VLM分层共用同一随机对照，并复用冻结模型预测，结果之间存在依赖。后续尝试的混合效应模型还存在未收敛或奇异警告，不能作为新增确认性证据。本文应继续以通过核验的既有统计为准。

## 八、局限性7：平均模型排名不能推广为普遍优劣

ConvNeXt-Tiny和Swin-T在已测完整Q5及固定预算风险混合设置中保持平均前两位，但这些排名对应的是当前训练配置、权重、目标区域输入与评价条件。

统一训练配置有助于形成一致比较，但每个架构的最佳训练超参数不一定相同。因此结果描述的是这些冻结模型实例，不是充分调优后所有同名架构的性能上限。

平均名次还不等于可靠的两两先后。完整池源图重采样显示，Objects365中Swin-T的平均第二名存在较大抽样不确定性；部分中间模型名次随风险占比变化。对接近的模型，应同时展示真实分差、区间及排名频率。

当前可以报告“在这些配置下，某模型平均高风险F1更高”。不能说“某架构在所有任务中更好”或把进入前两名的重采样频率称为真实世界最优概率。新的可视化应让差异可读，同时保留接近结果的真实距离。

## 九、局限性8：类别、数据来源和任务形式仍有范围限制

主实验包括dog、cat、horse、sheep、person和car，并在COCO、VOC2007与Objects365三个确认来源上开展。它已经是多类别研究，但仍不能代表全部对象类别、细粒度属性或所有视觉任务。

研究使用已知目标框裁剪后分类。真实部署还可能包含目标框定位失败、多目标关联、未知类别、背景目标混淆和输入质量变化。当前没有验证检测、分割、开放集识别等任务；person也不等于独立人脸识别实验。

六类平衡配额便于隔离类别比例的影响，但真实部署可能高度不平衡，类别之间的误报流向也会改变Precision和F1。实验池的资格筛选、下载前缀和框级标注规则，使结果不能直接当作自然部署分布或官方检测排行榜成绩。

历史排重与近重复检查降低了已知重叠风险，但无法保证排除全部近重复或与ImageNet等预训练数据的重叠。冻结规则保证当前比较一致，不等于数据与模型从项目最初起都没有历史影响。

## 十、局限性9：稀有状态与严格一致子集存在支持不足

细粒度诊断需要相应条件中有足够目标。候选池总体规模达到数千，并不保证每个类别的每种状态或状态组合都有足够样本。

VOC确认池中，部分冻结薄弱状态难以达到原支持门槛。Objects365扩大了可评价范围，但仍不是每条状态都复现。没有足够样本的状态应标为无法评价，不能把它解释为模型没有弱点，也不能把单个失败图当作统计确认。

严格要求多个字段同时在两VLM之间一致，还会大幅缩小可评价集合。这些保留样本可能更典型或更容易描述，与原始总体分布不同，因此“一致子集”不等于无偏的清洁真值集。

此处的局限主要影响所有状态的完整覆盖诊断及对标签分歧的总体稳健性证明。逐字段、支持足够的结果可以报告，但不能代替整个六类高低风险层和排名的验证。

## 十一、局限性10：探索历史与离线预标注条件影响适用方式

风险规则来自项目探索，后续确认沿用冻结规则。最新随机分层与删维分析是在已有历史结果后设计、在本轮新统计前固定的补充实验。因此“冻结确认”表示后续规则不随新结果修改，不应写成整个项目从一开始完全预注册。

技术失败替换、候选来源和下载预算调整都有记录。这些调整没有按分类收益挑选样本，但仍可能改变最终候选分布，需要在实验设置中保留说明。

当前策略还假设候选池已经完成状态标注，且真实类别已知，能够按类别配额选样。实际面对未知流式输入时，如何先取得类别、以何种成本完成状态描述、如何处理VLM服务与版本变化，是另一组尚未被本轮静态池实验完全验证的流程问题。

本研究的主要成果是测试与诊断，尚不能声称诊断一定指导了有效模型修复。修复实验不是当前测试主张成立的前提，但若未来声称定向补图或微调能改善被诊断状态，则需要另行比较训练前后及匹配对照。

## 十二、论文中最重要的三条收口原则

第一，将主结论写为“预定义视觉风险分层在已评估设置中区分固定分类器的条件表现”，不要写成“覆盖率越高模型必然越差”。

第二，将状态解释写为“自动状态协议下的条件关联与薄弱线索”，不要写成“全字段真值已经验证”或“已证明独立失败原因”。

第三，将Coverage增量结果写为“有条件的诊断收益”，将模型比较写为“冻结配置下的平均表现及排序不确定性”，不宣称全面最优。

这些局限不否定已测风险层差异及随机对照结果；它们决定了论文能把结论解释到哪里。当前研究适合以有明确证据边界的实证测试研究组织全文。
