# 视觉状态驱动的模型测试与充分性分析方法

版本：2026年11月9日，参照原稿优化。正文说明方法机制；附录提供当前实现参数与复现依据。候选规模比较及其结果另放实验章节。

## 一、问题定义与总体框架

本文面向图像分类模型测试中的视觉条件描述与测试充分性分析问题。测试集的样本数量、类别比例与整体分类分数，可以说明测试规模及总体识别表现，却不能直接说明类别内部的哪些视觉变化得到了测试。例如，选择200个马目标时，如果入选目标大多清晰、完整且朝向相近，即使模型总体分数较高，也难以据此了解其在背向、遮挡或局部不可见条件下的表现。因此，除计算模型分数外，还需要明确测试集包含哪些视觉条件、每种条件有多少样本，以及哪些条件仍缺少测试支持。

为此，本文构建视觉状态驱动的模型测试框架：将目标的可观察属性转化为结构化状态，利用状态覆盖与支持描述测试内容，依据本文定义的视觉风险组织测试构成，最终将模型预测与状态记录关联，形成条件能力报告。其中，覆盖评价回答“测试了什么、支持有多少”，风险组织规定“在怎样的视觉条件构成下开展测试”，条件能力报告进一步回答“模型在这些条件下表现如何”。

观察与选样单位为数据集中由目标框指定的目标实例。对类别 \(c\)，候选集合记为 \(\mathcal P_c\)，每个目标包含唯一标识、原图、官方目标框及类别真值。测试预算记为 \(B_c\)，最终入选集合记为 \(S_c\)。待测分类器接收按既定预处理生成的目标裁剪图，评价任务是在已知目标区域上进行多类别分类。

方法区分三类信息的作用：官方标注提供目标位置与类别真值；视觉语言模型描述目标的可见状态；被测分类器提供类别预测。状态提取时可使用目标类别提示，但其输出不替代官方类别真值。被测分类器的参数和预处理在测试过程中固定，其预测、置信度及错误信息不参与风险计算与成员选择。

完整流程为：

> 目标与状态字典准备 → 多视图状态提取与编码 → 视觉风险评分及配额分配 → 初始选样 → 覆盖与支持检查 → 必要时有限调整 → 固定测试集合 → 模型评价与条件复核。

已有测试集可以直接进行状态覆盖评价；需要构建或调整测试集时，再执行风险配额选样与有限调整。方法输出包括成员名单、风险构成、逐状态支持记录、覆盖指标及条件能力报告。本文所称充分性分析，是对预定义状态空间及支持要求的检查，其范围由状态字典明确界定。

## 二、目标级视觉状态表示

### 2.1 状态字典与观察范围

视觉状态是目标某项可观察属性的具体取值，例如“身体朝向—背向”或“遮挡程度—重度”。一个目标可以同时具有多个状态，因此状态能够描述同一类别内部的多种视觉变化。

状态字典由研究人员与大语言模型协同整理，在状态提取及选样前确定。字典按空间几何、可见性与完整性、外观与形态、朝向与姿态、场景与图像质量组织，并区分共享字段与类别专属字段。共享字段描述尺度、遮挡等跨类别条件，专属字段描述被毛、衣着或汽车部件等具有类别含义的外观。每个状态以“命名空间—字段—取值”唯一标识，避免将共享与专属字段中的同名取值直接合并。

以 \(U_c\) 表示类别 \(c\) 的全部合法已知状态，状态数量为 \(D_c=|U_c|\)。评价分母使用预先确定的字典，字典内尚未在候选池中观察到的状态仍予保留。当前评价单位为单字段取值；多个状态同时出现在同一目标上，不等同于已经评价其全部组合关系。

### 2.2 多视图提取与二值编码

状态提取利用原图、目标框标记图与目标细节裁剪，分别提供场景上下文、目标定位及局部外观证据。视觉语言模型按字段定义和允许取值输出结构化记录，尺度则由官方目标框面积占原图面积的比例计算。模型只能依据指定目标的可见证据赋值；不能判断时保留为未知。

提取完成后，核对目标绑定、字段完整性、枚举合法性、多选去重及互斥和依赖关系，并保存原始响应、提示词与版本信息。结构检查用于确认记录可解析、取值合规；语义核查需对照原图及裁剪图，重点检查未出现或极少出现的状态。

随后建立目标—状态二值矩阵。设类别 \(c\) 有 \(N_c\) 个候选目标，则

\[
X_c\in\{0,1\}^{N_c\times D_c},\qquad X_{is}=\mathbf1\{\text{目标 }i\text{被标注为具有状态 }s\}.
\]

矩阵每行对应一个目标，每列对应一个状态；同一目标对同一状态最多贡献一次，多选字段可以激活多个状态。未知、缺失及不适用不增加已知状态的支持。因此，零值表示当前记录未确认该状态，其中可能包含未知信息，不能全部解释为已确认该状态不存在。

## 三、状态覆盖与样本支持评价

### 3.1 三类覆盖指标

对类别 \(c\) 的测试集合 \(S_c\)，状态 \(s\) 的支持数为 \(n_s(S_c)=\sum_{i\in S_c}X_{is}\)。支持数回答“有多少入选目标被标记为具有该状态”。以下省略类别下标，设状态支持目标为 \(K>0\)，分别定义出现覆盖率、支持完成度与达阈值覆盖率：

\[
\begin{aligned}
C_{\mathrm{occ}}(S)&=\frac{1}{D}\sum_{s\in U}\mathbf1\{n_s(S)>0\},\\
C_{\mathrm{sup}}(S)&=\frac{1}{KD}\sum_{s\in U}\min\{n_s(S),K\},\\
C_{\mathrm{thr}}(S)&=\frac{1}{D}\sum_{s\in U}\mathbf1\{n_s(S)\ge K\}.
\end{aligned}
\]

出现覆盖率描述字典中至少被涉及一次的状态比例；支持完成度描述各状态相对于支持目标的积累程度；达阈值覆盖率描述支持数已经达到目标的状态比例。例如，\(K=20\) 时，一个只出现一次的状态已经计入出现覆盖，其支持完成度贡献为 \(1/20\)，但尚未计入达阈值覆盖。某状态支持达到 \(K\) 后，继续增加样本不再提高支持完成度，避免常见状态的大量重复掩盖其他状态的不足。

各指标先在类别内对状态等权平均，再在类别间进行宏平均；共享、专属与完整状态空间分别报告。字段内部不再额外归一化，因此枚举值较多的字段具有更大的潜在总贡献。\(K\) 为统一的操作性支持要求；达到该值表示达到规定样本量，不自动保证统计精度或全部部署条件已经测试充分。

### 3.2 支持缺口及候选池约束

依据支持数，将状态区分为未出现、已出现但支持不足、达到支持目标三类。对每个缺口，同时查询完整候选池支持数 \(n_s(\mathcal P_c)\)：若池内也未观察到该状态，仅重选现有目标无法补充；若全池支持仍低于 \(K\)，则当前候选池无法使其达阈值；池内数量足够时，还需检查预算、风险配额与成员调整限制是否允许补入。

因此，覆盖评价同时输出汇总指标与逐状态缺口表，区分候选池本身缺少的条件和当前入选集合尚未提供的支持。这里的计数均以目标为单位；同一原图中的多个目标不自动视为相互独立的观测，模型诊断阶段另行检查不同原图数量。

## 四、视觉风险定义与初始测试组织

### 4.1 风险评分与未知信息

为组织不同视觉条件下的测试，本文选取尺度、可见性、遮挡、截断和朝向五个维度构造视觉风险评分。各字段取值按预设映射换算至 \([0,1]\)，再将五个维度等权合成为0—100分。尺度越小、可见性越低、遮挡或截断越重，对应分值越高；朝向按预设规则赋值。具体映射及维度内组合规则见附录A。

当基础分量未知时，保留其原定权重，将可能贡献表示为区间。设第 \(d\) 个维度的风险上下界为 \(r_{id}^-\) 与 \(r_{id}^+\)，定义

\[
\begin{aligned}
R_i^-&=20\sum_{d=1}^{5}r_{id}^-,\qquad R_i^+=20\sum_{d=1}^{5}r_{id}^+,\\
\bar R_i&=\frac{R_i^-+R_i^+}{2},\qquad W_i=R_i^+-R_i^-.
\end{aligned}
\]

已知分量的上下界相同，未知基础分量保留 \([0,1]\) 范围，并按原权重聚合。中点 \(\bar R_i\) 用于排序，宽度 \(W_i\) 记录未知信息造成的评分范围。未知值不置零，也不通过删除后重新分配权重处理。

风险分值及其高低方向由本文的映射与合成规则定义，用于组织测试条件。其与模型实测表现的关系在后续评价中检验，分数本身不解释为分类错误概率。

### 4.2 类内风险单元与固定配额

在每个类别内，按风险中点升序排列目标，同分按目标ID排序，按数量划分为Q1至Q5五层。Q1与Q5分别表示该类别候选池中的相对低分层与高分层，不对应跨类别通用的绝对难度界限。

在各Q层内，将风险中点和区间宽度相同的目标划为同一精细风险单元。实现中对两项数值乘以 \(10^8\) 后四舍五入，确定单元身份。主设置将每类预算均分至五层，再按层内各单元的候选数量比例，以最大余数法分配整数名额。设类别 \(c\) 中单元 \(h\) 的候选集合为 \(\mathcal P_{ch}\)，其配额为 \(b_{ch}\)，合法测试集合满足

\[
|S_c|=B_c,\qquad |S_c\cap\mathcal P_{ch}|=b_{ch}\quad\text{对每个单元 }h.
\]

在每个单元内按配额无放回随机抽样，合并为初始集合 \(S_c^0\)。配额随后固定，成员调整仅在相同配额约束下进行。这样，可以在测试数量和规定的代理风险构成相同的条件下，比较不同集合提供的状态支持；这种控制不保证五个原始维度逐项相同，也不保证所有影响分类错误的因素相同。

## 五、覆盖检查与有限成员调整

### 5.1 参照集合与调整触发

初始选样先满足风险构成要求，再检查视觉状态是否获得规定支持。为给出可执行的检查要求，在同候选池、同预算及同风险配额下，构建一个覆盖引导的贪心参照集合 \(V_c\)。参照选择从空集开始，每步仅考虑所在单元仍有名额的候选，优先选择能增加稀缺状态支持的目标；达到支持上限后不再增加收益。具体采用截断对数支持的边际增益，同分按目标ID决定。

以参照集合的出现覆盖与支持完成度确定双指标门槛：

\[
\alpha_c=\rho C_{\mathrm{occ}}(V_c),\qquad
\beta_c=\rho C_{\mathrm{sup}}(V_c),\qquad \rho=0.95.
\]

门槛在读取本轮分类预测前确定。若初始集合同时满足两项要求，则直接保留；否则，触发有限成员调整。这里95%表示取参照指标的95%，不是95%的字典状态已经达标，也不是统计置信度。参照集合提供同约束下的可行比较基准，不作为全局最优上界。

### 5.2 约束与两阶段求解

调整旨在保留初始测试组织的基础上补充不足状态。设最多允许移出 \(L\) 个初始成员，省略类别下标后，调整集合 \(S\) 满足

\[
\begin{aligned}
|S|&=B,\qquad |S\cap\mathcal P_h|=b_h,\qquad |S^0\setminus S|\le L,\\
C_{\mathrm{occ}}(S)&\ge\max\{C_{\mathrm{occ}}(S^0),\alpha\},\\
C_{\mathrm{sup}}(S)&\ge\max\{C_{\mathrm{sup}}(S^0),\beta\}.
\end{aligned}
\]

前一行固定测试数量、单元配额和改动上限，后两行要求出现覆盖与支持完成度均不低于初始水平，并达到检查门槛。约束依据最终集合的净支持计算，同时计入新增成员的贡献与移出成员造成的损失。

采用两阶段混合整数规划求解。第一阶段最大化封顶支持总量 \(T(S)\)；第二阶段在保持第一阶段所得实际支持总量不下降的条件下，最大化出现状态数 \(A(S)\)：

\[
T(S)=\sum_{s\in U}\min\{n_s(S),K\},\qquad
A(S)=\sum_{s\in U}\mathbf1\{n_s(S)>0\}.
\]

当前主设置为每类选择200个目标，\(K=20\)、\(L=20\)，即至少保留180个初始成员。该实现简称P20，其中20表示最多移出20个初始成员；两阶段共用同一初始集合与调整预算。

求解结束后，依据最终成员和完整状态矩阵重新核验目标身份、数量、风险配额、改动数及两项指标。第一阶段有合格结果而第二阶段没有可接受结果时，保留第一阶段结果；未取得合格结果时，返回初始集合并记录未达标原因，不降低门槛继续补选。求解状态同时注明结果是否取得最优性认证。

达阈值覆盖率与逐状态缺口随最终集合一并报告。两阶段的优化次序为支持完成度优先、出现覆盖其次，不据此保证达阈值覆盖率或每一个状态的支持数都不下降。

## 六、模型评价与条件能力报告

### 6.1 总体、风险层与状态表现

最终成员固定后，将官方类别、模型预测和视觉状态按目标ID关联。先构建多类别混淆矩阵，报告整体Top-1准确率、各类别Precision、Recall、F1及宏平均F1；宏平均F1为各类别F1的算术平均。随后按Q1至Q5分别评价，观察本文定义的风险层与模型实测表现的对应关系。

为定位具体视觉条件，对每个“类别—模型—状态”建立状态组与已知对照组。状态组包含具有该状态的入选目标；已知对照组包含同类别、同命名空间、同字段具有其他已知取值且不具有该状态的目标。字段未知的目标不进入已知对照组。多选字段中，只要目标具有待分析状态，就归入状态组。

设两组为 \(G_s^+\) 与 \(G_s^-\)，\(a_{mi}\) 为模型 \(m\) 对目标 \(i\) 在固定预测种子上的平均正确性，取值介于0与1。组内条件召回率及其差值为

\[
\begin{aligned}
\operatorname{Recall}_m(G)&=\frac{1}{|G|}\sum_{i\in G}a_{mi},\\
\Delta_{cms}&=\operatorname{Recall}_m(G_s^+)-\operatorname{Recall}_m(G_s^-).
\end{aligned}
\]

两组的真实类别均为 \(c\)，因此组内正确识别比例即为该条件下的类别召回率。采用同字段已知对照，可以明确比较对象，例如将“背向”与同类别中朝向已知的非背向目标比较，避免把朝向未知目标混入对照。

### 6.2 候选弱状态与跨来源复核

当前诊断要求两组各至少包含20个目标，并各自来自至少20张不同原图。满足要求且 \(\Delta_{cms}\le-0.10\) 时，将该条件记为候选弱状态，表示状态组召回率比已知对照组至少低10个百分点。样本门槛限定可评价范围，差值门槛筛选具有一定幅度的差异；它们不等同于逐项显著性检验。支持不足时标记为不可评价，并保留对应缺口。

对全部符合规则的候选条件，在无原图重叠的其他来源参考数据中，沿用相同状态定义、分组方式、样本门槛和差值门槛复核。参考数据满足支持要求且仍达到差值门槛时，记为重复出现；支持足够但未达到差值门槛时，记为未重复；支持不足时，记为无法复核。保留全部结果，不根据参考结果替换候选清单。当前使用已分析过的历史参考数据，按历史跨来源重复分析报告。

条件能力报告逐行记录数据来源、标注版本、模型、类别、状态、两组目标数与原图数、条件召回率、差值及复核状态。汇总时同时给出候选数、可复核数、重复出现数、支持不足数，以及跨模型去重后的状态数量。跨模型与跨来源的重复现象描述观察到的一致性，不将状态与分类错误的关联解释为因果关系。

### 风险映射与配额计算

设原始目标框面积占原图面积的比例为a。尺度按a＜0.01、0.01≤a＜0.03、0.03≤a＜0.10、a≥0.10划分为tiny、small、medium、large，对应风险分为1、2/3、1/3、0。

| 字段 | 冻结取值与风险分 |
|---|---|
| 局部可见性 | clear:0；partial:0.5；not_visible:1 |
| 腿部可见性 | all_expected:0；some:0.5；one:0.75；none:1 |
| 汽车整体可见性 | full/most:0；partial:2/3；minimal:1 |
| 遮挡程度 | none:0；light:1/3；moderate:2/3；heavy:1 |
| 截断程度 | none:0；light:0.25；moderate:0.5；heavy:1 |
| 主体朝向 | front/left_side/right_side/three_quarter:0；back:0.5；overhead_or_unusual:1 |
| 头部朝向 | front/left/right:0；back:0.5；up/down:1 |

当前采用equal_parts规则：非汽车类别可见性由共享头部与腿部可见性各占0.5合成，朝向由共享主体与头部朝向各占0.5合成；汽车使用整体可见性和主体朝向。

设维度d内构成字段权重为w_dk、已知分值为v_ik，则：

\[
r^-_{id}=\sum_{k\text{已知}}w_{dk}v_{ik},\qquad
r^+_{id}=r^-_{id}+\sum_{k\text{未知}}w_{dk},\qquad
R_i^{\pm}=20\sum_{d=1}^5r^{\pm}_{id}.
\]

精细单元键为 \((c,Q_i,\operatorname{round}(10^8\bar R_i),\operatorname{round}(10^8W_i))\)。Q层q内有N_cq个候选、需选b_cq个，某单元候选数为N_ch，则理想名额为 \(\widetilde b_{ch}=N_{ch}b_{cq}/N_{cq}\)。先向下取整，再按小数余数从大到小分配剩余名额，同余时采用固定单元顺序。初始抽样随机流由SeedSequence([selection_seed, class_index])派生，类别顺序为狗、猫、马、羊、人、汽车。

### 有限调整的优化形式

以z_i∈{0,1}表示是否选择目标i，以a_s∈{0,1}表示状态是否出现，以连续变量t_s表示封顶支持，设n_s=∑_i X_is z_i、M_s=∑_i X_is。约束为：

\[
\sum_{i\in\mathcal P_h}z_i=b_h,\quad
\sum_{i\in S^0}z_i\ge B-L,\quad
0\le t_s\le K,\quad t_s\le n_s,\quad
a_s\le n_s\le M_sa_s.
\]

另设 \(A(S)=\sum_s\mathbf1[n_s(S)>0]\)、\(T(S)=\sum_s\min(n_s(S),K)\)，要求：

\[
\sum_sa_s\ge\max\{A(S^0),\lceil\alpha D\rceil\},\quad
\sum_st_s\ge\max\{T(S^0),\lceil\beta KD\rceil\}.
\]

实际取整采用1e−9容差，避免浮点误差使整数下限多加1。第一阶段最大化∑_s t_s；获得候选后从完整矩阵重算其实际T¹，第二阶段追加∑_s t_s≥T¹，再最大化∑_s a_s。若第二阶段未产生可接受结果，保留第一阶段合格结果；若没有合格结果，返回初始集合并报告失败状态。
