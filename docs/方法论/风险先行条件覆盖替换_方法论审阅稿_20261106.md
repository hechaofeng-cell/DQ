# 风险配额约束下的视觉状态覆盖检查与条件替换测试方法

审阅稿日期：2026-11-06。本文依据2026-11-05冻结协议、实际选样实现及结果编写。第1—7节为方法正文，第8节为当前实现范围，第9节说明已有证据边界。历史文档中尚未实现的建议，以本稿引用的冻结协议和实现为准。

## 1. 研究问题与总体思路

在有限测试预算下，仅规定测试样本的类别数量和风险分层数量，仍不能确定具体视觉状态获得了多少样本支持。同一风险层中，不同目标可能具有不同的外观、局部可见性、朝向和场景状态；风险构成相近的两个集合，也可能具有不同的状态覆盖情况。因此，本研究在固定预算和预定义风险构成的条件下，检查并修补测试集的视觉状态覆盖，再利用固定后的集合评价分类模型。

方法首先按风险配额形成完整初始集合，随后计算其状态覆盖。若覆盖达到预先冻结的操作要求，直接保留集合；若未达到要求，则仅在同一精细风险单元内替换目标，并在双覆盖达标后停止。覆盖要求用于决定是否需要调整以及何时停止，模型预测不参与选样。

整体流程为：

> 定义视觉状态字典 → 提取逐目标状态 → 计算风险及配额 → 按配额选满初始集合 → 检查双覆盖 → 未达标时执行同单元替换并复查 → 达标或触发停止条件 → 冻结集合 → 模型分层评价与状态诊断。

本文将覆盖达标定义为满足指定字典、预算和阈值下的操作要求，不将其等同于测试充分性已获证明。

## 2. 候选目标与视觉状态表示

输入为具有真实类别标签和目标框的候选池。选样单位为目标实例：同一原图可以包含多个目标，替换只改变入选实例，不修改原图、目标内容或真实标签。每个实例保留目标ID与原图ID，以支持身份核对、数据隔离和按原图进行统计。

首先由人工与LLM协同明确字段、有效取值和适用规则，冻结视觉状态字典；随后由VLM依据字典提取逐目标状态，尺度等几何信息由原始目标框和原图尺寸计算。字典按空间几何、可见性与完整性、外观与形态、朝向与姿态、场景与图像质量五大类组织，并区分跨类别共享字段与类别专属字段。

一个状态由“命名空间、字段、取值”共同标识。例如，“共享／遮挡程度／重度”与“类别专属／头部可见性／部分可见”是不同状态；头部朝向与主体朝向也分别编码。对类别 \(c\)，记候选池为 \(\mathcal P_c\)，冻结字典为 \(U_c\)，实例 \(i\) 的状态向量为：

\[
X_{is}=\mathbf 1\{\text{实例 }i\text{ 具有状态 }s\},\qquad s\in U_c.
\]

同一实例对同一状态最多贡献一次支持。unknown、缺失和不适用不作为有效状态；字典中已经声明但候选池未观测到的有效状态仍保留在覆盖分母中。覆盖计算采用全部共享与专属状态，同时分别报告两部分结果。当前合并指标按状态等权，不按五大类等权。

## 3. 风险评分与固定配额

风险分支决定测试集应保留怎样的风险构成。当前实现采用目标尺度、可见性、遮挡、截断、朝向五个风险维度，每维权重为0.2。五大类是完整字段的组织方式，五个风险维度是本轮实际使用的评分范围；外观、姿态动作、场景等字段保留用于覆盖和诊断。

各维度依据冻结映射得到 \([0,1]\) 内的分值；含多个局部字段的维度先按固定维内权重聚合。对实例 \(i\)，维度 \(d\) 的分值下、上界分别记为 \(r^-_{id}\) 和 \(r^+_{id}\)，总风险表示为：

\[
R_i^-=20\sum_{d=1}^{5}r^-_{id},\qquad
R_i^+=20\sum_{d=1}^{5}r^+_{id},\qquad
\bar R_i=\frac{R_i^-+R_i^+}{2}.
\]

已知字段的上下界相同；未知字段按其固定权重保留从0到1的贡献范围，不能直接计为零风险，也不通过删除未知字段改变权重分母。中点用于分层，同时保留区间宽度 \(w_i=R_i^+-R_i^-\) 作为评分不确定性的记录。该分数是预定义视觉风险代理，不是模型分类失败概率。

按类别内风险中点排序并依照冻结的同分规则划分Q1—Q5，每层获得相同测试名额。在每个Q层内，再以“类别、Q层、风险中点、区间宽度”定义精细风险单元 \(h\)。中点和宽度按实现乘 \(10^8\) 后取整。单元名额依候选数量比例通过最大余数法分配，记为 \(b_{ch}\)。

若该类总预算为 \(B_c\)，最终集合 \(S_c\) 始终满足：

\[
|S_c|=B_c,\qquad |S_c\cap\mathcal P_{ch}|=b_{ch},\qquad
\sum_h b_{ch}=B_c.
\]

各方法共用相同配额，替换过程中不重新划层或分配名额。这样控制的是上述聚合代理风险单元的数量，不保证五维风险逐项相同，也不保证真实识别难度相同。

## 4. 双覆盖检查与阈值冻结

对状态 \(s\)，当前集合的支持数定义为：

\[
n_s(S_c)=\sum_{i\in S_c}X_{is}.
\]

出现覆盖率衡量有多少声明状态至少获得一次支持：

\[
C_{\mathrm{occ},c}(S_c)=\frac{1}{|U_c|}
\sum_{s\in U_c}\mathbf 1\{n_s(S_c)\ge1\}.
\]

支持完成度衡量状态支持达到目标数量的平均进度：

\[
C_{\mathrm{sup},c}(S_c)=\frac{1}{|U_c|}
\sum_{s\in U_c}\min\left(\frac{n_s(S_c)}{K},1\right).
\]

其中 \(K\) 为支持目标，主设置取20。例如某状态有10个支持时，其支持完成度贡献为0.5。该指标不等于“支持数达到20的状态比例”；后者作为辅助指标另行报告。两指标分别检查状态是否出现、支持是否充足，避免只凭一次出现就忽略样本支持不足。

类别 \(c\) 达标要求两项同时满足：

\[
C_{\mathrm{occ},c}(S_c)\ge\alpha_c,\qquad
C_{\mathrm{sup},c}(S_c)\ge\beta_c.
\]

各类分别检查，所有优化类别均达标才记为整体共同达标，不能以类别平均值代替。

当前阈值由历史开发池校准：在相同预算、风险配额和完整字典下运行确定性覆盖贪心，得到参照集合 \(W_c\)，并固定：

\[
\alpha_c=0.95C_{\mathrm{occ},c}(W_c),\qquad
\beta_c=0.95C_{\mathrm{sup},c}(W_c).
\]

95%是相对参照覆盖值的比例，不是绝对覆盖率95%。参照集合及实际阈值在主选样前冻结，后续新候选池沿用冻结值，不依据模型表现回调。贪心参照提供历史池中的一个可行集合，不代表覆盖最优解，也不保证新候选池可达。建立参照的成本单独计入首次使用成本。

## 5. 完整初始集合与条件替换

### 5.1 初始选样与触发

在各精细风险单元内按名额无放回随机抽样，一次性选满 \(S_c^{(0)}\)。各类别随机流由固定种子和类别索引共同派生。随后检查完整集合：若双覆盖已经达标，不进行候选交换搜索，保留原样；否则启动该类的条件替换。已经达标的其他类别不参与调整。

### 5.2 合法交换与净支持更新

令 \(x\in S_c\) 为移出实例，\(y\in\mathcal P_c\setminus S_c\) 为移入实例。仅允许两者属于同一个精细风险单元，得到：

\[
S'_c=(S_c\setminus\{x\})\cup\{y\},\qquad
n_s(S'_c)=n_s(S_c)-X_{xs}+X_{ys}.
\]

这一交换保持总预算及精细配额。收益必须按交换后的完整集合计算：移出实例可能提供某个状态的最后一个支持，不能只统计移入实例新增的状态。

### 5.3 缺口优先的交换选择

以双覆盖的归一化正缺口表示未达标程度：

\[
D_c(S)=
\frac{[\alpha_c-C_{\mathrm{occ},c}(S)]_+}{\max(\alpha_c,\varepsilon)}+
\frac{[\beta_c-C_{\mathrm{sup},c}(S)]_+}{\max(\beta_c,\varepsilon)},
\qquad [z]_+=\max(z,0).
\]

辅助采用封顶对数支持效用：

\[
J_c(S)=\frac{1}{|U_c|\log(1+K)}
\sum_{s\in U_c}\log\bigl(1+\min(n_s(S),K)\bigr).
\]

该效用为覆盖缺口相同的候选提供排序依据，支持达到 \(K\) 后不再增加贡献。每轮枚举所有合法同单元交换，并执行以下规则：

1. 已达标的任一覆盖指标不得重新跌破其阈值。
2. 仅接受缺口 \(D_c\) 严格减小，或缺口在容差内不变且 \(J_c\) 严格增大的交换。
3. 在可接受候选中先选择缺口最小者，再选择辅助效用最大者；仍同分时按移出ID、移入ID排序。

数值容差 \(\varepsilon=10^{-12}\)。该规则不将风险分与覆盖收益加权相加：风险配额限定可交换范围，覆盖缺口和状态效用决定范围内的替换。

### 5.4 停止、核验与输出

每次接受交换后更新状态支持，重新计算双覆盖，并检查预算、精细配额及增量计数与全量重算是否一致。双覆盖达标即停止；若没有合法交换、完整扫描没有可接受改进，或搜索资源耗尽，也停止并保存当前集合。

主设置每类最多接受 \(B_c\) 次交换，最多评价2,000,000个候选交换。若扫描中途达到评价上限，丢弃该次未完成扫描的临时最优候选，保持当前集合并结束。输出区分初始达标、调整后达标、无合法交换、局部无改进、搜索上限及交换次数上限，并另存最终达标标记。局部无改进不能解释为全局不存在可行解。

```text
输入：候选状态、风险单元、配额、双覆盖阈值、支持目标、随机种子
逐类别执行：
    按精细风险配额无放回抽样，形成完整集合S
    计算完整集合的状态支持和双覆盖
    当双覆盖未达标时：
        若达到交换次数上限：停止
        枚举已选与未选实例之间的全部合法同单元交换
        若没有合法交换或无法在剩余搜索预算内完成扫描：停止
        按“保护已达标项、缺口优先、效用次序”选择最佳可接受交换
        若无可接受交换：停止
        执行交换，核验预算、配额和状态支持
    保存最终集合、达标标记、停止原因与完整轨迹
冻结全部选集，再开展分类评价
```

## 6. 固定集合后的模型评价与状态诊断

最终集合冻结后，才读取被测模型预测。按风险层分别构建完整多类别混淆矩阵，计算各类Precision、Recall、F1，以及明确口径的Accuracy。六类整体top-1 Accuracy与单类one-vs-rest Accuracy分别命名；单类Precision不能仅由该类正例计算。分层表现用于描述模型在不同代理风险层的表现，不能反过来修改选集或选择阈值。

状态诊断在冻结集合上查找低表现条件。对每个“类别—模型—状态”，以具有该状态的目标为状态组，以同类、同字段已知且不具有该状态的目标为对照组。unknown、缺失及不适用不能作为已知非状态对照。

当前诊断规则要求两组分别至少20个目标且来自至少20张不同原图；先平均三个预测种子的组内Recall，再计算状态组减对照组的差值。差值不高于−10个百分点时列为候选，每个类别、每个模型最多保留差值最负的3项，同分按状态标识排序。

候选条件冻结后，再在独立参考池中按相同状态定义、支持门槛和差值标准复核。分别记录提出数、可评估数、确认数、支持不足数，以及跨模型去重后的确认状态类型数。支持不足单独列示，在确认数量中贡献零，不进入可评估确认率的分母。

该分析描述状态与低表现的关联；共现视觉因素仍可能影响组间差异，不能解释为该状态独立导致错误。独立确认要求发现池与参考池按原图隔离；已分析过的历史参考池重算仅作为回顾性证据。

## 7. 对照设计与评价维度

实验分别评价约束与覆盖、选样成本、模型分层表现及诊断效用，避免以覆盖增加直接替代测试效用证据。保留以下六种方法：

| 方法 | 选样机制 | 比较用途 |
|---|---|---|
| R：风险配额随机 | 按精细配额选满，不调整 | 提供初始集合和覆盖修补前的参照 |
| G：完整覆盖贪心 | 从空集合按封顶对数支持边际增益逐例加入，直至选满 | 比较最终覆盖与真实选样时间 |
| SR：静态稀缺度 | 依据候选池状态频次反比评分，在配额下选满 | 检查简单状态选样是否已足够 |
| KC：ViT k-center | 在固定视觉嵌入和配额下选择多样性实例 | 比较视觉嵌入多样性与具名状态覆盖 |
| CS：条件替换 | 完整集合未达标时替换，双覆盖达标即停 | 本方法 |
| AS：持续替换 | 与CS共用初始集合、交换规则及资源上限，达标后仍尝试提高辅助效用 | 检验条件触发和停止机制的作用 |

R、CS、AS使用配对的初始种子和初始集合。CS与AS在CS首次达标前应有相同交换轨迹。确定性基线的重复计时不当作独立选集，多个随机种子也不当作多个独立数据集。

成本分别报告候选标注与编码、输入载入、参照校准、初始抽样、覆盖检查、候选搜索及分类预测。算法计时和首次使用总成本分开；交换次数、候选评分数与真实耗时分别记录。所有最终集合预算相同，不能据替换减少宣称分类推理次数减少。诊断统计以原图作为重采样单位，避免将同图目标当作独立证据；正式不劣性结论还需有效的统计校准与新参考数据。

## 9. 审阅时应把握的证据边界

本稿的方法主线是风险配额约束下的覆盖检查与必要修补。当前实验支持CS在既定历史池中保持预算和精细配额、完成覆盖修补，并相对AS减少继续搜索。主设置尚未支持CS相对完整贪心更快；历史参考集复核也未显示其平均确认条件实例数高于随机选样。

新C-select与C-ref确认尚未完成，因此跨新候选池的可用性与独立诊断收益仍待验证。自动状态标签也没有独立人工金标准提供语义准确率证明。上述边界依据[完整实验结果](/home/hcf/project/QE/docs/实验方案与结果/风险先行条件覆盖替换_实验结果_20261105.md)、[主结果原表](/home/hcf/project/QE/artifacts/risk_first_conditional_coverage_20261105/method_summary.csv)和[实现核验记录](/home/hcf/project/QE/artifacts/risk_first_conditional_coverage_20261105/validation.json)。

因此，当前可表述的作用是：在给定风险构成下形成测试集，用冻结的状态覆盖要求检查证据分布，并通过受约束的条件替换补足覆盖缺口。选样是否更快、是否发现更多可复核弱项，分别由成本实验和独立诊断实验回答。
