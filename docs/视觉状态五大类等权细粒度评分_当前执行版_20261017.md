# 视觉状态五大类等权细粒度评分：当前执行版

更新时间：2026-10-17

本文件记录用户最新执行口径。它是对历史“五维风险评分”实验的**版本化补充**，不覆盖历史结果。

## 五大类

1. 空间几何
2. 可见性与完整性
3. 外观与形态
4. 朝向与姿态
5. 场景与图像质量

五类等权，每类 20 分，总分 100 分。每一类内部由 LLM 已确定的细粒度视觉字段组成；字段在类内等权，缺失值保留下界/上界，并用总分中点进行 Q1–Q5 五等分。

## 猫类本次执行

## 解释边界

本次是流程联调和小样本 pilot。20 个目标、每个 Q 层 4 个候选且每层只选 2 个，因此模型分层召回只作描述性检查。正式结论前，需要对各类别扩充样本，并由人工审查细粒度标签和名义特征的难度映射。
