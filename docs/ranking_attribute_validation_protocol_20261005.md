# 模型排名与官方属性参考补强方案

本轮为已有结果之后确定的事后分析。研究目标是条件诊断与模型能力比较，不将Coverage全面优于其他方法设为成立条件。复用全部现有标签、预测与官方属性；不训练、不新增VLM请求、不新增人工复核。

## 排名敏感性

使用B/COCO2400、C/VOC2007 600、D/Objects3652400正式目标及8架构×3种子的冻结预测。每池独立分析本地/线上×unknown下界/中点/上界六种配置。沿用已定义的H映射，按类别风险排序、同分按sample_id，五等分，完整Q5为主要排名样本。每配置每类Q5保持80/20/80图；不对一致样本重新分层。架构分数是三个种子的Macro-F1均值。

记录六配置全部15对Kendall tau-b、Spearman、前两名重合数、Q5目标交集/Jaccard及各模型名次变化。真分数完全相同时按并列名次、前两名席位均分处理，图中保留并列。逐种子结果用于描述训练变动，不充当24个独立架构。

2000次按源图、真实类别重采样，每类别抽取该完整候选池原数量。一次抽样由所有模型及六配置共享，固定各配置原Q5身份，保留不同分层的重叠和模型间预测相关性；筛选后缺类的抽样不可评价并报告有效次数，不另补样。此区间条件于固定模型、标签和风险层。输出名次2.5/97.5百分位、进入前两名的重采样频率、F1区间、模型间配对F1差区间。模型差包含零时不明确区分先后；多对区间仅描述性、不作新显著性确认。抽样中的前两名频率不是模型在真实世界最佳的概率。

停止标准：所有正式目标ID/类别与缓存一致，18种配置完整、每配置24运行、重采样记录可追溯。按实测排序稳定程度表述，不调整H或指标争取排序稳定。

## 官方属性参考

只对历史A中已有Open Images框级参考的目标计算遮挡、截断二值参考一致性；VOC和没有等义参考的来源不混入。先固定现有映射：none→0、light/moderate/heavy→1、unknown→缺失。该映射仅验证二值参考的一致性，不验证所有严重度等级或其他字段真值。

按来源、字段、类别输出planned/known/unknown、TP/TN/FP/FN、参考一致率及Wilson区间、Precision/Recall/F1、Specificity、Balanced Accuracy和Kappa；汇总同时报告目标加权与类别等权均值，避免sheep数量较少隐藏构成差异。Unknown单独报告，主要指标条件于非unknown；不把缺失当作正确。

2000次按源图、类别重采样，双VLM共享抽样，报告Precision/Recall/F1等区间及来源配对差。保留标签参考与本地/线上状态的样本级映射，并逐项核对既有官方属性核验的混淆矩阵。

目标尺度另在A/B/C/D按官方目标框归一化坐标复算面积比、尺度阈值，核对清单浮点舍入误差和阈值边界；这属于程序一致性，不是独立视觉状态真值。受控图像变换不在本轮范围，它需要新标注且只能核验变换响应。
