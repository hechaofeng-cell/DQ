# 多类别完整目标视觉状态覆盖实验协议

## 研究问题

在冻结多分类模型、相同类别预算和相同候选池条件下，类别内部视觉状态覆盖选样能否比随机选样发现更广的模型失败状态？

## 主实验类别

主实验固定为五个粒度一致的完整目标类别：`dog`、`cat`、`horse`、`sheep`、`person`。`face`属于局部区域目标，保留为独立扩展实验，不混入主实验宏平均。

每类候选固定为400张，总计2000张。每个测试预算对五类等量取样，禁止只增加某一个类别。

## 覆盖定义

所有类别统一使用`object_state_v1.0`核心状态协议。类别`k`的频数饱和覆盖为：

`C_k(D) = sum_s min(n_{k,s}(D), cap) / (|S| * cap)`

总体覆盖使用类别宏平均：

`C_macro(D) = (1/K) * sum_k C_k(D)`

不得把不同类别的样本直接合并计算微平均覆盖，以免候选更多或状态更频繁的类别占据更大权重。

协议显式记录自然照片、屏幕或印刷、插画、雕塑或玩具等视觉呈现形式。描绘目标可以进入对应类别，但不能与自然照片隐式混合；它们作为可审计的视觉状态参与覆盖分析。

## 预算梯度

第一轮预算为每类`20、40、60、80、100`张，对应总测试集`100、200、300、400、500`张。每个预算点的类别比例始终为1:1:1:1:1。

## 选样方法

- Coverage：只使用结构化视觉状态，不访问被测模型；
- Random：同预算重复随机抽样；
- DeepGini：使用被测模型输出；
- DSA：使用训练特征和候选特征；
- k-center：使用固定视觉嵌入。

## 主要指标

- 类别宏平均失败状态广度；
- 每100张测试图片发现的新增失败状态数；
- 各类别失败状态广度及其AUC；
- 模型间覆盖敏感度。

Macro-F1、Macro-Recall、每类别Recall/F1和混淆矩阵为辅助指标。压力测试F1降低只表示所选测试集更难，不表示冻结模型训练退化。

## 固定条件

- 冻结训练数据、模型权重和预处理；
- 候选源图与训练源图零重叠；
- 所有方法使用相同类别预算；
- 状态协议在选样前冻结；
- 不使用face结果支持完整目标多类别主结论；
- 自动VLM状态标签必须通过字段、枚举、依赖和身份一致性校验。

## 判定边界

Coverage相对Random在类别宏平均失败状态广度AUC上提高，并在多数模型、种子和类别上方向一致，支持模型无关诊断价值。只有跨类别一致并经多重比较校正后显著，才支持通用性；单一类别显著只能作为局部证据。
